### 1.2 模型要点（决定求解器设计的关键结构）

**状态（33 维）**：S、DO2、O₂尾气、P、V、Wt、pH、T、Q、黏度、总 X、菌丝区 A0/A1/A3/A4（分支/延伸/退化/自溶）、液泡种群分布 n0–n9 + nm + φ0（对流-扩散-消亡 PDE 离散）、CO₂尾气、溶解 CO₂、PAA、NH₃、μ_p、μ_x。

**动力学/传递结构**：
- 底物消耗 Monod（K_b=0.05、K_e=0.009 g/L）；μ_p 产物形成 = 非生长关联项（ρ_a0·v_a1·P_inhib，Luedeking–Piret 变体）− 水解 μ_h·P；
- 抑制开关链：DO/pH/T/CO₂/PAA/NH₃ 的 tanh 型抑制项（inhib_flag 0/1/2 三档）；
- 传氧 kLa 与功率、黏度、油体积分数耦合（a/b/c/d 指数 0.38/0.34/−0.38/0.25）；OUR/CER 走尾气 O₂/CO₂ 平衡；
- pH 酸碱分段（[H⁺] 与 [OH⁻] 两套平衡，γ1/γ2/γ3 化学计量系数）；
- 能量平衡：发酵热 + 搅拌/通气功率 − 夹套非线性传热（Fc^(β+1) 项）− 蒸发；
- 体积/重量/稀释项与蒸发耦合，进料为糖/PAA/油/氨/水多流股。

**数值特性**：负值截断、DO₂ 下限 1、黏度下限；μ_x 在 pH/T 长期偏离时自适应衰减（培养龄 >65h 且 μ_x 持续下降时置为最小值）；控制器是**离散环节**（仅在采样点读上一步状态）→ 移植时须保持"采样-积分"两层结构。

**扰动与故障注入**（鲁棒性/门禁用）：7 路低通滤波随机扰动（μ_p/μ_x/c_s/c_oil/abc/PAA_c/Tcin/O₂in）；8 类故障（通气、背压、补料、碱液、冷却水、全故障、T 传感器、pH 传感器）。

**观测接口**：在线 T/pH/DO/尾气 O₂/CO₂/流量 + 离线化验（每 12h、滞后 4h：P/X/PAA/NH₃/黏度）→ 天然支撑软测量观测模型构造。

### 1.3 数据要点

## 2. 目标定义（S0 候选，**需用户确认**）

Workflow §S0：目标未签署前不开工。三档用途分级（决定组合栈走到哪层，§3.5）：

| 档位 | 目标 | 求解器形态 | 组合栈 |
|---|---|---|---|
| **A 仿真引擎（正问题）** | 给定操作条件/配方/扰动/故障 → 全状态轨迹 + 批次统计（产量/收获量）+ 诊断 | 机理 ODE 引擎（Python 移植） | 仅 L1 机理 |
| **B 软测量（逆问题）** | 从易监测量（尾气 O₂/CO₂、T、pH、DO、流量、离线化验）反推难监测量（X、S、P、PAA、OUR、μ_x/μ_p）± 置信区间 + 状态 | UKF/EnKF/MHE + 稳态碳平衡基线 | L1 + L2（残差有结构才加） |
| **C 寻优（反设计）** | 目标指标（产量/产率）下的操作条件寻优 | 仿真优化/RL（后期） | 需 A+B validated 后 |

**建议路线**：先 A（V0 必做）→ B（V0 后期起，可辨识性先行）→ C（V1+，另行批准）。

**成功标准草案（A 档）**：
1. 复现 V3 统计：正常批次最终产量分布偏差（RMSE 口径待定，±5% 初值）；
2. 轨迹级：关键状态（S/X/P/DO/T/pH）逐点偏差指标，对照 V3 同批次；
3. 守恒：C/N/O 元素平衡误差 < 已批准误差预算；
4. 多工况：故障注入批次可复现故障特征（通气/传感器类）；
5. 失败可见：滤波/积分发散、越有效域必须显式输出状态与原因（I2）。

**红线与 out-of-scope（草案）**：不接实产闭环；不放宽安全/操作窗口约束；不进行在线 RL 探索；实产数据再训练需另行授权；本项目无实产装置，故 HAZOP/联锁类硬约束以文献/规程为准（T1）。

## 3. 求解器架构草案

### 3.1 分层（对齐 Workflow §3.3 四层 + §3.5 组合栈）

```
应用层    SimuForge 看板：运行视图 / 评估视图 / 健康视图（growth-panel）
引擎层    工况寄存器（配方/初始条件/扰动种子/故障注入）· 物料能量闭合检查
          · 批处理 API：POST /v1/solvers/{id}/simulate 与 /estimate（ENGINE_CONTRACT.md）
求解层    L1 机理模型（33 维 ODE，Python 移植）
          L2 估计器/补偿（B 档：UKF/EnKF/MHE + 稳态碳平衡基线 + 回退链）
          L3 寻优（C 档，后期）
数据层    V3 流式解析 · 单位换算 · 时间戳对齐 · 质量标志 · 化验标签（采样时刻+滞后4h）
治理轨    知识账本 knowledge/ledger.jsonl · 证据账本 runs/ledger.jsonl
```

### 3.2 正问题求解器（A 档）设计要点

1. **物理量/变量两层表**：先冻结单位与符号约定（Workflow T-2.1 第 1 步），33 状态 + 105 参数逐项登记；
2. **刚性处理**：隐式求解器（LSODA/Radau/BDF）+ 事件（补料切换、氨补加、放罐）；步长策略与 MATLAB h_ode=0.01h 对照验证；
3. **数值守卫显式化**：负值截断、DO₂ 下限、黏度下限 → 输出为诊断字段而非静默兜底（I2）；
4. **单位/守恒强制**：输入校验（单位、符号、范围）；输出含守恒误差诊断（OUR/CER 与尾气平衡闭合、C/N 平衡）；
5. **随机性对齐**：扰动/故障注入的分布与 MATLAB 对齐（低通滤波白噪声）；rng 序列 → numpy default_rng 的映射登记为假设（T7）；
6. **控制器移植**：pH/T/DO 的 PIDSimple3（增量式）+ 配方进料，保持"采样-积分"两层结构；V0 另提供**开环回放模式**（从 V3 提取操作量直接回放）作为对照基线。

### 3.3 逆问题（B 档）设计要点

- 观测 y：尾气 O₂/CO₂（→OUR/CER）、T、pH、DO、Fs/Fg/RPM、离线化验（12h/滞后 4h）；
- 目标 x：X、S、P、PAA、OUR、μ_x/μ_p、菌丝区组成；
- **物理桥**：尾气平衡 → OUR → 化学计量 → μ；**可辨识性**（灵敏度秩/profile likelihood）为第一道闸门——无尾气观测时 μ 不可辨识，登记约束并输出 `unidentifiable`，不静默输出貌似合理的数（I2/I3）；
- 方法族：UKF/EnKF/MHE + 机理基线（稳态碳平衡）；回退链：滤波发散 → MHE → 稳态基线 → 显式失败；
- L2 准入：仅当残差有结构；PAA-PLS 资产可复用，但必须消融证明净贡献。

### 3.4 数据管道

- V3 流式解析 → 按批次落 HDF5；表头异常清洗规则登记（T7）；
- 化验时间戳一律用**采样时刻**，滞后 4h 登记（反模式清单第 2 条）；
- **黄金集**：保留 10 个正常批 + 2 个故障批作为回归基准，只增不减；调参与评估数据按批次切分，禁止在评估批次上调参。

### 3.5 版本与迭代纪律

- draft / candidate / stable 三区：`candidate/<solver>/<name>/<version>/` 只允许 draft/candidate 区写；
- 版本推进：candidate → backtest → promote（**人工发起**，§8.1①）；
- 完成判据：gate 的 metricsHash 写入 manifest 的 `gateEvidence.hash`，promote 返回 `to=stable/...` 后方可对外。
