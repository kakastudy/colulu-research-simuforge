# M2 方法选型 + 机理基线 + 回退链冻结

> 状态：draft（2026-10 会话）
> 关联：设计文档 §3.3 逆问题（B 档）

## 1. 方法选型

### 1.1 候选方法族

| 方法 | 优势 | 劣势 | 适用场景 |
|------|------|------|----------|
| **UKF** | 无需 Jacobian；对非线性 ODE 鲁棒；计算量适中 | 调参敏感（α/β/Q/R）；协方差可能发散 | 中等非线性、观测稀疏 |
| **EnKF** | 免调参（样本数控制）；天然并行；适合高维 | 需大量样本；协方差秩受限 | 高维状态、集合预测 |
| **MHE** | 滚动优化显式处理约束；可融合机理 | 计算量大；需 QP 求解器 | 约束密集、实时性要求低 |

### 1.2 选型结论

**主方法：UKF**（理由：33 维状态中等规模；ODE 强非线性但光滑；观测通道少（~10），UKF 的调参成本可接受）

**备选：EnKF**（当 UKF 协方差发散时启用，作为回退链第二环）

**约束处理：MHE**（当 EnKF 也发散时，降级为稳态碳平衡 + MHE 约束优化）

### 1.3 UKF 参数初值

- α = 1.0（缩放因子）
- β = 2.0（协方差权重）
- κ = 0（尺度参数）
- Q = diag(1e-3 × I₃₃)（过程噪声）
- R = diag(观测通道噪声方差)（量测噪声）
- P₀ = diag(1e-1 × I₃₃)（初始协方差）

### 1.4 可辨识性约束

可辨识性分析（`identifiability.py`）结论：
- **Tcin, c_oil 最敏感**（但 MATLAB 中固定为 285K / 1000 g/L）
- **mux, mup, alpha_kla** 敏感度中等
- **PAA_c, N_conc_paa** 敏感度低
- **无尾气观测时 μ_x/μ_p 不可辨识** → 输出 `unidentifiable` 标记，不静默输出貌似合理的数

## 2. 机理基线

### 2.1 基线模型

`candidate/indpensim/v0.1/model.py` 提供 33 维 ODE 机理模型：
- 状态：S, DO2, O2, P, V, Wt, pH_H, T, Q, vis, A_t1, A0-A4, mup, mux, n0-n9, nm, phi0, CO2, CO2d, PAA, NH3
- 参数：105 维向量（对齐 MATLAB `Parameter_list.m`）
- 输入：26 维 inp1（对齐 MATLAB `indpensim.m u00`）

### 2.2 守恒基线

`conservation.py` 提供元素平衡 + OUR/CER 尾气闭合：
- C 平衡：输入 C（底物 + 油）vs 输出 C（尾气 CO2 + 产物 P + 生物量 + 放罐）
- N 平衡：输入 N（NH3 + PAA）vs 输出 N（生物量 + 放罐）
- OUR/CER 闭合：尾气 O₂/CO₂ → OUR/CER → 化学计量 → μ

### 2.3 已知限制

- 崩溃是结构性 CO2d 级联，distTcin=+10 可绕过但引入生长率提高副作用
- 逐批校准可改善但无法完全复现 MATLAB 的 rng 随机扰动
- 守恒检验中 C 平衡误差 +58.7%（大部分 C 进入生物量/P，非 CO2）

## 3. 回退链冻结

### 3.1 回退链定义

```
UKF 收敛 (RMSE < 阈值)
  ↓ 否
EnKF (集合协方差)
  ↓ 否
MHE + 稳态碳平衡约束
  ↓ 否
显式失败标记 (unidentifiable / diverged)
```

### 3.2 回退判据

| 环节 | 判据 | 动作 |
|------|------|------|
| UKF | 协方差 trace > 10×P₀ | 降级到 EnKF |
| EnKF | 集合 spread → 0 | 降级到 MHE |
| MHE | QP 求解失败 / 残差无结构 | 降级到稳态基线 |
| 稳态基线 | C 平衡误差 > 20% | 显式失败 |

### 3.3 禁止行为

- 不得静默输出貌似合理的数（I2/I3）
- 不得在评估批次上调参
- 不得跳过可辨识性检查直接估计

## 4. 回退链实现计划

- Phase 1（M3）：UKF 骨架 + 协方差监控 + 降级触发
- Phase 2（M4）：EnKF 备选 + 稳态碳平衡基线
- Phase 3（M5+）：MHE 约束优化
