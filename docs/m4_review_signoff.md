## 三、`cap = L1 prototype` 的含义边界

### 3.1 允许对外表述

- "工业青霉素补料分批发酵的**机理仿真引擎原型**，可复现 86 批历史批次的最终产量（RMSE 2.35%，全部落在 ±5% 内）。"
- "含守恒核算（C/N 元素平衡）与故障分级输出，可用于**工艺侧假设检验与反事实推演**。"

### 3.2 明确不允许表述

| 禁止表述 | 原因 |
|---|---|
| "可交付验收 / 可用于放行决策" | 标准 2/4/5 仍 PARTIAL，L2 未开 |
| "轨迹级全通道达标" | X 幅度偏高 21%、DO₂ R² 0.584、S 未评估 |
| "故障可定量复现" | 幅值跨求解器散布 67 pt（R134 T5） |
| "置信区间可信" | I3 仅 3 批实测且 X 不达标 |
| 引用任何**具体崩溃数值**（如"b27 mup 0.03500 → −22.6%"） | 该值不可复现，已作废（R134 T5） |

## 五、签署后的强制约束（继承 R134）

1. **零回归闸门**：任何改动须过 `tools/r134_zero_regression.py --tol 0`（RMSE ≤3.5%、86/86、0 catastrophic、逐批差 0）。
2. **不硬凑**：C 类通道只登记、不调参（PAA 已按此处置）。
3. **数值可引用性**：混沌区（b27/b92 窄窗）只允许定性描述。
4. **台账一致**：结论必须落 `ENGINE_CONTRACT` + `state.yaml` + `runs/p3/*.json` 三处，缺一不算数。
