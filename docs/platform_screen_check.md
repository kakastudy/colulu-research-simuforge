## 三、复验中发现并修复的缺陷

| # | 缺陷 | 影响 | 修复 |
|---|---|---|---|
| 1 | 拓扑视图 **`补料` 盒与 `搅拌` 盒横向重叠 16px**，"补料流量"标签被盖住 | 信息不可读（属真实可用性缺陷，非审美） | `loopPos.feed` 214→**196**、`agit` 330→**356**（盒宽 132，中心距 ≥140 才不压字），复验截图确认已分离 |
| 2 | 平台页脚契约版本恒显示 **v1.59**（实际已 v1.61） | 对外口径与契约不一致 → "平台数字 vs 报告数字"分叉 | `export_data.py:contract_version()` 改为**扫描表体最大 `\| vX.YY \|` 行**（原实现只读标题行，而追加行从不改标题）；刷新后显示 v1.61 |
| 3 | 视图状态不进 URL | 无法直达/分享某屏，刷新回到总览 | `app.js` 增加 hash 路由（`#overview/#topology/#batch/#channels/#operators`），用 `replaceState` 不污染历史；手改 hash 也跟随 |

> 缺陷 3 是复验的"副产品"，但也是复验手段的前提：没有 hash 路由，无头浏览器无法逐屏截图，
> 只能截到总览——这正是 R133 只做了参数层验证的结构性原因。
