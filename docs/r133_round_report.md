## 一、出发问题

R132 S1.2 已证明"按 1/gain 强改 `vis_scale`"会让产量 within ±5% 从 86/86 崩到 63/86，
据此判定：黏度残差**不可独立修**，且被解释为"形状错误"（衰减支路 `t2=250h` > 批长 230h）。
R133 先复核这个解释是否成立。

## 二、证据链（先归因，再动手）

| 检验 | 证据 | 结论 |
|---|---|---|
| 残差是幅度还是形状 | `corr(nRMSE, \|相对偏差\|) = 0.975` | 残差主体是**幅度** |
| 实测衰减形状 | `r133_vis_shape.json`：观测峰后相对回落中位 **22.7%**（p25–p75 0.223–0.231） | 观测确实有回落 |
| 仿真衰减形状 | 同文件 b8：`decline_rel = 22.2%` | **形状已匹配**，非"缺衰减支路" |
| 改机理能否救 | `r133_vis_decay.json`：kd ∈ {0, 0.001, 0.002, 0.003}，产量容差 0.2pt 下 **n_accepted = 0** | 改衰亡率必然动产量 → 否 |

> 更正：R132 §4.5 把"末段饱和"读成形状问题；本例显示**形状对、标度偏**。
> 因此正确的最小改动是**测量链换算**，不是改 ODE。

## 三、方法：`VIS_OUT_SCALE` 测量链解耦

- 黏度状态量 `vis_state`（进入 `kla` 的 `a0^(1/3)`）保持不变；
- 新增批级比例系数 `VIS_OUT_SCALE[b]`，只作用于**上报通道** `vis = scale × vis_state`；
- 系数由逐批最小二乘反解（median 0.72，p5–p95 ≈ 0.65–0.98）。

因为 `kla`、OTR、生长、产量链都读 `vis_state`，所以**产量零回归**是结构保证，不是巧合。
