## 1. T2 元素平衡 C 口径复核（原 P1 头号缺口）

### 1.1 根因不是 `c_paa`，是 CER 的两次量纲错误

原代码（`conservation_metrics.py`）：

```python
CER = _trapz(t, CER_series)              # ∫CER dt
C_out = CER / 44.0 + ...                 # ← 两个错
```

实际数据（V3 批文件）：

- `CER` 是**体积速率 g/L/h**（b8 中位 1.53，区间 0.03–1.94，量级符合 40–60 mmol/L/h 的高密度发酵）；
- 罐体积 `V` 是 **8.5 万升**（工业罐，58,720 → 85,259 L），不是实验室罐。

于是：

| 错误 | 后果 |
|---|---|
| 漏乘 `V(t)` | 体积速率没换成总量速率，差 **~85,000 倍** |
| `/44` 当摩尔数 | CO₂ 质量误当物质的量；正确换算是 **×12/44** 折成碳质量 |

两项叠加，CO₂ 项从 ~6.6×10⁶ g 碳塌缩成 **~7 g** 碳，C_out 只剩 P 与 X 两项，于是系统性低估 60% 以上。

### 1.2 修正

```python
CER_g = _trapz(t, clip(CER, 0) * V)      # g CO₂（体积速率 × 罐体积）
C_co2 = CER_g * 12.0 / 44.0              # g C
C_out = C_co2 + C_prod + C_biom + C_sub_end
```

同时修掉一个**会在当前环境直接崩溃**的兼容性 bug：代码用了 `np.trapezoid`（numpy ≥2.0），
而本项目运行在 **numpy 1.26.4**（只有 `np.trapz`），已改为兼容取用。
并给 C 项加了 `C_in_split` / `C_out_split` 分项输出，便于后续逐项审计。

### 1.3 结果（`runs/element_balance_v2.json`，12 批）

| 元素 | 修正前中位 | 修正后中位 | 修正后范围 | 预算 | 通过 |
|---|---|---|---|---|---|
| **C** | −64.5%（0/12） | **−1.5%** | −20.1 ~ +7.4 | ±20% | **11/12** |
| N | −15.8%（10/12） | −15.8% | −61.9 ~ −8.0 | ±35% | 10/12（不变） |

- 修正后 CO₂ 占 C_out 的 **52.6–67.6%**，符合青霉素发酵碳流以呼吸为主的生理事实，可作交叉验证。
- 唯一未达标批 **b91**（C −20.1%、N −61.9%、RQ 2.23），与产量通道的 b91 异常同源，属**已知故障批**。
- `c_paa`（g/L 530）与 X 的 4h 对齐假设**经本次复核不构成主要误差源**，R134 计划里对它的怀疑可以撤销。

### 1.4 影响

`docs/m4_acceptance_package.md` 标准 3 由 **🟡 PARTIAL → 🟢 PASS**，"升 L2 前必须关闭"的第 1 项**关闭**。
产能（产量通道）未受任何影响——本项只动核算代码，不进 ODE。

## 2. T3 PAA_offline 归因（C 类 → 判"哪一侧"）

工具：`tools/r134_paa_attrib.py`，证据：`runs/p3/r134_paa_attrib.json`（86 批，复用平台缓存轨迹，不重新仿真）。

### 2.1 误差先分解，再判侧

R132 把 PAA 判 C 类的依据是"R²=0.378、lag=0.0h、形状本身错"。但 R² 同时混了**水平偏差**和**形状**，
不能回答"该改 ODE 还是改口径"。本轮按幅度/形状/波形三层拆开：

| 量 | 中位 | 含义 |
|---|---|---|
| nRMSE | 29.1% | 总误差 |
| gain（k·sim ≈ off） | 0.92 | 幅度只差 8% |
| **水平（常偏置）** | **−3.4%** | 几乎无系统性偏置 |
| **波形（箱均值 std）** | **22.8%** | 结构性成分，占 RMS 的 **97%** |
| ρ(残差, \|dPAA/dt\|) | 0.07 | 与摄取速率无关 |

→ **不是标度问题、也不是测量口径偏移，是形状本身错**，R132 的 C 类判定方向正确，
但"形状错"可以进一步定位到**具体时段**：

### 2.2 残差轮廓（86 批中位，gain 校正后，% of mean）

```
 0h +2   12h −12   24h −10   36h  +1   48h +32   60h +36   72h +24
84h +19   96h  +8  108h  +1  120h  −4  132h −11  144h −21  156h −12
168h −13 180h −17 192h −20  204h −17  216h −14  228h −17
```

可读成一句话：**模型在峰后回弹过头（48–72h 高估 32–36%），中期平台撑不住、后期又掉得太狠（132–230h 低估 13–21%）**。
化验侧的真实形态是"48h 见谷 → 回到 ~1000 mg/L 平台 → 后期升到 1400"，模型则"见谷更早更浅 → 冲高 → 单调衰减"。

### 2.3 判侧结果

| 判侧 | 批数 | 判据 |
|---|---|---|
| **generation（生成侧结构）** | **76 / 86** | 波形 std ≥8% 且波形占 RMS ≥60% |
| scale_only（仅幅度） | 10 / 86 | gain 校正后残差 ≤12%（这 10 批本身 nRMSE 已 ≤12%） |
| measurement（测量侧） | 0 / 86 | — |

补充证据：中段/晚期形状残差几乎等量（早期 20.0% / 中期 23.8% / 晚期 22.5%），
说明**不是"缺一个起始爆发"，而是整条 PAA 平衡的形状都不对**；
86/86 批"化验与模型都有谷"，所以"谷的有无"不能用来判侧（首版判据曾据此误判）。

### 2.4 处置

**不改、不拟合**。PAA 的问题需要 V1+ 在 PAA 平衡上补机制（正解方向：中期维持平台 / 后期供给偏少的矛盾），
不属于 M4 范围内可修项。已在 M4 证据包记为"升级前可接受遗留"。

## 3. T4 OUR 从属验证（B 类 → 是否可单独处置）

工具：`tools/r134_our_subordinate.py`，证据：`runs/p3/r134_our_subordinate.json`（86 批）。

三个预先登记的检验（定义 `obs ≈ k·sim`，k<1 表示模型偏高）：

| 检验 | 结果 | 解释 |
|---|---|---|
| H1 跨批同源：corr(k_OUR, k_X) | **0.854** | 高相关，同源成立 |
| 回归斜率 dk_OUR/dk_X | **1.44** | 边际敏感度：X 偏 1 分，OUR 偏 1.44 分 |
| 中位 k_OUR / k_X | 0.771 / 0.845 | OUR 比 X 再多偏约 **8%** |
| H2 幅度继承：用 k_X 校正 OUR 后 nRMSE 改善 | **39.4%**（40/86 批 ≥40%） | 只能解释约四成误差 |
| H3 结构派生：OUR 由 [dX/dt, X] 线性重建 R² | sim **0.85** / obs **0.76** | OUR 在模型内基本是 X 的泛函 |

**结论：【partial】从属但带放大。**

- OUR 的误差**大部分与 X 同源**（corr 0.85、可由 X 重建 R² 0.85），所以**单独给 OUR 扫参在数学上不成立**（计划 §7.1 的判断成立）；
- 但 X 幅度只解释 39% 误差，且存在 1.44 的边际放大 → **不能指望"X 修好后 OUR 自动达标"**；
- 正确顺序：**X 收敛 → 复评 OUR → 若仍超标，再查氧传递链路（kla / DO2 / 尾气）**，而不是回头扫 OUR 参数。

## 4. T5 b27/b92 分岔真伪（两个问题必须分开）

工具：`tools/r134_bifurcation.py`，证据：`runs/p3/r134_bifurcation.json`（80 次仿真）。
配置：BDF@1e-3（生产默认）/ BDF@1e-6 / Radau@1e-8 / LSODA@1e-8。

### 4.1 先做方法自检

b27 在基线 `mup=0.03515` 上，四种求解器产量：

| 配置 | 产量 (g) | yield_err |
|---|---|---|
| BDF@1e-3 | 3,183,163.4 | +4.770% |
| BDF@1e-6 | 3,183,152.4 | +4.770% |
| Radau@1e-8 | 3,183,159.1 | +4.770% |
| LSODA@1e-8 | 3,183,158.7 | +4.770% |

散布 **0.0003%** → 可行区内解是收敛的，**不是"整体没算准"**。
b8 对照全网格跨求解器散布 **0.001 pt**，说明本测法本身不产生假散布。

### 4.2 两个问题

**Q1：加密求解器会不会让可行窗变宽？**（决定 `narrow` 标签去留）

| 批 | BDF@1e-3 | BDF@1e-6 | Radau@1e-8 | LSODA@1e-8 |
|---|---|---|---|---|
| b27 | 1.5e-4 | 1.5e-4 | 1.5e-4 | 1.5e-4 |
| b92 | 1.0e-4 | 0.0 | 0.0 | 1.0e-4 |
| b8（对照） | 2.0e-3 | 2.0e-3 | 2.0e-3 | 2.0e-3 |

→ **没有一处变宽**。b27 的可行 mup 区间恒为 `0.03505–0.03520`（误差 +4.50% ~ +4.90%），
b92 恒在 0–1e-4 量级，b8 恒为 2e-3（比 b27 宽 13 倍）。
**"窄窗"是真实的模型性质，不是积分假象。**

**Q2：阈值之外的跌落幅度可复现吗？**（决定能否引用具体数值）

| b27 mup | BDF@1e-3 | BDF@1e-6 | Radau@1e-8 | LSODA@1e-8 | 散布 |
|---|---|---|---|---|---|
| 0.03500 | −22.57% | −6.64% | **−73.73%** | −21.99% | **67.1 pt** |
| 0.03490 | −20.64% | −7.90% | −73.79% | −25.92% | 65.9 pt |
| 0.03505 | +4.51% | +4.50% | +4.50% | +4.50% | 0.000 pt |

→ 阈值**以上**四解一致到 0.001 pt；阈值**以下**同一 mup 能给出 −6.6% 到 −73.7% 的任何值。

### 4.3 结论与需要纠正的历史表述

**「阈值真实、跌落幅度不可复现」**。两个直接后果：

1. `narrow` 标签**保留**，b27/b92 继续"可评估不可控制"、不作 M5 控制基线（与原结论一致，但理由更硬）；
2. **R131/R132 报告里"b27 0.03500 → −22.6%"这类具体数值不能再引用**——它只是 BDF@1e-3 在混沌区的一次抽样。
   正确表述是："b27 的可行 mup 窗宽仅 1.5e-4，窗外观测到产量崩塌，但崩塌深度依赖积分器，不可量化。"

附带发现：b92 在 `mup=0.03950/0.03960` 处 **Radau 直接积分失败**（无解），
说明该批在这些参数点上条件数极差。这对 M4 标准 4（b92 pH 故障"必崩"）是一个警示：
**"必崩"的幅度同样不可引用**，重标定故障时只能标定方向与阈值，不能标定深度。
