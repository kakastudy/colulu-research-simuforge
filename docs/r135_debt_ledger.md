## D-1　I3 置信区间覆盖率（严格版）

| 项 | 内容 |
|---|---|
| **现状** | 有实测的只有 **3 批**（b11/b16/b60），非计划中的 12 批 |
| **合并覆盖率**（Wilson 95% CI，n=54） | **X：0.630 [0.496, 0.746]** ❌　**P：0.944 [0.849, 0.981]** ✅　**PAA：0.889 [0.778, 0.948]** 🟡 |
| **判定** | **I3 未达标**。X 的区间上界 0.746 < 名义 0.95 → 集合平滑器对生物量的后验带**系统性偏窄**（不是抽样波动） |
| **证据** | `runs/hier_est/esmooth_{11,16,60}_p4gate.json`（每批 n=16–19 个化验点） |
| **为什么不强推 12 批** | 单批成本 ≈ 2.5 min 快校准 + `n_ens×8 s`（n_ens=30 时 ≈ 4 min），12 批 ≈ 1.5–2 h，且**结论方向已定**（X 不达标），扩样只会把 CI 收窄、不会翻盘 |
| **触发条件** | 一旦 X 幅度问题（D-3 关联的 gain 1.211）进入修复，须重跑全部 12 批——覆盖率是对"修好后的 X"才真正有意义的指标 |
| **归属** | V1+（PH3-m2） |

> 备注：M4 证据包里"覆盖率 0.629"即本表 X 通道的合并值 0.630，**不是**三通道平均。
> 这个歧义已在 `docs/m4_review_signoff.md` 里按"仅 3 批实测且 X 不达标"记账。

## D-2　DL σ̂（数据受限的可辨识性估计）

| 项 | 内容 |
|---|---|
| **现状** | 网格后验显示 `var_w ≫ var_between`（批内噪声远大于批间方差）→ 总体方差估计 **σ_pop → 0**，层级模型退化 |
| **判定** | **不可辨识，记为已知限制**。不是"还没算"，是"用当前数据算不出来" |
| **含义** | 不能对外宣称"批间参数有统计显著的分布"；逐批参数是**点估计**，不含群体先验 |
| **为什么不强推** | σ_pop=0 时任何 MCMC 都会在边界堆积，跑出来的"后验"是伪精度——这比不给更糟 |
| **触发条件** | 需要更多**同配方重复批**（若 V3 中有重复运行批次，可先做批次聚类再谈层级模型） |
| **归属** | V1+ / 数据侧 |

## D-3　产量红线余量（新发现，优先级最高）

86 批全部达标（RMSE 2.345%、86/86 within ±5%），但**余量分布极不均匀**：

| 批 | 产量误差 | 距 5% 红线余量 |
|---|---|---|
| b59 | +4.829% | **0.171 pt** |
| b58 | −4.814% | **0.186 pt** |
| b27 | +4.770% | **0.230 pt** |
| b5 | −4.763% | **0.237 pt** |
| b83 | +4.757% | **0.243 pt** |

| 项 | 内容 |
|---|---|
| **判定** | "86/86 达标"成立，但**5 批余量 < 0.25 pt**。任何再标定 / 参数微动都可能把其中一批推出红线 → 每次改动必须跑全量闸门，不能只看 RMSE |
| **证据** | `runs/p3/r135_golden86.json` |
| **为什么不强推** | 把余量"做宽"意味着为这 5 批单独调参，属拆东墙补西墙；且 b27 已在分岔窄窗内（见 D-4），**越调越危险** |
| **触发条件** | 若某轮改动使最紧余量 < 0.10 pt，立即回滚并复核 |
| **归属** | 常驻约束（已写入 `tools/r134_zero_regression.py` 的判据） |
