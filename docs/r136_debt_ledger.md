## D-2　DL σ̂（数据受限的可辨识性估计）

| 项 | 内容 |
|---|---|
| **现状** | 网格后验 `var_w ≫ var_between` → 总体方差 σ_pop → 0，层级模型退化 |
| **判定** | **不可辨识，记为已知限制**（不是"还没算"，是"用当前数据算不出来"） |
| **含义** | 不得对外宣称"批间参数有统计显著的分布"；逐批参数是点估计，不含群体先验 |
| **为什么不强推** | σ_pop=0 时任何 MCMC 都在边界堆积，跑出来的"后验"是伪精度 |
| **触发条件** | 需要更多同配方重复批 |
| **归属** | V1+ / 数据侧 |

| 项 | 内容 |
|---|---|

## D-5　X 幅度（新，最高优先级）——**parametric-infeasible**

| 项 | 内容 |
|---|---|
| **现状** | `X_offline` nRMSE 24.6%、R²0.931；分段 sim/lab 比值 1.046→1.079→1.183→**1.356**（单调爬升）；峰值比 1.244、峰后跌幅 化验 −12.8% vs 模型 −0.7% |
| **判定** | 误差是**累积漂移**（峰高 +24%、尾段 +36%），不是整体标度。五类单参数杠杆（late_death / Y_sX / m_s / Y_sP / 组合）在 12 批次 / 72 个反事实配置里（8 批×6 + 4 批×6）**全部把产量推出 ±5%**，兑换率中位 ≈ 1:1（pt/pt），最差 1:4.8 |
| **为什么不强推** | 产量余量总共 4.8 pt，而把 X 拉回 15 pt 要付 6–60 pt 产量——预算差一个量级。这不是标定精度问题，是模型结构不能同时表达"低菌 + 高产素" |
| **证据** | `runs/p3/r136_x_s_channel.json`(A)、`r136_xaxis_probe.json`、`r136_decouple_probe.json` |
| **触发条件 / 出路** | 只接受**结构改型**：① D-6 的形态学退化链；② 菌体/产物的独立碳通道（死菌池不产素、弱呼吸） |
| **归属** | V1+（结构） |

## D-6　形态学退化链 `a1→a3→a4` 从未激活（新）

| 项 | 内容 |
|---|---|
| **现状** | 抽查 b56 全时程（0/23/69/115/161/207/228 h）：`a0≈0.18–0.29 / a1≈0.71–0.82 / a3=a4=0.000`，**`debris(a3+a4)/X` 恒为 0.000** |
| **含义** | `r_vac`（a1→a3）与 `r_d4`（a3→a4）两条退化分支全程未启动。原 IndPenSim 里这两条链在生产期是会启动的 |
| **为什么重要** | 这是唯一"**降 X 而不动 P**"的通道：死菌丝不产素、维持呼吸也弱，可同时压 X 尾段与 OUR，而不像衰亡那样把产素期一起削掉 |
| **判定** | **疑似装配/门控缺陷，而非参数问题**（参数扫不出"分支恒零"这种形态）。待 R137 诊断：查 `r_vac`/`r_d4` 的输入项（`mu_vac_ref`、`k_vac`、形态学占比门控）是否被默认值钉死 |
| **证据** | `tools/r136_xaxis_probe.py` 的运行期抽查（未落盘，R137 补 `runs/p3/r137_a3a4_probe.json`） |
| **归属** | R137 P0 |
