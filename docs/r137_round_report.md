## 1. T1 形态学链：从"可疑"到"确诊装配缺陷"

### 1.1 参数层证据

```
86/86 批黄金参数中，k_vac 从未出现 → params.get("k_vac", 0.0) 取默认 0
⇒ r_vac = k_vac · a1 · gate ≡ 0
⇒ a3 ≡ 0 ⇒ r_d4 = mu_a · a3 ≡ 0 ⇒ a4 ≡ 0
```

`mu_a = par[6] = 3.5e-3`（非零，τ≈286 h），所以**只要 a3 有量，a4 就会跟上**。断点只在 `k_vac`。

`model.py:355-360` 的注释写着"R130: 液泡化修复 —— A1→A3 转移 r_vac（原 n_k=0 近似恒为 0，
A3/A4 永远为 0）"，但**修复只加了代码路径，没有把参数接进黄金集**。这是典型的"改了引擎没改参数"。

### 1.2 第二个结构缺陷：kd 等比衰减

```python
_kd_active = biomass_death_rate if t >= death_start else 0.0
_late_kd   = late_death_rate * _late_death_gate
da_0_dt = r_b0 - r_d1 - ... - _kd_active*y[11] - _late_kd*y[11]
da_1_dt = ...                - _kd_active*y[12] - _late_kd*y[12]
da_3_dt = r_vac - r_d4 - ... - _kd_active*y[13] - _late_kd*y[13]
da_4_dt = r_d4 - ...         - _kd_active*y[14] - _late_kd*y[14]
```

对 **a0/a1/a3/a4 四组分等比扣减**。形态学分区的意义（死菌才该被移除）被完全抹掉，
"只移除死菌、保留活菌"在现有实现下**无法表达**。

### 1.3 但修复它无收益（反事实，`runs/p3/r137_morphology_probe.json`）

| 配置 | debris 末 | yield 中位 | X nRMSE 中位 | peakR 中位 |
|---|---|---|---|---|
| base | 0.0000 | +2.48% | 14.6 | 1.093 |
| kv001 (`k_vac`=0.001) | 0.0852 | **−19.34%** | 16.2 | 1.106 |
| kv003 | 0.2467 | **−56.47%** | 21.4 | 1.134 |
| kv01 | 0.6130 | **−90.22%** | 21.8 | 1.034 |

**机制解释（关键）**：
`r_vac` 是 **A1→A3 的内部转移**，`da_3_dt = r_vac − r_d4`、`da_4_dt = r_d4`，
`X_1 = Σ da_* = r_e1 − 稀释 − kd`——转移项在求和中**完全抵消**。
而产素 `r_p = μp·ρa0·v_a1·...`，`v_a1 ∝ a1`。

> **产素对 a1 是一阶敏感，总生物量对 a1 是二阶敏感**（需经 a1→a0 分枝链才反映到 r_e1）。
> 所以抽干 a1 会先摧毁产量、再慢慢影响 X。这是死结，不是参数没调好。

`k_vac=0.001` 时 debris 才 8.5%，产量已 −19.3%（4/4 破线），而 peakR 反而从 1.093 升到 1.106。

### 1.4 "X_offline 测活菌"假设被否证

若化验只测活菌，则 `X_active = a0+a1` 应比 `X_total` 更接近化验。实测：

| 批 | base `X_nRMSE` | kv005 `Xact_nRMSE` | 方向 |
|---|---|---|---|
| b8（base 准） | 4.9 | 27.0 | 恶化 |
| b27（base 准） | 8.2 | 51.5 | 恶化 |
| b56（base 差） | 40.9 | 8.4 | 改善 |
| b59（base 差） | 20.9 | 6.7 | 改善 |

`Xact` 的"改善"**只出现在 base 高估的批**，在 base 已准的批剧烈恶化——这是"把 X 整体往下拉"
的削足适履，不是揭示真值。**viability 假设否定**。

### 1.5 结论

D-6 的表述需要撤回两处：
- ❌ "唯一不动产量就能降 X 的通道" → ✅ "纯转移，对 X 无一阶效应、对 P 有一阶副作用"
- ❌ "R130 已修复液泡化" → ✅ "R130 加了代码路径但未接线，86/86 批 `k_vac`≡0"

## 5. T5 为什么产量会往上跑：一个必须记下的"错误的正確"

修复 X 后产量中位从 −0.07% 升到 **+4.25%**，与直觉（少菌应少产）相反。机制：

1. `dS_dt` 里没有回流项（`death_recycle=0`），所以衰亡不补底物；
2. 但 **base 的 S 在 t>200 异常积累**（b56：0.0017 → 3.36 g/L），S 高抑制产素 → P 从 30.4 掉到 25.5；
3. kd=0.005 的菌少、耗底物少……**但实测 S 反而更低**（0.0007）；
4. 结果 kd 版的 P 继续涨到 32.8，破了化验（25.18）。

**第 3 步是目前没解释清的异常**（X 少应耗得少、S 应更高）。已确认**不是数值伪影**：
`rtol` 从 1e-3 收到 1e-5，`S_max(t>195)` = 4.168 / 4.167 / 4.167，`P_end` 恒 25.221，
yield 恒 +0.195%。⇒ 是模型真实动力学（疑似 S 高抑制生长 → 消耗停 → S 更高的正反馈分支）。

**而化验 P 也在晚期下降**（b56：t=204 峰 29.938 → t=230 的 25.184，−16%），
与化验 S 逃逸（0.0019 → 19.76 g/L，t>201 起）同时发生。

> ⇒ **base 的产量精度，部分依赖"S 逃逸→P 下降"这个机制的幅度不足但方向正确**。
> 修 X 时若把这个机制一起抹掉（kd 让 S 不逃逸），产量就会偏正。
> **所以 X 修复与 P 对齐不能分开做。**

## 6. T6 异质多因：X 高不是一件事

| 类别 | 代表 | 化验 S 晚期 | 机制 |
|---|---|---|---|
| A：摄取在、生长停 | b29（S_lab 0.0025） | 不逃逸 | 代谢活性下降，底物仍被消耗但不用于生长 |
| B：摄取停、S 逃逸 | b56（S_lab 19.76） | 逃逸 | 菌停止摄取，补料在罐内积累 |

S 逃逸幅度与 X nRMSE 相关 **−0.007**（无相关）⇒ **不是单一原因**。
这解释了为什么单一机制修不好所有批，也解释了 28/45 的分裂。

### 6.1 修正 R136 对 S 通道的判定

R136 判 S 通道 `insensitive`（补料期绝对误差 6 mg/L），依据是**只看 t<195**。
但 t>200 的 S 逃逸段（化验 19.76 vs 模型 3.36）绝对值差 **16 g/L**——
比补料期大 2700 倍。**S 通道不是没信息，是信息集中在末段**。

R136 的判定应修正为：`S: insensitive in [0,195]h, informative in [195,末]`。
"不能作独立约束通道"的结论**保留**（末段只有 1–3 个化验点），但"无信息量"的措辞要撤回。

## 8. R138 建议（P0）

**逐批定标 `death_start`/`kd`，用 OUR 通道作判据，不用产量标签。**

1. 对每批，从 `OUR_lab(t)` 拟合晚期衰减率 `k_our`（t>峰后，在线连续，无滞后）；
2. 令 `kd_i = k_our × α`，`death_start_i` = 化验 X 峰值时刻 − 一个滞后常数；
3. 先在 28 个 `both_ok` 批上验证 `kd_i` 的估计精度，再扩到 86 批；
4. 若某批估计出的 `kd_i` 使产量越线，则**该批改用 A 类机制**（晚期摄取关闭而非衰亡）——
   这正是 T6 的分类。

**风险**：`death_start` 依赖化验峰值时刻，而 X_offline 只有 ~21 点（12h 间隔），峰值定位误差 ±6h。
OUR 是 0.2h 采样，可以从 `dOUR/dt = 0` 精确定位代谢峰，作为 `death_start` 的代理。

**若 R138 仍不能同时满足 X 与产量**，则应当承认：**X 通道在当前模型结构下不可修复**，
并把 GOAL §4 的轨迹条款降级为 PARTIAL 的正式表述（M4 已判 3 项 PARTIAL，此处是第 4 项）。
