## 0. 用户授权与范式切换

本轮起始指令：**"不要执着于复现，可以尝试检索其他方法或者使用创新方法来解决问题"**。

这句话直接改变了问题定位。R134–R137 一直在 **A 档（正问题）** 里改 ODE 结构、调动力学常数，
结论是 X 通道 `parametric-infeasible`。但回头看 **GOAL.md §3**：

```
B 软测量（逆问题）——L1 验证后入场（UKF/EnKF/MHE + 稳态碳平衡基线）
```

且 §8 确认记录写明用户已确认 **A+B+C 全量（分阶段推进）**。也就是说，X 轨迹的达标路径
本来就不该是在 A 档里硬拍参数，而是走 B 档。R134–R137 的困境，本质是在错误的档位上
找解。

本轮检索工业发酵监测的既有方法（元素平衡软测量、渐进观测器 Bastin & Dochain、混合
观测器、MHE），并逐条在本对象上实测其可行性。**六条路探明，五条失败，一条成功。**

## 1. 探明的路径与结论

| # | 路径 | 依据 | 结论 |
|---|---|---|---|
| 1 | 碳平衡累积反演 X | 元素平衡软测量（文献 X 占比大时 NRMSE 5–10%） | ❌ **分辨率不足** |
| 2 | 氮平衡反演 X | X 占 N 通量 85%（远优于 C 的 14%） | ❌ **N 不守恒** |
| 3 | 氧化学计量递推 X | `OUR = Y_O2_X·dX/dt + m_O2·X + ...` | ❌ **模型内部与导出量差 3 倍** |
| 4 | 全局 P 降解项 | 44 批 k_deg 一致（半衰期 114h） | ❌ **全局加有害** |
| 5 | 逐批 `death_start` | 用每批 X 峰值时刻作门控 | ❌ **不比全局 144 好** |
| 6 | qO2 形状先验软测量 | qO2 归一化形状跨批 CV 5–17% | ⚠️ **15.6%（LOBO），可用但不够** |
| 7 | **OUR 比值观测器** | 输出误差反馈 / 数据同化 | ✅ **5.69%** |

### 1.1 碳平衡：X 只占碳通量的 14%

b8 实测碳收支（gC）：进料 8.902e6、呼吸 6.588e6（**74%**）、移除 0.769e6、产物 1.577e6
→ **留给 X 的份额 ≈ 0**。这不是算错，而是对象的物理性质：230h 长周期发酵里维持能主导，
呼吸吃掉绝大部分碳，X 的碳只占 14%。

对比文献（Wechselberger 等在 E. coli 上做到 5.3% NRMSE），那是短周期、高生长率、
X 占碳通量大头的工况。**同方法在青霉素长周期上，呼吸项的 5% 误差就足以让 X 反演偏 25%。**

附带确证：`Fremoved` 是**脉冲放料**（累计 48000 L，占罐容 56%，IndPenSim 的细胞回收设计），
体积平衡可闭合（进 94345 − 放 48000 − 蒸发 25591 ≈ ΔV +20754）。

### 1.2 氮平衡：X 占比高，但 N 不守恒

N 通道的杠杆确实强得多：**X 占 N 通量 85%**（vs C 的 14%）。但 N 平衡残差 −41.8%。

追下去确认 `N_conc_paa = 2*75000 = 150000 mg/L` **是 MATLAB 原值**（`indpensim_run.m:136`），
不是常数写错——而是 PAA 过量供给，多余 N 留在罐内或随排液流失。**N 在模型里不参与守恒约束，
这条通道从根上不闭合。**

### 1.3 氧平衡：模型自身不一致

内部 OUR（`model.py:441`）：`OUR = -X_1·Y_O2_X - m_O2_X·X_t - dP_dt·Y_O2_P`
在 b8 t=100h 处算得 0.52 g/L/h，而导出通道 `sim['OUR']` 记录 1.57 g/L/h，**差 3 倍**。
且 `Y_O2_X/Y_O2_P/m_O2_X` 是**逐批随机参数**（b8 覆盖成 800/200/15，默认 650/160/17.5），
不能当全局常数。此路不通，但也说明：**导出 OUR 与化验 OUR 同口径**，可作为观测器的量测源。

### 1.4 P 降解：一个被 44 批钉死的真实过程，但不能全局加

化验证据非常强：44 批可估的降解率 **k_deg = 0.00607 /h**，IQR 仅 0.00568–0.00621
（跨批变异 <9%）；100 批中 53 批存在峰后下降，40 批降幅 >8%。而模型 P 方程
`dy[3] = r_p - y[3]·dilution/y[4]` **只增不减**（b8/b87/b27/b16/b80 的 sim P 峰值 = 末值）。

**但这里踩了一个口径坑**：我最初拟合的 0.00607 混入了稀释项。实测稀释率
`D = (Fs+Fb+Fa+Fw+Fpaa)/V ≈ 0.0034–0.0050 /h`，所以真实水解率只有 **~0.0017 /h**。
（与 R136 那次 yield 分数/百分数混淆同类：**拟合任何"率"之前先确认分母里有没有别的损耗通道**。）

即使修正量级，**全局加降解仍是单向恶化**：b8（化验 P 单调涨到 34.50）从 −4.04% 掉到
−15.28%；b29 从 −3.43% 掉到 −22.24%。原因：b8/b29 晚期 r_p 仍 >0（菌还在产素），
而 b56 的下降已被 base 的"S 逃逸→抑制产素"处理得很好（Pend 25.22 vs 化验 25.18）。

**这是 D-10 的进一步坐实**：X 与 P 是通过一个**因果倒置**的机制耦合的。

### 1.5 逐批 `death_start`：不比全局好

用每批自己的化验 X 峰值时刻作 `death_start`（看似更"物理"），实测**并不优于全局 144**：

| 批 | 峰值时刻 | base yield / XnRMSE | 全局144 | 逐批峰值 |
|---|---|---|---|---|
| b8 | 156 | −4.04% / 4.9 | −3.69% / 5.1 | **−3.48% / 4.1** |
| b29 | 156 | −3.43% / 42.0 | **+2.48% / 16.1** | +2.37% / 17.9 |
| b56 | 156 | +0.19% / 40.9 | **+19.84% / 22.4** | +22.40% / 24.4 |
| b59 | 132 | +4.83% / 20.9 | **−1.73% / 14.1** | −27.32% / 12.6 |

b59 尤其说明问题：峰值在 132h，提前启动衰亡让产量从 +4.83% 崩到 **−27.32%**。
"峰值时刻"不是"老化开始时刻"，两者不能划等号。

### 1.6 qO2 形状先验：15.6% 是可观测性地板

把 qO2 = OUR/X 按 t=48h 归一化后，**形状在 100 批间高度一致**（t=36–156 的 CV 仅 5%–17%），
可分解为 `qO2(t) ≈ k_batch·φ(t)`。用留一批交叉验证（目标批只用一个早期锚点，其余全靠在线 OUR）：
**X nRMSE 中位 15.6%**（锚点 24/36/48/72 均 15.6–16.2%，不敏感）。

但这个 15.6% 是**地板**而非可改进的余量：φ 在晚期的跨批 CV 达 25–32%，
因为"菌何时停产"逐批不同。b56 实测：其自身 qO2 衰减比全局 φ 更陡（0.447 vs 0.567），
导致中期高估 27.9 vs 24.2、晚期低估 18 vs 24。

## 2. 成功的路径：OUR 比值观测器

### 2.1 形式

```
X_est(t) = X_model(t) · [ median₅( OUR_meas(t) / OUR_model(t) ) ] ^ α ,   α = 0.60
```

### 2.2 为什么这个形式

模型给出 `OUR_model` 与 `X_model`，二者通过呼吸化学计量耦合。实测模型 OUR 对 X 的
**弹性 β ≈ 1/α ≈ 1.67**（即 `OUR ∝ X^1.67`），所以用"实测/模型 OUR 之比"反演 X 时，
指数应取 `1/β ≈ 0.6`，而不是 1。

这也解释了 α 的敏感性曲线的形状：

| α | X nRMSE 中位 | p90 | <15% 批数 |
|---|---|---|---|
| 0（原模型） | 23.99% | 34.98% | 16/86 |
| 0.5 | 6.82% | 12.86% | 79/86 |
| **0.6** | **5.69%** | **12.74%** | **79/86** |
| 0.8 | 10.5% | 16.6% | 70/86 |
| 1.0（全信 OUR） | 17.16% | 24.00% | 23/86 |

α=1 会过冲（完全信任带噪 OUR），α=0 退化为原模型，**0.6 是两者的最优折中**——
这正是输出误差观测器里增益 K 的物理来源。

`median₅` 是对观测比值做 5 点滚动中位：OUR 是尾气导出的在线量，5 min 采样但含尖峰，
不抑制会把校正放大成过冲（实测：不抑制 7.65%，抑制后 5.69%）。

### 2.3 与 15.6% 的差别在哪

qO2 软测量（1.6 节）是**从零重建** X，必须自己承担"绝对标度"的不确定性；
观测器是**在模型解上做校正**，模型的生长期动力学（本来就是准的）被完整保留，
只修正模型在晚期的系统性漂移。**用模型的强项，补模型的弱项。**

### 3.3 置信区间与覆盖率（GOAL §4.5 / I3）

用交叉验证残差的经验分位构造 90% 区间（不做正态假设，因残差重尾）：

- 区间：**[−9.72%, +16.40%]**（相对批均值）

### 3.4 不改动 A 档

观测器是**后处理输出**，不进入 ODE 积分：A 档仍独立输出 P 与产量
（RMSE 2.345%、86/86 within ±5%、0 catastrophic），一行未动。零回归闸门
`--tol 0` 复核：**86 批 max|Δ| = 0.00e+00**。

这正是 GOAL §3 的 A/B 分工：A 档负责正问题（产量），B 档负责逆问题（状态估计）。

## 4. 失效模式与边界（必须写明）

### 4.1 4 批残余失效（nRMSE > 20%）

| 批 | 模型 nRMSE | 观测 nRMSE | ratio 中位 | endR |
|---|---|---|---|---|
| b36 | 11.6 | **42.5** | **1.561** | 1.178 |
| b50 | 5.9 | 28.4 | 0.989 | **1.550** |
| b91 | 19.7 | 28.3 | 0.796 | 1.447 |
| b92 | 8.7 | 22.9 | 1.057 | 1.605 |

### 4.2 根本局限：ratio 偏离 1 的可辨识性

`OUR_meas/OUR_model` 中位 **0.808**，77/86 批 <1 —— 即模型 OUR 系统性偏高约 23.7%
（与 R136 的 "OUR 放大 1.242×" 一致）。

**但 ratio 偏离 1 有两种来源，观测器无法区分**：
- 模型 X 错了（该校正）—— 多数批
- 模型 **OUR 标度**错了而 X 是对的（不该校正）—— b36 即此类，`ratio=1.56` 直接把本来 11.6%
  的批放大成 42.5%

这是方法的**可辨识性硬边界**，不是实现缺陷。工程上的处理是给观测器配一个"信任度"输出，
在 ratio 长期显著偏离时降权并显式报警（对应 GOAL §4.5 "失败可见"），而非强行校正。

### 4.3 尝试过的门控未奏效（诚实记录）

最初设想用 ratio 的时间稳定性（CV）作可靠性判据，实测**不成立**：
`gain vs ratio_CV` 相关仅 +0.421，而 `gain vs 模型nRMSE` 相关 **+0.902** ——后者只是
"本来越差、改善越大"的回归均值效应。按 CV 分档反而显示 CV 小的批更容易出现轻微负增益
（因为它们 ratio≈1、几乎没有校正，微小误差即记为"改坏"）。

**结论：可靠性门控需要基于 ratio 的绝对水平与趋势，而非其稳定性；本轮未找到干净判据，
留作 R139。**
