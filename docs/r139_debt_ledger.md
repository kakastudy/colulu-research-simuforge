## 一、本轮关闭

### D-11　观测比值的可辨识性边界（R138 立）→ **已闭（判据已找到，机制已重写）**

| 项 | 内容 |
|---|---|
| 原判定 | `OUR_meas/OUR_model` 偏离 1 分不清"X 错"还是"OUR 标度错"，二者框架内不可区分 |
| **R139 闭合方式** | **引入第二通道 CER 后就不再需要在单通道内区分**——两通道对 X 的响应应当一致：<br>`r_CER/r_OUR = RQ_meas/RQ_model`，与 X 无关。偏离即标度问题。 |
| 定量裁决 | `log r_CER ~ log(X_lab/X_model)` 斜率 **1.005**（R² 0.699）vs `r_OUR` 斜率 **1.420**（R² 0.433）<br>⇒ **CER 是 X 的无偏代理，OUR 不是**。 |
| 残留 | b36 仍是唯一需要门控的批（§D-18），但不再是"不可区分"，而是"可识别为通道标度异常"。 |

### D-12　可靠性门控未找到干净判据（R138 立）→ **已闭（含一个重要的负面结论）**

| 判据 | 结果 |
|---|---|
| ratio 的 CV / IQR | ❌ `gain~CV` +0.421（R138 已否） |
| **J5 晚期 `ratio>1.3` 时长占比** | ✅ 识别力最强（拦 4/4 失效、误报 1/82；`gain~J5` −0.481）<br>❌ **但不可用作校正门控**：接成"触发即冻结"后 **52/86 批误触发**、中位 5.69→13.17 |
| J1 水平 `\|log(med/g0)\|` | ⚠️ 只有**极端离群**可用（阈值 0.45：拦 1/1、误报 0/85） |
| J2 漂移 `\|log(late/early)\|` | ❌ 阈值 0.45 时误报 18/82 |
| J4 峰值校正幅度 | ❌ `gain~J4` +0.432 |
| 在线可分性 | T=120h 时 J1_online 与 J1_full 的 ρ 仅 +0.215；T=168h 才到 +0.577 ⇒ **早期无法预判** |

**教训（写入方法论）**：**能识别异常 ≠ 异常是坏的。**
J5 拦得准，是因为"晚期 ratio 上冲"既包含通道故障，也包含**真实的模型缺陷**
（模型晚期 OUR 掉得比实测快），而后者正是观测器要修的东西。
任何"用它做门控"的想法都要先做**反事实**（接上去跑一遍全量），不能只看判别力指标。

**最终采用**：J1 极端水平离群（`r_OUR_bar ∉ [0.52, 1.28]`）→ 回退 A 档 + 报警。触发 2 批（b27、b36）。

### D-19　b8/b12/b16 的过度校正（❌ 未闭）

| 批 | A 档 | v2 | 性质 |
|---|---|---|---|
| b8 | 4.83 | 9.63 | 模型误差 < 量测噪声，校正反而引入误差 |
| b12 | 7.40 | 9.87 | 同上 |
| b16 | 3.71 | 8.93 | 同上 |

这是所有数据同化方法的固有代价，三批均 <10%，不破线。
**候选对策**：用 `cons = |log(r_OUR/r_CER)|` 做连续降权 —— 但本轮实测 `cons~模型 nRMSE` 的 ρ 仅 **+0.06**、
`cons~gain` **+0.325**，**判别力不足，暂不采用**。需要找更好的"模型可信度"代理量。

### D-20　CER 通道的自身标度偏差（❌ 未闭，影响观测器上限）

`r_CER` 批级中位 1.039，但 log-log 截距分析显示：**当 X 完全一致时，模型 CER 仍偏低约 16.8%**
（`q_co2` / `Y_CO2_X` 的系统偏差）。这意味着 CER 通道本身带一个约 17% 的固定偏置，
观测器靠 `p·mean(log r_OUR)` 的批级项把它部分吸收掉了。

- 修正它会让观测器更干净（q 可以真正取 1.0），但**会动 A 档 CER 通道**。
- 需先做零回归影响评估（CER 是否进入任何控制回路 / 是否被平台视图消费）。
- **R140 候选**。
