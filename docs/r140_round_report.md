## 1. N 元素平衡：从"破线"到"85/86 达标"

### 1.1 三个实现缺陷（都是真的，不是解释）

| # | 缺陷 | 证据 | 后果 |
|---|---|---|---|
| 1 | **Y_NX / Y_NP 单位方向错** | MATLAB `Parameter_list.m:76-77` 注释是 `mg of N per gram`，即 **10 mgN/gX = 0.010 gN/gX**、**80 mgN/gP = 0.080 gN/gP**；现实现写成 `P/80 + X/10`，把二者当**倒数**（gP/gN、gX/gN） | P 项**小 6.4 倍**、X 项**大 10 倍**；两项误差方向相反、量级相近，**总和凑巧接近**（b8：3.52e5 vs 正确 3.51e5）。这是 R137「错误的正確」的第二次出现 |
| 2 | **漏 N 池变化与随罐移除** | MATLAB `dy(31)` 的 N 是**浓度状态**，罐内库存与排液带走都是实打实的项；现实现只算"产物 + 菌体" | N 池中位从 **1713 → 2062 mg/L**（Δ 中位 **+55 k g**），移除中位 **90 k g**——两项合计相当于 N_in 的 **38%**，全被漏掉 |
| 3 | **`NH3_shots` 恒为 0 且无人报警** | 原始数据集 `100_Batches_IndPenSim_V3.csv` 的 `Ammonia shots(NH3_shots:kgs)` 列**全部为 0**（113 935 行） | N_in 完全由 `N_conc_paa=150 g/L`、`N_conc_oil=20 g/L` 两个**模型虚构氮源**支撑（结构：PAA 68.4% / oil 31.6% / NH3 **0%**）。苯乙酸与三油酸甘油酯本身不含氮 |

### 1.2 修正后的结果（86 批）

完整账恒等式：`N_in = 产物N + 菌体N + 维持 + ΔN池 + 随罐移除`
重排后与实际消耗对比，两种口径：

| 口径 | 化学计量 | 中位 | 达标（±35%） | p90 \|e\| | 最坏 |
|---|---|---|---|---|---|
| **模型标定常数**（逐批 Y_NP / Y_NX） | `P·Y_NP/1000 + X·Y_NX/1000` | **+9.9%** | **85/86** | 18.9% | b91 −60.3% |
| 真实化学计量 | `P×0.0838 + X×0.090` | −58.1% | 0/86 | — | −89.6% |
| 旧口径（不完整账 + 全局 80/10） | `P/80 + X/10` | −14.6% | 73/86 | 38.1% | −61.9% |

对比轮次前的状态（中位 −15.8%、10/12）：**达标率 73/86 → 85/86**，中位绝对值 14.6% → 9.9%。

唯一破线批是 **b91**（−60.3%），与它历来的异常一致（产量余量最紧的 5 批之一、N 账旧口径也报 b36/b91 超 35%）。

### 1.3 关键限定：这不等于"模型 N 守恒"

`Y_NP / Y_NX` 在 86 批里有 **7 种不同组合**（40/20、40/25、50/25、60/10、60/12、60/15、80/10）——
它们在 M3 标定阶段被当成自由参数调过。真实化学计量口径下的 **−58.1%** 说明：

> 模型用的 N 化学计量（Y_NP=40 mgN/gP 即 **4%** 含氮，真实青霉素 G 是 **8.38%**；Y_NX=25 mgN/gX 即 **2.5%**，真实生物质 8–10%）
> 比真实分子式低 **2–3.6 倍**，靠 `N_conc_paa` / `N_conc_oil` 两个虚构氮源**互相配平**。

所以 §1.2 的 +9.9% 证明的是**我们的账实现正确**（与引擎同一套常数自洽），
**不证明** IndPenSim 的 N 元素守恒（登记为 D-21）。

判定方式与 R134 的 PAA 判侧一致：**能判定到哪一步就说到哪一步，不硬凑**。

## 2. 闭环数据同化：判决为"不可行"

### 2.1 做了什么

引擎新增 `assimilate` 开关（默认关闭），每个观测时刻（12h，warmup 24h）用 R139 v2 观测器估计 X，
把菌丝形态 `A0/A1/A3/A4` 等比缩放后继续积分。带 R139 同款门控（`|mo|>0.45` 跳过）与单步限幅（±5%）。

### 2.2 结果：X 拉住了，P 全崩

| 指标 | 开环 | 闭环 | 改善批 | 恶化批 |
|---|---|---|---|---|
| X nRMSE 中位 | 24.53% | **7.44%** | **75** | 11 |
| P nRMSE 中位 | 18.42% | **101.82%** | 4 | **79** |
| \|产量偏差\| 中位 | 1.49% | **92.53%** | 0 | **84** |

- **产量红线 ±5%：86/86 → 6/86**（仅 b8/b11/b37/b41/b65/b84 存活）
- **49/86 批产素归零**（P 末 <1 g/L，开环中位 28.7 → 闭环中位 **0.2**）
- D-16 耦合检验：X 改善且 P 同步改善 **3 批 / 仅 X 改善 72 批**（同向率 3%），ρ(ΔX, ΔP) = **−0.035**

### 2.3 机制：为什么必然崩

1. 开环 X 系统性偏高（R136/R137 已证），观测器因此**持续要求 k<1**——单步 k 全部撞到限幅下界 0.95；
2. X 被压低后，`Y_PAA_X·X_1` 的 PAA 消耗同步减少，**PAA 相对过量积累**；
3. `P_crit_PAA` 抑制被触发，产素速率塌陷 → P 崩；
4. P 崩掉后，产物的碳/氮去向消失，`OUR`/`CER` 比值再次偏离，观测器继续要求压低 X ⇒ **正反馈**。

**这不是"参数没调好"，是路线本身的问题。**

### 2.4 判决与教训

R139 的后处理观测器之所以安全，是因为它**只改上报的 X，不动 ODE 内部状态**——P 的标定完全不受影响。
一旦把同一个公式当反馈控制器用，就等于**打破"X 高估 ↔ 产量匹配"这对既有平衡**，
而这正是 D-10「错误的正確」的实时版本：修 X 的同时把产量修没了。

> **方法论入库（第 3 条）**：**后处理观测器的增益不能直接当闭环增益用。**
> 后处理是"在给定轨迹上做最优拟合"，闭环是"改轨迹再拟合"。前者可以无约束，后者必须过守恒与稳定关。
> 任何"把它接进回路试试"的想法，先跑 3 批看产量红线，不要直接上 86 批。

**如果还要走闭环，只有两条路**（都不在 V0 范围）：
- 状态校正时同步做元素守恒化（把缩掉的菌体折算回底物/PAA，而不是凭空消失）；
- 改用**参数在线估计**（调 `mup/mux/Y_sX`）而不是状态重置——但这会与 M3 标定冲突，需重新签核。
