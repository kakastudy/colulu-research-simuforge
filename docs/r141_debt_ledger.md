## 一、关闭项

### D-8　kd 等比衰减，形态学分区失效　—— ✅ 关闭（结构已实现，前提被证伪）

| 项 | 内容 |
|---|---|
| 原事实 | `-_kd_active·y[i] − _late_kd·y[i]` 对 a0/a1/a3/a4 **等比**施加，形态分区比例恒定，"只移除死菌、保留活菌"无法表达 |
| 原影响判断 | 任何基于 kd 的晚期衰亡方案都会同时砍掉产素主力 a1，是 R136 `ld` 破线的直接原因 |
| 原处理计划 | "给 `kd` 加 selective 开关（只作用 a4）" |
| **实际做法** | 新增 `death_mode=1` 形态学链（A1→A3 老化 + A3/A4 溶菌出系统），**叠加**在等比项之上；默认 0 逐位不变 |
| **结构实测** | `X/A1` 中位 1.23–1.28、CV **2.5–3.3%**；A1 占 X **80–83%**；`r_p = μp·a1/2` |
| **为什么"只作用 a4"不可行** | A4 ≡ 0（`k_vac` 未接线，R137 已确诊）；且**死菌仍计入 X**，清死菌不降 X |
| **退化极限** | 稳态死菌池 ≈ `(age/lysis)·a1`、X 降速 ≈ `age·a1`（与 lysis 无关）⇒ `lysis→∞` 退化为"按 age 移除 a1"；有限 lysis 严格更差。实测 lysis 0.01→1.0：死菌池 14.2%→0.4%（b8）、16.4%→0.4%（b29）、18.7%→0.6%（b56） |
| **净收益** | morph 臂 ΔX 中位 **+0.2~+0.5pt**、Δyield **−2.48~−7.32pt**、破线 0/10 → **4–7/10**；前沿在 **~10pt** 饱和（prop 可达 32pt） |
| 结论 | 缺陷**真实存在且已修复**，但**修复不带来任何收益**——因为它的前提（选择性移除可解耦 X 与产素）在本测量模型下不成立 |

**这条债务的性质因此改写**：D-8 不是"待实现的能力缺口"，而是"一个被误判为有收益的结构假设"。
把它实现出来并证伪，比留着它当借口更有价值。

## 二、新增项

10 批 × 7 配置（70 次仿真）已足以支撑结构结论，但若将来有人主张启用形态学链，
必须先跑全量 86 批。**当前默认路径不受影响**（`death_mode=0`，零回归 0.00e+00）。

### D-26　观测模型未建模"非活性组分"　P2

本轮三线收敛指向同一结论：化验 `X_offline` 的组成与模型 `a0+a1` 的组成不同。
若要**真正**在状态层面修 X，需要在观测模型里引入非活性组分（例如聚集/碎片），
使 X 的可观测值 ≠ 产素活性池。这会改变 `X_offline` 的定义与 I3 区间口径，**需独立评审**，
且与 R139 B 档后处理是两条不同的路（后者已在交付范围内，前者属机理扩展）。
