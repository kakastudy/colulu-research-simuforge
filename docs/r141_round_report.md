# R141 轮次报告 —— D-8 形态学衰亡链：结构实现，前提证伪

> 时间：2026-11-04　契约：v1.68 → **v1.69**　cap：L1 prototype（不变）
> 本轮改了引擎（新增 `death_mode` 等 6 个参数），但**默认路径逐位不变**：
> 零回归 86 批 `max|Δ| = 0.00e+00`、RMSE 2.345%、86/86 within ±5%（417 s）。

---

## 0. 一句话结论

**D-8 的机制现在能表达了，但把它打开之后它不解决问题——因为它的前提是错的。**
"只移除死菌就能修 X 而不伤产素"在本模型里**结构上不可能**：死菌仍然计入 X，
而 X 与产素主力 a1 被锁成 `X ≈ 1.25·a1`（CV ≤ 3.3%）。

---

## 1. 为什么做这一项

L2 三个阻断项里，D-8 是唯一与其他项耦合的：

| 项 | 内容 |
|---|---|
| D-2 | DL σ̂ 未定 |
| **D-8** | `-_kd·y[i]` 对 a0/a1/a3/a4 **等比**施加，形态分区比例恒定，"只移除死菌、保留活菌"无法表达 |
| D-9 | b92 故障幅值重标 |

R137 的晚期衰亡把 X 修好（24.6→13.5%）却把产量从 86/86 打到 33/86，当时的解释就是"kd 等比，
砍 X 必然同比例砍产素主力 a1"。D-8 因此被列为 P1 前置条件：**先让结构能表达选择性，再谈能不能修好**。

---

## 2. 引擎改动（默认关闭）

`candidate/indpensim/v0.1/model.py` + `simulate.py`：

| 参数 | 含义 | 默认 |
|---|---|---|
| `death_mode` | 0 = 现行等比移除；1 = 叠加形态学链 | **0** |
| `age_rate` | A1→A3 老化速率（1/h），门控 `max(0, 1−μ/age_mu_ref)` | 0.0 |
| `lysis_rate` | A3+A4 溶菌出系统速率（1/h） | 0.0 |
| `lysis_recycle` | 溶菌底物回收比例 | 0.0 |
| `age_mu_ref` | 老化生长率阈值（1/h） | 0.02 |
| `age_start` | 老化起始时刻（None = 沿用 `death_start`） | None |

结构：

```
death_mode=1 时（叠加在等比项之上，不替换）：
    r_age = age_rate · max(0, 1 − μ_actual/age_mu_ref) · A1      # A1 → A3（X 内转移）
    r_lys = lysis_rate · (A3 + A4)                               # 死菌 → 出系统
    A3 得到 +r_age − r_lys，A4 得到 −r_lys，S 得到 +r_lys·lysis_recycle
```

### 2.1 一个必须记下来的实现陷阱

**首版把 mode 1 写成"替换"等比项，结果 `death_mode=1` 且 age=lysis=0 时仍然 t=0.6 就分叉。**
原因：黄金参数里 `biomass_death_rate` **本来就非零**（b8 kd=0.001/death_start=100、b16 kd=0.005/death_start=0）。
等比衰亡不是"待实现的功能"，它**已经在基线里跑着**。改成"叠加"之后 `max|Δ| = 0.000e+00`（b8/b29 验证）。

> 教训：新增机理开关时，先确认"旧机理是否已经生效"，否则会以为在做加法、实际在做减法。

## 3. 结构事实：X 与产素主力被锁死

这是本轮最硬的证据，也是后面所有结论的根。

| 批 | X/A1 中位（t∈[40,220]） | CV | p10–p90 |
|---|---|---|---|
| b8 | 1.2397 | **3.3%** | 1.224–1.327 |
| b16 | 1.2534 | **3.3%** | 1.238–1.352 |
| b29 | 1.2768 | **2.9%** | 1.242–1.337 |
| b56 | 1.2330 | **2.5%** | 1.220–1.302 |

同时 `A1 = 80–83%` 的 X，而产素速率 `r_p = μp·a1/2`（一阶）。

⇒ **X 与产素共享同一个状态变量。** 任何**状态层面**的 X 削减，都是等比例的 a1 削减，
也就是等比例的产素削减。这不依赖死菌怎么定义，只依赖 `X = a0+a1+a3+a4` 这个求和。

---

## 4. 前提证伪：死菌仍然计入 X

D-8 的假设是"死菌没被清除，导致 X 高估；只清死菌就能修 X 而不动产素"。三个事实把它拆掉：

1. **`X = a0+a1+a3+a4`**，A3/A4 是死菌，但仍然计入 X。化验 `X_offline` 同样是**总生物量**。
   ⇒ 把 a1 转成 a3，X **不降反升**（先建池），产素却立刻下降。
2. **能降 X 的只有溶出系统**（r_lys）。稳态下死菌池 ≈ `(age/lysis)·a1`，X 的下降速率 ≈ `age·a1`，
   **与 lysis 无关**。
3. ⇒ `lysis → ∞` 时死菌池 → 0，机制**退化为"按 age 直接移除 a1"**——正是等比衰亡的 a1 特例；
   `lysis` 有限时**严格更差**（池子抬高 X + 1/lysis 的滞后）。

## 5. 十批对照：morph 付了全部代价，几乎没换来 X

`runs/p3/r141_death_mode.json`，10 批 × 7 配置 = 70 次仿真（356 s）。
两条臂都**叠加**在逐批标定基线之上；基线本身 **0/10 破线**。

| 配置 | ΔX 中位 | ΔP 中位 | Δyield 中位 | 产量破线 | X 改善批 | debris 中位 |
|---|---|---|---|---|---|---|
| prop_d005 | −0.2 | −2.5 | −2.37 | 6/10 | 4 | 0.0% |
| prop_d010 | −3.3 | −3.5 | −8.54 | 7/10 | 4 | 0.0% |
| prop_d020 | −13.1 | −4.5 | −13.07 | 8/10 | 3 | 0.0% |
| **morph_a05_l02** | **+0.2** | −0.0 | **−3.16** | **4/10** | 0 | 15.4% |
| morph_a10_l05 | +0.2 | −0.7 | −2.48 | 7/10 | 4 | 21.6% |
| morph_a20_l10 | +0.5 | −1.6 | −7.32 | 7/10 | 4 | 31.0% |

读法：

- **morph 臂的 ΔX 中位只有 +0.2 / +0.2 / +0.5pt**，等于没动 X；代价却是 −3.16 / −2.48 / −7.32pt 产量，
  破线从 0/10 变成 4/10–7/10。
- 典型例子 b8（base 已很准，X 5.4%）：`morph_a20_l10` 的 ΔX **+0.8pt**（噪声级），Δyield **−7.25pt**。
- prop 臂的方向对但过冲：b29/b56/b87 大改善，b27/b80/b36 大崩坏。

## 6. 一个必须说清的细节：不是单调权衡，是两个 regime

全 60 个配置点 ρ(ΔX, Δyield) = **+0.549（正）**。这看着像"修 X 也修产量"，其实是因为批分成两类：

| 类 | 例子 | 规律 |
|---|---|---|
| X 严重高估批 | b29、b56、b87、b51 | 砍掉多余生物量后 S 不再被抽干 → 产素反而上去（b56 prop_d005：ΔX +17.3、Δyield **+14.90**） |
| 本来就准的批 | b27、b80、b36、b8 | 同一刀下去双向恶化（b27 prop_d020：ΔX −52.7、Δyield **−91.81**） |

所以约束不是"X 与产量的物理权衡"，而是**可辨识性**：从单条 X 轨迹判断不出这一批属于哪一类，
而一个全局常数必然把第二类打穿。这和 R137"28 批双改善、45 批 X 好产量破"的分裂是同一件事。

## 7. 三线收敛：X 高估不是状态模型问题

| 轮次 | 路线 | 结果 |
|---|---|---|
| R137 | 等比晚期衰亡（时间门控 `kd`） | X 24.6→13.5%，产量 **86/86 → 33/86** |
| R140 | 闭环数据同化（v2 观测器反馈进 ODE） | X 24.5→7.4%，产量 **86/86 → 6/86**，49 批产素归零 |
| **R141** | 形态学衰亡链（选择性死菌池） | ΔX 中位 +0.2~+0.5pt，产量破线 **0/10 → 4–7/10** |

三条互不相同的"改状态"路线全部把产量打穿，而 R139 的**后处理**观测器把 X 从 24% 压到 3.2% 且零风险。
差别只有一个：后处理改的是**上报值**，其余三者在改 **ODE 内部状态**。

⇒ **X 高估是观测模型问题（化验 X 的组成 ≠ 模型 a0/a1 的组成），不是状态模型缺陷。**
这正面解释了 R140 的硬否决，也给 D-8 的否定判决提供了统一解释。

## 9. 判决与档位

| 项 | 结论 |
|---|---|
| D-8 结构缺陷 | ✅ **已修**：选择性形态学衰亡现在可表达 |
| D-8 的修复价值 | ❌ **前提不成立**：死菌计入 X，降 X 只能靠溶出，而溶出上限 = `age·a1` |
| 是否进生产 | ❌ 否，`death_mode=0` 保持默认 |
| L2 阻断项 | **3 → 2**（余 D-2 DL σ̂、D-9 b92 故障幅值） |
| 档位 | 不变，**L1 prototype** |

## 10. 遗留

- 形态学链只在 10 批上做了对照（70 次仿真）。全量 86 批约需 90 min，**本轮未跑**——
  但结论依赖的是结构论证（第 3、4 节）与退化极限，不是这 10 批的统计量，风险可控。
- 若将来要真正修 X 且保产量，方向应是**观测模型**（给化验 X 加"非活性组分"分量），
  而不是再动 ODE —— 该方向与 R139 B 档后处理兼容，但会改变 `X_offline` 的定义，需要单独评审。
