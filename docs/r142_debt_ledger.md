## 一、关闭项

### D-2　DL σ̂（数据受限的可辨识性估计）　—— ✅ 关闭（判定维持，归因与口径重写）

| 项 | 内容 |
|---|---|
| 原记录 | `var_w ≫ var_between` → σ_pop→0，层级模型退化；判"**不可辨识，记为已知限制**"；归因"数据不含批间信息"；触发条件"需要更多同配方重复批"；归属 V1+ / 数据侧 |
| **原记录为什么站不住** | 它把**估计量的输出**当成**数据性质的证据**。`σ_pop = sqrt(max(var_b − var_w, 0))` 对温度双重反向敏感（T↑ → var_b↓ 且 var_w↑），任何 T 偏大都会稳定输出 0 |
| **归因一：温度口径（主因）** | `T_EB = 1.0` 是硬编码常量（`quick_calibrate` 另用 `T = median(loss)`），两处都无量纲依据。实测损失 profile 跨度中位 **0.0094（mux）** ⇒ T 大 **106 倍**。后果：**ESS = 46.8/48 = 0.98**、`var_w` 顶到网格满铺方差的 **99.9%** ⇒ 后验 ≡ 无信息先验；`var_b` 被压到 MAP 口径的 **1%**（1.03e-05 vs 1.08e-03） |
| **归因二：网格量化下限** | v2 网格 mux 仅 **3 点（步距 0.060 = 真值 σ 的 2.4 倍）**、m_s 仅 **2 点**。量化下限 `d²/12`：mux 3.00e-04、m_s **6.75e-06 > var_b(MAP) 3.55e-06** ⇒ m_s 的 σ_pop **在任何数据质量下都只能报 0** |
| **归因三：单批信息量** | 可加模型方差分解（88 批可分解）：SNR 中位 **mux 0.76**（62% 的批 <1）、mup 2.95、m_s 2.97；残差 SD 0.1323 而 mux 主效应跨度仅 0.0521 |
| **温度敏感性** | σ_pop(mux) 只在 **T ≤ 0.002** 时非零（0.0265 / 0.0140），此时 **ESS = 1.3–2.1** ⇒ 后验塌缩到 1–2 个点，属伪精度。mup/m_s 的转正窗口同为 T ≤ 0.01。T=0.001 时 0.0265 与真值 0.025 只差 6%，但那是 `var_w` 被压到 2.24e-04 后 `σ_pop ≈ sqrt(var_b)` 的退化，**不是方法可用** |
| **可交付的新结论** | `σ²_pop ≤ var_b` 无条件成立 ⇒ 用 MAP 口径给**保守上界**（不依赖温度）：**mux ≤ 0.0328、mup ≤ 0.0056、m_s ≤ 0.0019**；对照真值 0.025 / 0.0025 / 0 —— **三者全部相容** |
| **对外口径（写入契约）** | 允许"σ_pop(mux) ≤ 0.033，来自 88 批 MAP 点估计的批间散布"；禁止"σ_pop = 0.033"、"批间参数服从 N(·,·)"、"逐批参数含群体先验"、禁止引用 `COMBINED` 的 sd 作批间分布证据 |
| **触发条件（改写）** | 原"等更多同配方重复批" → **"换估计协议"**：连续优化 + 剖面似然/Laplace 给 var_w；若坚持网格，步距须 ≤ σ/2（mux 至少 10 个水平） |
| 结论 | 判定**成立**（σ_pop 确实估不出来），但**性质从"数据侧不可行动"改为"协议侧可行动"**，且从"无定论"变为"有定量上界 + 明确禁令" |

**为什么判关闭**：阻断项的实质要求是 σ̂ 有定论、可引用、可复现——三项均满足（4 个可复跑工具、
3 个上界、引用禁令）。限制本身没有消失，但边界已量到小数点后三位。
处理逻辑同 R141 的 D-8：**把"未知"变成"已知的边界"。**

### D-28　`COMBINED` 的批间散布是伪的（4–8 倍膨胀）　P2

| 项 | 内容 |
|---|---|
| 源码真值 | `indpensim_run.m:82` `x0.mux = 0.41 + 0.025*randn`；`:85` `x0.mup = 0.041 + 0.0025*randn`；`Parameter_list.m:30` `m_s = 0.029`（**常数，无 randn**） |
| COMBINED 实测 | mux sd **0.2083**（8.3×）、范围 [0.350, 1.000]；mup sd **0.0099**（4.0×）；m_s sd **0.0033**（真值为 0，**无中生有**） |
| 结论 | `COMBINED` 不是参数估计，是**把结构误差吸进参数的补偿器**。给恒定参数造散布这一条已足以否证"COMBINED 的批间方差 ≈ σ²_pop" |
| 已证伪的旧证据 | `tools/d9_dl_sigma_combined.py` 注释"mux σ_pop=0.0272 vs 0.025 差 8%"是**选择性报告**：同一次运行里 mup 输出 0.01009（真值 0.0025，**+303%**）、m_s 输出 0.00643（真值 **0**）。mux 的"接近"来自 var_b（sd 0.0545，已是真值 2.2 倍）与 var_w 两个错误互相抵消 |
| 使用边界 | `COMBINED` 只能作**逐批点估计**（复现 86 批产量）；不得作批间分布样本 |
