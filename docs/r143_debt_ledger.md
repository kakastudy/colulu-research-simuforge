## 一、本轮关闭

### D-9　b92 故障幅值重标 —— **关闭（撤销命题）**

| 项 | 记录 |
|---|---|
| 原命题 | "b92 pH 故障 mag 100–1000 → yield −1.0（必崩），幅值需重标" |
| 实际 | ① `mag` 量纲错 4 个数量级：`ph_acid = mag / V(mL)` ⇒ 等价 mag **4.18e-3**，旧范围放大 **23 936×–239 363×** |
| | ② 旧扫描 8 个窗口×4 幅值：只有 `[100,180]` 覆盖观测窗 **141.2–167.6**，但早启 **41.2 h**、晚停 **12.4 h**；其余 7 个完全不覆盖（[80,160] 在最低点截止） |
| | ③ 参照基线已陈腐：b91 −0.302 → **+3.52%**、b92 −0.0062 → **+1.36%**（同参数同调用） |
| 机制 | b92 的 pH 凹陷由 **Fb 撞下限 10.00 mL/h（140–160 h，连续 20.2 h，全集最长）** 驱动，随后撞上限 225.00 复原；该饱和**在原始表里就存在** |
| 因果证据 | 反事实臂（窗内 Fb→114.5）：窗内 pH 最低 5.434 → **6.322**、窗内 RMSE 0.254 → **0.872** ⇒ 凹陷消失 |
| 独立复现 | **b98**（从未标为故障批）同一时段 `Fb 141–159 = 10.00`、`162 = 225.00`，化验 pH 5.602；标称模型窗内 RMSE **0.170**、最低 5.554、yield **+0.33%** |
| 剂量响应 | mag 0 → 100：窗内 RMSE 0.254 → 3.432、yield +1.36% → −82.93%，**单调恶化，最优 = 0** |
| 结论 | 该算子在 b92 上**没有可标定的自由度**。正确动作不是"重标幅值"，而是**撤销该标定需求**：故障载体已在回放输入里 |
| 遗留 | docstring 里 `fault_magnitude` 的"pH 为酸注入速率 mg/L/h"是错的，实际量纲 ≈ mmol H⁺/h —— **未改代码（零回归纪律），记入 D-31 待一并修** |

## 四、本轮净变化

- **关闭 1 项**：D-9（撤销命题）
- **新增 2 项**：D-30（L2 阻断）/ D-31
- **L2 阻断项 1 → 1**（D-9 出、D-30 进）——净额未减，**性质从"标定/文档"变成"数值可复现性"**
- **引擎零改动**，零回归 86 批 `max|Δ| = 0.00e+00`、RMSE 2.345%、86/86
- **方法论入库 1 条**（累计 6 条）：

  6. **先查故障信号是否已经在回放输入通道里，再决定要不要注入算子。**
     开环回放把受控变量当输入喂进去；若故障的物理载体就是这些变量（如 Fb 撞限），
     再叠一个算子等于**同一扰动计两次**，"必崩"是叠加的结果，不是模型对故障的响应。
     D-9 挂了三轮都在问"幅值给多少"，正确答案是"不给"。
     算子只该用于**没有录进输入通道**的故障：传感器偏置、未记录的 KLa 衰减、生物摄取停滞。

  （附带一条：**先做量纲审计，再做参数扫描。** 一个 `mag / V(mL)` 的单位错误，
  让整张扫描表测的是"在错误时段灌过量四位数倍的酸"，而它被当成"必崩"的证据引用了三轮。
  ）
