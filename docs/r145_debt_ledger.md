# R145 债务台账 —— D-32 关闭：不是"产酸偏小"，是**产酸源变号 + 守卫放大水解**

> 时间：2026-11-04　契约：v1.73
> **引擎新增 2 个 opt-in 开关**（`ph_hyd_acid=False`、`ph_mode="model"`），默认关闭 ⇒
> 零回归 86 批 `max|Δ| = 0.00e+00`、RMSE 2.345%、86/86（846 s）。

## 一、本轮关闭

### D-32　尾段产酸项偏小 → pH 越出验证域　**关闭（机制定位 + 两条修复路径证伪）**

| 项 | 记录 |
|---|---|
| 原表述（R144） | "模型尾段产酸项（`ph_prod`/`r_p`）在 P 衰减期过小 ⇒ pH 漂到 7.44" |
| **修正** | 不是"偏小"，是**变号**：`acid := γ1·(ph_prod + r_p)` 在 **30 / 86 批**的尾段**为负** |
| 直接原因 | `P_inhib`（残糖的高斯门控）在残糖高时归零 ⇒ 产素通道关闭 ⇒ `r_p` 只剩 `−mu_h·P`（水解）。b92 t=200：`ph_prod = +0.0619`（其中 `m_ph·X = 0.0601`）、`r_p = −0.1065` ⇒ 合计 **−0.0446** |
| 分水岭 | 残糖。b8（t≥180 实测残糖 **0.00 g/L**）`P_inhib` 中位 **0.820**、产酸源 **+1.96e-07**、pH 6.30；五批钳位批残糖 7.3–91.7 g/L、`P_inhib` 中位 **0.000**、产酸源 −1.24e-07…+5.6e-09 |
| 后果（代数） | 冻结 t=200 的 (V, Fb) 解 `dy6=0`：`acid=+1e-7` → 定态 pH **5.691**；`acid=0` → **7.022**；`acid=−1.45e-8` → **7.161**；`acid=−1e-7` → 酸性域**无根**。**`acid` 一旦不为正，定态 pH 就 ≥7.02，即离开 acidic 分支自己的定义域** |
| 后果（动力学） | 越 7 后进 basic 分支，`−Kw/[H+]` 正反馈（R144：`t*=[H+]²/2Kw`，pH 7.0 → 0.5 h）⇒ 0.2 h 网格上必崩 |
| **守卫的真实代价** | `y[i]<=0→0.001` 把 `[H+]` 写成 0.001 ⇒ **pH 3.000 ⇒ `mu_h = k4` 从 3.713e-03（pH6.5）跳到 3.129e-02（pH3.0），8.43 倍**。钳位不是"显示成 3"，而是**加了一个 8.4 倍的产物水解汇** |
| 定量后果 | 额外水解率 2.758e-02 /h ⇒ b37 在 37 h 钳位窗内多损失 **64.0%** 的 P；b50 52.2%（26.8 h）、b91 50.6%（25.6 h）、b51 29.4%（12.6 h）、b92 29.0%（12.4 h）。窗长与 Δyield（+125/+64/+28/+32/+32 pt）同序 |
| 修复路径 1（`ph_hyd_acid`） | 水解按产酸翻正 ⇒ pH 末掉到 **5.0–5.3**，**46 批**破线，RMSE **20.555%**、max\|err\| **69.80%** ⇒ **证伪** |
| 修复路径 2（`ph_mode="measured"`） | pH 按实测回放 ⇒ 5 批变 **+125.2/+64.2/+27.6/+31.6/+31.8 pt**；全库 **62/86** 命中，排除 5 批仍只有 62/81、max\|Δ\| **55.54 pt** ⇒ **不是"改对 pH 就变好"，是 pH 是产量的一根杠杆** |
| 结论 | D-32 的实质是：**`P_inhib→0` ⇒ 产酸源变号 ⇒ 酸性域无定态 ⇒ 越 7 ⇒ 爆破 ⇒ 钳位 ⇒ 水解 ×8.4**。链条从"残糖"起，不始于数值格式，也不始于"产酸偏小" |
| 处置 | ①关闭 D-32；②pH 验证域定为 **`pH ∈ [5.396, 6.766]`（实测包络）**，越界即 `domain_violation`；③口径第三次修订（见 §三）；④问题转 **D-35** |

## 二、新增

### D-35　pH 轨迹的系统偏差与产量标定耦合　**🔴 L2 阻断项（新，唯一）**

| 项 | 记录 |
|---|---|
| 现象 | 开环模型 pH 系统性**偏酸** 0.1–0.25 个 pH 单位（抽样 6 批：b8 −0.159、b3 −0.225、b24 −0.243、b31 −0.096、b92 −0.305、b37 −0.730） |
| 传递 | `k4(6.34)/k4(6.50) ≈ 1.10` ⇒ 模型全程多损失约 10% 产物；同时 `pH_inhib` 压低生长与产素 |
| 耦合证据 | 把 pH 换成实测（等价于消除该偏差）后，**24/86 批**越出 ±5%（21 批升、均值 +5.84 pt，最大 b37 +125.24 pt）。Δ 分布：**49 批 <2 pt、16 批 2–5 pt、21 批 ≥5 pt、8 批 ≥20 pt** |
| 判读 | `μp / Y_*` 等标定参数是在**一条偏酸的 pH 轨迹上**拟合出来的，已经吸收了 pH 偏差。单改 pH 会把这些参数变成错的；单改 pH 方程会换一个方向偏（见 `ph_hyd_acid` 臂）。**必须联合重标定** |
| 为什么不本轮修 | 需同时动 `γ1/γ2/m_ph` 与 `μp/Y_sX/Y_sP/Y_NP/Y_NX`，属全库重标定；且要先决定"pH 是预测还是输入"这一产品口径 |
| 与既有债的关系 | 与 D-20（CER 固定偏置）、D-22（`Y_NP/Y_NX` 差 2–3.6 倍）、D-26（观测模型缺非活性组分）同族，都属"标定把系统偏差吸收掉了" |

### D-36　守卫钳位会**改写动力学**，不只是改写显示（D-33 重定级）

| 项 | 记录 |
|---|---|
| 问题 | R144 把守卫下限当"显示口径"问题（D-33：`[H+]` 不该用 0.001）。本轮证明它同时**改写 ODE**：`mu_h = k4(pH)` 在 pH 3 处是 pH 6.5 的 **8.43 倍**，直接放大产物水解 |
| 影响 | 5 批钳位批的产量由钳位窗长决定（见 D-32 表）；这也是 R144 混沌检验（b37 极差 70.96 pt）的物理来源 |
| 处置 | D-33 从"口径"升为**结论有效性**问题，优先级提到 D-35 之后第一位；但仍须等 D-35 定下 pH 口径，否则只是把 pH 3 换成 pH 9 |
| 附加要求 | 任何钳位都必须在批量验收里**显式报出**（D-34），且**按状态索引**报，不能只报"触发过守卫" |

## 三、口径修订（第三次，对 GOAL / M4）

| 版本 | 表述 |
|---|---|
| R143 及以前 | 86/86 批产量 ±5% |
| R144 | 81/86 干净 + 3 批 artifact-dependent + 2 批域外（产量可复现） |
| **R145（现行）** | **62 批对 pH 处理稳健 / 19 批依赖 pH 轨迹 / 5 批由钳位窗长决定** |

| 类别 | 批数 | 判据 | 能否当证据 |
|---|---|---|---|
| **稳健** | **62** | 默认臂与"实测 pH"臂都 ±5% | 可以 |
| **依赖 pH 轨迹** | **19** | 换实测 pH 后越 ±5%（\|Δ\| 5–55.5 pt） | 证据强度取决于 pH 轨迹，当前 pH 有 −0.2 偏差 ⇒ 不足 |
| **由钳位决定** | **5** | b37 b50 b51 b91 b92，Δ +28…+125 pt | **不能** |

> R144 的"81 干净"只查了"有没有撞钳位"；本轮加查"把 pH 换成实测会不会变"，多出 19 批不稳健。
> **同一批数据，判据收紧一次，结论就收紧一次——这是第三版口径，不能保证是最后一版。**
