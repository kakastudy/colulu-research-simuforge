> **【R148 勘误 · 2026-11-04】**：本报告中"守卫把 pH 写成 3 并**维持** N 个样点"的表述**不准确**。

> 另：本文的"钳位样点 N"实为"pH≈3 的样点数"，非"守卫改写次数"。详见 `docs/r148_round_report.md` §3。

## 0. 一句话结论

D-32 的原表述「尾段产酸项**偏小**」是错的。实测是**变号**：

> 86 批里 **30 批**的净产酸源 `γ1·(ph_prod + r_p)` 在尾段**由正转负**。
> 直接原因是 `P_inhib`（残糖的高斯门控）在残糖高时归零，`r_p` 只剩 `−mu_h·P`（水解）。
> 产酸源一旦为负，pH 方程在 `pH ∈ [5,7)` 内**没有平衡点**——[H+] 单调衰减到 0 是必然的。
>
> 而守卫 `y[i]<=0 → 0.001` 把这条支路写成 **pH = 3.000**，同时把 `mu_h` 抬高 **8.4 倍**
> （k4 是 pH 的指数函数，实测罐温 303.4 K 下：pH 6.5 → 3.713e-3，pH 3.0 → 3.129e-2）。
> **钳位不是显示问题，它把产物水解汇放大到 8.4 倍。**

两条修复路径本轮都被**证伪**：

| 路径 | 结果 |
|---|---|
| 水解通道按"产酸"翻正（`ph_hyd_acid`） | pH 末掉到 **5.0–5.3**，**46 批**破线，RMSE 20.6% |
| pH 降级为实测输入（`ph_mode="measured"`） | 5 批产量 **+28…+125 pt**；另有 **19 批**越 ±5% |

⇒ **D-32 关闭（机制定位 + 两条修复证伪）**，问题以更尖锐的形式转成 **D-35（pH–产量标定耦合）**。

## 2. 方法：pH 方程的逐项预算（只读）

`model.rhs` 的 acidic 分支是四项之和：

```
dy[6] = γ1·ph_prod + γ1·r_p + γ2·pH_dis + buffer
ph_prod = r_b0 + r_e1 + r_d4 + r_d1 + m_ph·total_X
buffer  = (−B + √(B²+4Kw))/2 − [H+]
```

`tools/r145_d32_terms.py` 包裹 `simulate.integrate_interval` 拿到每个区间的 `(t0, y0, inp1, par)`，
调 `rhs` 取 `dy[6]`，再**自行重算** `buffer` 与 `γ2·pH_dis`，反解出产酸项：

```
acid := dy[6] − γ2·pH_dis − buffer        （acidic）
```

### 2.1 自检踩了一个坑，必须先说清楚

第一版自检定义 `closure := dy[6] − (dis + buf + acid)`，恒等于 0（`acid` 就是这么定义的）。
**这是同义反复，不是验证。** 本轮改用**有限差分**独立校验：

| 导数 | 实测 | 理论 | 判定 |
|---|---|---|---|
| `∂dy6/∂γ1` | **−4.464965e-02** | `ph_prod + r_p` | 与反解值 **−0.044650 逐位相同** |
| `∂dy6/∂m_ph` | **7.809774e-06** | `γ1·total_X` | 一致（X=24.0301） |
| `∂dy6/∂par[19]` | **0.000000e+00** | 若 `mu_h=par[19]` 应为 `−γ1·P=−8.5e-06` | **证伪**：`inhib=2` 下 `par[19]` 不参与 |

第三条抓出一个真错误：`inhib=2` 分支里 `mu_h = k4·par[18]`（`k4 = exp(B₁+B₂·pH+B₃·T+B₄·pH²+B₅·T²)`），
`par[19]=0.003` **根本不被使用**。第一版工具拿 `par[19]` 算 `r_p`，把 `r_b0+r_e1` 算成了 −0.0279
（不可能为负）。修正后 `r_b0+r_e1 = 0.0000`，与 `m_ph·X + r_d1 + r_d4` 精确对账。

> 记一条：**"残差为 0" 只有当残差不是用被检验量定义的时候才算证据。**
> 本轮第一次写成了循环定义，靠有限差分才发现。

### 2.2 校验通过后的口径

`∂dy6/∂γ1` 与反解值逐位相同，说明 `dis + buf` 的重算**精确等于**引擎里与 `γ1` 无关的那部分，
因此 `acid` 可信。下面所有数值均由修正后的工具产出。

**参数取值（易错，单列）**：`γ1 = par[62] = 3.25e-07`、`γ2 = par[63] = 2.5e-11`（相差 **4 个数量级**）、
`m_ph = par[64] = 2.5e-03`、`abc = par[61] = 0.033`。

## 3. 发现一：净产酸源会变号（30/86 批）

b92 尾段（`runs/p3/r145_d32_terms_b92.json`）：

| t (h) | pH | `acid` (mol/L/h) | `buffer` | `γ2·pH_dis` | `ph_prod+r_p` |
|---|---|---|---|---|---|
| 200.0 | 6.079 | **−1.45e-08** | −9.15e-08 | +6.91e-09 | **−0.0446** |
| 210.0 | 6.491 | −9.36e-09 | −3.97e-08 | +9.26e-09 | −0.0288 |
| 214.0 | 6.541 | −8.56e-09 | +3.14e-08 | +9.30e-09 | −0.0263 |
| 216.8 | 7.007 | −7.09e-09 | −4.17e-08 | +9.15e-09 | −0.0218 |
| 217.2 | 7.155 | −6.97e-09 | −1.12e-07 | +9.13e-09 | −0.0214 |

三项里 `γ2·pH_dis` 恒为 `~9e-9`（`γ2 = 2.5e-11`，比 `γ1 = 3.25e-7` 小 4 个数量级），
所以 pH 由 **`acid` 与 `buffer` 两者角力**决定。**而 `acid` 是负的** —— 代谢项整体在"碱化"。

拆开看（t=200，b92）：

| 分项 | 数值 | 说明 |
|---|---|---|
| `m_ph·total_X` | **+0.0601** | 维持产酸，**与 S 无关**（`∂dy6/∂m_ph` 已校验） |
| `r_d1` | +0.0018 | 衰亡迁移 |
| `r_d4` | +4.8e-07 | 死菌衰亡（A3≈0） |
| `r_b0+r_e1` | **0.0000** | 生长相关产酸 —— 此处**精确为零** |
| `r_p` | **−0.1065** | 产素 0 − 水解 `mu_h·P`（`mu_h = k4 = 4.065e-03`，P=26.21） |
| **合计 `ph_prod+r_p`** | **−0.0446** | ⇒ `acid = γ1×(−0.0446) = −1.45e-08`（与 `∂dy6/∂γ1` 逐位相同） |

**`r_p` 为什么是负的**：`r_p = μp·a₁/2·P_inhib·DO₂·PAA − mu_h·P`，而

```
P_inhib = 2.5σ·(σ√2π)⁻¹·exp(−½((s−mean_P)/σ)²)
```

是**残糖的高斯门控**。b92 尾段残糖 `s ≈ 12–26 g/L`（实测 t≥180 均值 **30.43 g/L**），
高斯尾巴归零 ⇒ `P_inhib = 0.000`（尾段中位）⇒ 产素通道关闭，`r_p` 只剩 `−mu_h·P`。

于是产酸项退化为 `m_ph·X − mu_h·P`：**P 越大、残糖越高，净产酸越负**。
b92 的 26.2 g/L 把 0.0601 的维持产酸抵消成 −0.0446。

## 4. 发现二：产酸源为负 ⇒ 定态 pH 被推出酸性域

acidic 分支可写成 relaxation 形式：

```
d[H+]/dt = acid + (root − [H+]),     root = (−B+√(B²+4Kw))/2
```

注意 `root` 自己也是 `[H+]` 的函数（`B` 里含 `[H+]·V`），所以平衡点不能直接读成 `acid + root`。
把 t=200 的 b92 状态（V=73432 L、Fb=23.4 L/h、Fa=0）**冻结**，对 `dy6=0` 做二分求根：

| `acid` (mol/L/h) | 定态 `[H+]` | 定态 pH | 落在哪 |
|---|---|---|---|
| +1.00e-07 | 2.036e-06 | **5.691** | 酸性域内 |
| +5.00e-08 | 2.313e-07 | **6.636** | 酸性域内 |
| **0** | 9.509e-08 | **7.022** | **已在域外** |
| −1.00e-08 | — | **7.114** | 域外 |
| **−1.45e-08**（实测） | — | **7.161** | 域外 |
| −1.00e-07 | — | 酸性域内**无根** | — |

**阈值极干净：`acid` 一旦不为正，定态 pH 就 ≥ 7.02，即离开 acidic 分支自己的定义域。**
所以 pH 不是"慢慢漂高"，而是**沿着一条指向域外的轨道单调上行**；
`0.2 h` 的采样步长只决定它哪一步跨过 7。

跨过 7 之后进入 basic 分支，其中含 `−Kw/[H+]`（R144 已证 `t* = [H+]²/2Kw`），
在 0.2 h 网格上必然爆破。**这条链的起点是 `acid < 0`，不是数值格式。**

> 附注：上式对 `Fb` 是敏感的——同一 `acid` 下 `Fb` 越大，定态 pH 越低。这正是"pH 是受控变量"的代数体现：
> 控制器通过 `Fb` 把定态 pH 按在 6.5。**模型回放的是控制器的输出而不是控制器本身**，
> 所以一旦 `acid` 掉到 0 以下，就没有任何机制把它拉回域内。

## 5. 发现三：钳位不是"显示问题"，它把水解速率抬高 8.4 倍

这是本轮最要紧的一条修正。

`inhib_flag=2` 下 `mu_h = k4·par[18]`（`par[18]=rho_d=1.0`），而

```
k4 = exp(B₁ + B₂·pH + B₃·T + B₄·pH² + B₅·T²)
```

代入 b92 在 t=200 的实测罐温 **T=303.397 K**：

| pH | k4 | 备注 |
|---|---|---|
| 7.155 | 3.530e-03 | 越 7 前一刻 |
| 6.500 | **3.713e-03** | 数据常态 |
| 6.079 | 4.065e-03 | b92 t=200 |
| 3.000 | **3.129e-02** | **钳位值** |

**比值 `k4(pH3)/k4(pH6.5) = 8.427`。**（该比值与 T 无关，`B₃·T + B₅·T²` 在比值里约掉。）
钳位把 `r_p` 里的 `−mu_h·P` 放大 8.4 倍，等于凭空加了一个产物水解汇。
b92 的实测印证：钳位前 P 每 0.2 h 掉 `0.03 g/L`，钳位后掉 `0.26 g/L`（9 倍）。

按钳位窗长估算额外 P 损失 `1 − exp(−(k4₃ − k4₆.₅)·Δt)`，其中 `k4₃−k4₆.₅ = 2.758e-02 /h`：

| 批 | 钳位窗 | 窗长 (h) | 额外 P 损失 | pH 换实测后 Δyield |
|---|---|---|---|---|
| **b37** | 173.0–210.0 | **37.0** | **64.0%** | **+125.2 pt** |
| b50 | 203.2–230.0 | 26.8 | 52.2% | +64.2 pt |
| b91 | 232.4–258.0 | 25.6 | 50.6% | +27.6 pt |
| b51 | 212.4–225.0 | 12.6 | 29.4% | +31.6 pt |
| b92 | 217.6–230.0 | 12.4 | 29.0% | +31.8 pt |

窗长与 Δyield 同序（b37 最长 → Δ 最大）。这不是严格分解，但方向与量级一致，
足以说明：**这 5 批的"达标"是由钳位窗长决定的，不是由化学决定的。**

## 6. 反事实一（`ph_hyd_acid`）：证伪

假设：青霉素 G 水解生成青霉噻唑酸（一元羧酸），应在 pH 方程里**产酸**而非碱化。
实现：`r_p_ph = r_p + 2·mu_h·P`（只改 pH 方程，不改 `dy[3]`）。

`tools/r145_d32_hydacid.py`（86 批）：

| 指标 | 默认 | 翻正后 |
|---|---|---|
| ±5% 命中 | 86/86 | **40/86** |
| RMSE(err) | 2.345% | **20.555%** |
| max\|err\| | 4.83% | **69.80%** |
| \|Δyield\| > 5 pt 的批 | 0 | **44** |
| pH 末（典型） | 6.3–6.6 | **5.0–5.3** |
| 仍被钳位 | 5 | 4（b27 b31 b50 b78） |

**pH 从"偏高"直接翻到"偏低"**（末值 5.0–5.3，而实测 6.5），产量随之崩塌。

结论：pH 方程是一个**近奇异平衡**——`acid` 与 `buffer` 在 1e-7 量级上互相抵消，
改任何单项都会把 pH 推过 1 个单位。**这不是"补一个漏项"能修的方程。**

## 8. 对 D-32 的处置

D-32 的命题（"产酸项偏小"）**不成立**，实际是"产酸源变号 + 门控关闭"。
但**它也不能被"修好"**：两条最自然的修复路径都被证伪，而 pH 方程对单项改动过敏。

因此本轮：

1. **关闭 D-32**（机制已定位：`P_inhib→0` ⇒ `r_p→−mu_h·P` ⇒ `acid<0` ⇒ 无域内平衡点 ⇒ 越 7 ⇒ 爆破 ⇒ 钳位 ⇒ `mu_h×8.4`）。
2. **新立 D-35**：pH 轨迹的 −0.16…−0.24 系统偏差与产量标定**耦合**，要修必须联合重标定
   （`γ1/γ2/m_ph` 与 `μp/Y_*` 同时），不是单点改动。
3. **重定级 D-33**：守卫下限按状态区分，从"显示口径"升为 **"产量污染源"**——因为
   `[H+]=0.001` 让 `mu_h` 变 8.4 倍。

### 8.1 验收口径（第三次修订）

| 类别 | 批数 | 判据 |
|---|---|---|
| **对 pH 处理稳健** | **62** | 默认与"实测 pH"两臂都 ±5% |
| **依赖 pH 轨迹** | **19** | 换实测 pH 后越 ±5%（\|Δ\| 5–56 pt） |
| **由钳位窗长决定** | **5** | b37 b50 b51 b91 b92，Δ +28…+125 pt |

⇒ `86/86 ±5%` 应改述为 **"62 批稳健 / 19 批依赖 pH 轨迹 / 5 批由钳位决定"**。

这比 R144 的"81 干净 + 5 有问题"更严格：R144 只查了"有没有撞钳位"，
本轮进一步查了"把 pH 换成实测会不会变"，**多出 19 批不稳健**。

---

## 9. 做了什么 / 没做什么

**做了**：两个 opt-in 开关（默认关闭）、三个只读工具、86 批两次全量反事实、零回归验证。

**没做**（明确留白）：

- 没有把 `ph_hyd_acid` 或 `ph_mode` 设为默认——两者都会破坏 86 批基线；
- 没有重标定 `γ1/γ2/m_ph`——那需要与 `μp/Y_*` 联合优化，属 D-35 的范围；
- 没有把守卫 `0.001` 改掉——D-33 的方案要先在 D-35 上确定 pH 口径，否则只是把 pH 3 换成 pH 9。
