## 二、新增 / 变更

### D-35b　pH 偏差的**可修正性**：可行步长 = 0　**🔴 未闭（挂在 D-36 之下）**

| 项 | 记录 |
|---|---|
| 基线事实 | 12 批 pH 偏差 **全部 ≤ 0**，但幅度 **−0.007 … −0.572（差 80 倍）**：b22 −0.007、b23 −0.009、b27 −0.015 已基本无偏；b36 −0.572、b80 −0.496、b16 −0.302 |
| 对 R145 的修正 | 「系统性偏酸 0.1–0.25」是**抽样偏置**（抽到的 6 批都在偏酸端）；扩到 12 批后是**重尾分布，不是常数偏移** |
| 全局重标定测试 | 沿 GN 方向（Δln = −0.1332/+0.6343/−0.6925）扫 λ∈[0,1.5]：**λ=0.25 即崩**（RMSE 0.407→0.995、钳位 809 样点、max\|err\| 100%） |
| 机制 | b22 基线 pH 峰 **6.798**、b27 **6.802**，距 7.0 仅 **0.198/0.202**；而这两批正是**偏差最小**的批。抬 pH 的方向 = 推悬崖的方向 |
| 定量 | λ=1 时 6 批偏差已 <0.11（b8 −0.004、b11 −0.056、b16 −0.104、b23 +0.048、b60 −0.170、b80 −0.214），代价 b22 −100%、b27 −24.3%、b55 −71.0% |
| 结论 | **不存在一个全局 pH 参数向量能同时服务两端**；要消掉 −0.24 平均偏差需 λ≈1，而 λ≈1 会推倒贴悬崖的批 |
| 为什么不本轮修 | 被 D-36 挡住：`pH>7` 在 0.2 h 网格上必崩并被钳到 3.000，可行域上界只有 0.2 pH 单位，而待修量 0.24–0.57 |
| 与 D-35 原表述的关系 | 原表述「需联合重标定」**方向对、归因粗**——真正的约束不是参数耦合，是**可行域截断**。单改产量参数也无济于事（产量并不需要改：12/12 在 ±5%） |

### D-36　守卫钳位改写动力学（= R145 的 D-33 重定级）　**🔴 升为唯一 L2 阻断项**

| 项 | 记录 |
|---|---|
| 变更 | R145 把 D-36 排在「待 D-35 定 pH 口径**之后**」；本轮证明顺序**反了** |
| 理由 | D-36 不是 D-35 的下游，是 **D-35 的可行域边界**。pH 7.0 前 0.2 个单位的天花板直接决定了 pH 标定能走多远（答案：走不动） |
| 现存代价 | `mu_h = k4` 在 pH 3.0 是 pH 6.5 的 **8.43 倍**（R145）；钳位样点 b91 **129**、b92 **63** |
| 下一步 | 先让 `pH > 7` 的 basic 分支**数值上不死**（至少不能用 `[H+]=0.001` 冒充），再回头做 D-35b 的重标定 |

### D-38　`classify_crash` 短路，看不见 pH 崩塌 / P 崩塌　**🟠 新增（口径可信度）**

| 项 | 记录 |
|---|---|
| 代码 | `simulate.classify_crash()` 第一句 `if co2d.max() <= co2d_crit: return "normal", []` |
| 后果 | 任何未穿越 CO2d 阈值的批，**无论 pH/P 多糟**一律报 `normal` |
| 实证 | b91：`CO2d < 7.57` 但 pH 末 **3.001**、钳位 **129** 样点、pH≥7 有 **14** 样点、P 末/峰 **0.162** ⇒ 三条病理判据全成立，仍报 `normal`；b92 同类（63/4/0.507） |
| 影响面 | `GOAL.md` 红线「**0 catastrophic**」目前由一个看不见 pH 崩塌的分级器给出 ⇒ 该结论的**判据基础**要重述 |
| 处置 | **本轮不改判据**（改了会让全部历史验收数字静默变化，违反方法论第 9 条）。登记，并已在新测试注释里写明这条局限；修 D-38 时须补「未穿越 + pH 崩塌 ⇒ 不得报 normal」用例 |

### D-34（扩展）　钳位与包络越界纳入验收必检

原为「钳位统计按状态索引报」。本轮追加：**pH 包络越界也要按批报**，因为基线自己就越界——

| 批 | 基线 pH 峰 | 对 R145 包络上界 6.766 |
|---|---|---|
| b22 | 6.798 | **+0.032** |
| b27 | 6.802 | **+0.036** |

⇒ R145 定的「pH ∈ [5.396, 6.766]，越界即 domain_violation」在 **λ=0 就不成立**，
不能当硬约束；硬约束只能是「**不钳位 且 不越 7.0**」。这条口径须写进 v1.74。
