## 一、本轮关闭

### D-40a　`k_deg` 作为可标定参数　✅ **关闭（否定结论）**

| 项 | 内容 |
|---|---|
| 原计划 | 与 `Y_sP/Y_sX/μp` 联合标定（R149 台账 §三 第 3 步） |
| 实测 1 | 在 P 通道上的列范数比 `mu_h` 小 **4–45 倍**（b22 2.44 vs 82.2；b59 1.79 vs 81.7） |
| 实测 2 | 三参数 SVD 的最小奇异方向**几乎纯 `k_deg`**（b55/b59 第三分量 +0.988） |
| 实测 3 | 置换检验：同样的等效量，`mu_h` 的效果是 `k_deg` 的 **1.4–42 倍**（全臂有效 4 批的**中位 10.16×**，抵消比 0.937，随工作点变化见 §五 纪律 2） |
| 结构原因 | `dP/dt = 产素项 − (mu_h + k_deg + D)·P`，二者在 P 方程里只以和出现；`mu_h` 还进 pH 方程，而 pH 已被 R149 判为不可用 |
| 与 R138 一致 | R138 全局启用 `p_deg_rate` 每批单向恶化（b8 −4.04%→−15.28%、b29 −3.43%→−22.24%），当时归因"估计混入稀释项"，现在有了结构解释：**它和 `mu_h` 重复计数** |

**处置**：保持 `p_deg_rate = 0.0`。表观水解全部留在 `mu_h`（它是 pH/T 相关的，物理上更合理）。

### D-40b　`Y_sP` / `Y_sX` 需要标定　✅ **关闭（前提不成立）**

| 项 | 内容 |
|---|---|
| 原计划 | 纳入联合待标定集 |
| 实测 | 60–120 h 的 **S 残差 +0.004**（+0.4%），6 批跨批均值同量级；糖轨迹这一段是准的 |
| 推论 | `Y_sP` 进 `dS/dt` 的 `−Y_sP·r_p` 项，动它必坏 S。**当前 S 没有可修的偏差** |

注意 0–60 h 的 S 相对残差是 **+1.657**，看似巨大，实为**分母接近 0** 的产物
（分批补料期残糖被压在低值），不是真实误差。**这正是 R149 第 19 条纪律的反面用法**：
分母趋近 0 时比值没有信息，不能拿它当"糖不对"的证据。

**新增四条纪律**：

1. **单标量指标会掩盖轨迹误差**（第 23 条）。产量是积分量，峰高尾低可完全抵消。
2. **可辨识性依赖工作点**（第 24 条）。b36/b55 的 cond 是 16，b22/b59 是 100–203，
   差别全在 `mu_h` 的列范数（11.4 → 82.2），因为后两者 pH 距 7.0 仅 0.198。
3. **排除法要按通道对齐到同一相位**（第 25 条）。
4. **扰动前先确认参数接到了方程上**（第 26 条）。本轮核对出 `params["mup"]` 是状态变量初值、
   `par[19]` 会被分支覆盖；工具里加了"轨迹差为 0 即抛异常"的硬断言。
