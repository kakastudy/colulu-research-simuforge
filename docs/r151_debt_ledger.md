## 五、纪律（新增，接 R149 §19 条、R150 §五）

1. **新指标先与旧实现对齐，再谈结论**。`shape_metrics()` 与 R150 手写统计在 86 批上逐位相同（`max|Δ|=0`）；没有这一步，"改善"可能只是换了算法。
2. **报数必须带口径名（中位 / 均值 / 分位）**。120–180 相位中位 +0.019、均值 +0.045，差 2.4 倍，源头只有 2 批 +0.63。跨轮引用不写口径 = 制造假矛盾。
3. **恒真的判据等于没有判据**。发现一条判据在当前批集上永远成立（如 86 批的 "0 catastrophic"），要替换它，不要加脚注。
4. **切片要切到"剔掉后缺口还在"**。60–120 的缺口在剔掉 9 批 invalid 后反而更深（−0.062 → −0.071），这才叫结构性缺口；剔掉就消失的只是尾部噪声。
5. **不相关也要报**。S 的 R² 与 P 的 relRMSE 不相关（14 批 S 崩、P 正常），这条本身是信息：两个通道不能合并处理。
6. **未查的不写结论**。D-44 只登记事实与候选方向，不写"因为 X 所以 Y"。
