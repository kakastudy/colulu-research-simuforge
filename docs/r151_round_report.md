## 1. 为什么要立这把尺

`yield_metrics()` 的 `rel_err_total` 是 `总产量_sim / 总产量_v3 - 1`——**一个标量和**。它只约束一条直线上的位置，留下两个自由度（峰高、峰后衰减速度）可以任意组合而互相抵消。R150 已给出最极端的一例：

| b50 | 数值 |
|---|---|
| 产量误差 | **−0.26%（达标）** |
| P 峰比 | **1.795** |
| P 末比 | **0.628** |
| P relRMSE | **0.848** |
| P R² | **−0.658** |

模型把峰顶抬高了 80%、又把后半段砍掉 37%，两处误差在积分里几乎精确抵消。**产量指标对此完全无感**——这不是模型恰好对，是尺子量不到。

所以 D-43 不是"再加个指标"，是**补一个维度**：把"总量对不对"扩成"总量对 + 形状对"。

## 2. 交付 1：`shape_metrics()`（引擎层，纯新增）

位置：`candidate/indpensim/v0.1/simulate.py`，紧随 `yield_metrics()` 之后。

```python
shape_metrics(sim, v3, channels=("P", "S"), phases=SHAPE_PHASES) -> dict
```

**三条口径决定**，每条都有踩过的坑对应：

| 决定 | 理由 |
|---|---|
| **按 `time_h` 对齐，不用行号** | `sim` 从 0.4 h 起记录（1149 行）、`v3` 从 0.2 h 起（1150 行）。按行号截断会整体错一格（R146 教训，R150 第八次口径修订）。本函数一律 `np.interp` 到 `sim` 的时间栅格 |
| **相位残差以实测峰值归一** | P 的绝对值跨批差 4 倍（峰值 ~2 到 ~8 g/L），绝对差值不可跨批平均。R149 的 `amp_ratio` 就是因为归一化分母选错（实测控制带 0.15–0.27）而作废 |
| **与 `trajectory_metrics()` 并存，不替换** | 后者按行号采 `n = min(len)`，是多处方共用的历史口径；直接改会一次性推翻全部历史可比性。D-43 的口径统一作为**独立待办**保留（见台账） |

相位切分沿用 R150：`0-60 / 60-120 / 120-180 / 180+`（h）。

每通道返回：`rel_rmse`、`r2`、`bias`（相对峰值）、`peak_meas/peak_sim/peak_ratio`、`t_peak_meas/t_peak_sim`、`end_meas/end_sim/end_ratio`、`drop_meas/drop_sim`、`phase{name: {mean, absmax, n}}`。

引擎新增函数**不被任何既有路径调用**，所以仿真行为必然不变。但"必然"不等于"已验证"，本轮做了逐批对照：把 `runs/r151_shape_baseline.json` 的 86 批与 R150 冻结的 `runs/r150_p_shape.json` 逐批比对。

| 量 | `max\|Δ\|` |
|---|---|
| P relRMSE | **0.000e+00** |
| P 峰比 | **0.000e+00** |
| P 末比 | **0.000e+00** |
| 产量误差 | **0.000e+00** |
| 四相位残差（86 × 4 = 344 个值） | **0.000e+00** |

两套实现（R150 的手写统计 vs R151 的 `shape_metrics()`）在 86 批上**逐位相同**。这同时验证了两件事：引擎未被扰动，以及新函数的口径与历史统计同源——不存在"换了实现数字就变了"的隐患。

> `--shape` 只影响 CLI 打印与 `data/processed/*_metrics.json` 的可选字段，默认关闭。

## 3. 交付 2：形状基线（86 批冻结参数）

工具 `tools/r151_shape_accept.py`，输出 `runs/r151_shape_baseline.json`。

### 3.1 主表

| 指标 | 中位 | P90 | max | min |
|---|---|---|---|---|
| P relRMSE | **0.1557** | 0.2473 | **0.8482**（b50） | — |
| P R² | 0.9412 | — | — | **−0.6583**（b50） |
| P 峰比 | 1.060 | — | 1.79 | — |
| P 末比 | 1.021 | — | 0.63 | — |
| P 峰时差（sim−meas） | **+0.0 h** | +12.2 h | — | −32.8 h（b18） |
| S R² | **0.454** | — | — | **−2.216**（b78） |

峰时差中位 0.0 h 说明**多数批峰的时点是对的**——误差主要不是"峰来早了/晚了"，而是幅值与峰后衰减。

### 3.2 分相位：中位数与均值必须分开看

| 相位 | 中位（R150 口径） | 均值 | 为负的批数 |
|---|---|---|---|
| 0–60 | −0.0421 | −0.0341 | 72/86 |
| **60–120** | **−0.0923** | −0.0625 | **65/86** |
| 120–180 | +0.0186 | **+0.0448** | 27/86 |
| 180+ | +0.0217 | +0.0367 | 14/84 |

均值与中位在 120–180 差 2.4 倍（+0.019 vs +0.045），因为少数批在那里有 **+0.63** 级别的正残差（b37/b50）。**这两个数都对，但不是同一个数**——R150 报的是中位、本轮汇总表给的是均值，跨轮引用时必须写清是哪一个，否则会得到"同一指标两个结论"的假矛盾。

### 3.3 切片：缺口集中在哪

| 切片 | n | P relRMSE 中位 | 60–120 中位 | 60–120 均值 | 120–180 均值 |
|---|---|---|---|---|---|
| 全量 | 86 | 0.1557 | −0.0923 | −0.0625 | +0.0448 |
| valid | 77 | 0.1462 | −0.0928 | −0.0710 | **+0.0228** |
| 主体（relRMSE ≤ 0.20） | 65 | 0.1367 | −0.0840 | −0.0596 | +0.0227 |

**读法**：把 9 批 invalid 剔掉后，120–180 从 +0.045 掉到 +0.023 —— 后段的"高估"几乎全部来自那 9 批。而 **60–120 的缺口剔不掉**（−0.062 → −0.071，反而更深）。这坐实了 D-42 的定位：**中段缺产素是模型的结构性缺口，与 pH 越界无关**。

## 4. 三个新发现

### 4.1 invalid 9 批 = D-41 的量化后果

9 批：b37 / b40 / b43 / b49 / b50 / b51 / b54 / b91 / b92，**全部**因 pH 越 7（`validity()` 的 two 类 flag：`pH 守卫前达 7.xxx ≥ 7.0` 或 `pH 被守卫钳位`）。

| 分组 | 峰比中位 | 120–180 均值 |
|---|---|---|
| valid（77） | **1.052** | +0.023 |
| invalid（9） | **1.238** | **+0.146 ~ +0.630** |

方向一致、量级一致：**pH 越界 → `Fb` 无限幅继续加碱（D-41 根因）→ 后段产素项被抬高 → P 峰高估、后段不回落**。R149 只证明了"越 7 不可逆"，本轮第一次给出它的**产量形状后果**。

注意这 9 批的产量都还在 ±5% 内（最差 b43 −4.12%、b59 不在此列但 +4.83%）——**又一次印证选产量当判据会漏掉它们**。

### 4.2 「0 catastrophic」在 86 批上是恒真命题

`classify_crash()` 的第一行是：

```python
if co2d.max() <= co2d_crit:   # 7.57
    return "normal", []
```

R151 实测：**86/86 批 `CO2d.max() <= 7.57`**，全部走这条早退分支。所以"0 catastrophic"这条红线在过去若干轮里**从未真正检验过任何东西**——它只说明"没有批在行为上越过生长抑制阈值"，不说明模型没有失效。

D-38 原先记的是"报告须带限定"。本轮升级处置：**该判据须替换**，不能靠加脚注糊过去。已在新验收工具里补一条有信息量的 hard 判据 **G2b：invalid 计数 ≤ 9**（当前恰好 9，作为不恶化基线）。

### 4.3 S 通道：14 批 R² < 0，与 P 的误差不相关（新债 D-44）

| 批 | S R² | S relRMSE | P relRMSE | valid |
|---|---|---|---|---|
| b78 | **−2.216** | 8.90 | 0.180 | Y |
| b22 | −1.412 | 6.79 | 0.158 | Y |
| b12 | −1.110 | 7.15 | 0.152 | Y |
| b89 | −0.688 | 6.06 | 0.184 | Y |

14 批 S 的 R² 为负，而它们的 P relRMSE 全在正常区间。**S 差与 P 差不相关** ⇒ 这不是"P 的问题连累 S"，是 S 自己的独立问题。

同时注意 D-40b 的关闭理由（"60–120 的 S 残差 +0.004，糖轨迹这一段是准的"）**仍然成立**——它是相位均值口径；而整段 R² 中位只有 0.454。两者不矛盾，但说明 **S 的误差不在 60–120 的中段，而在别处**（候选：0–60 初糖段的快速下降，或补料脉冲附近的抖动）。

本轮**未查**这一步，如实登记为 D-44（L2，观察项），不猜结论。

## 5. 交付 3：验收单入口 `tools/acceptance.py`

红线散在四个工具里，每次改动都要人工拼一遍。R149 之所以漏掉 pH 峰位，就是因为只看了产量。

```
python tools/acceptance.py                 # 86 批 + 确定性抽检，~9 min
python tools/acceptance.py --no-det        # 跳过确定性
python tools/acceptance.py --limit 12      # 冒烟
python tools/acceptance.py --json runs/x.json
```

分两层，**只有 hard 失败才 exit 1**：

| 层 | 判据 | 说明 |
|---|---|---|
| HARD G1 | 产量 `|err| <= 5%` 达 86/86 | GOAL 红线 |
| HARD G2 | catastrophic = 0 | **恒真**，保留但标注（见 4.2） |
| HARD G2b | invalid 计数 ≤ 9 | 补 G2 的信息量缺口 |
| HARD G3 | 确定性 `max|Δ| = 0`（抽 2 批双跑） | 非确定性会让所有标定结论失效 |
| SOFT | 6 条形状判据 | D-42 结项前只 WARN，不阻断 |

形状判据草案（`GATE`，写在 `r151_shape_accept.py` 里，单一来源）：

| 判据 | 阈值 | 当前 | 状态 |
|---|---|---|---|
| P relRMSE 中位 | ≤ 0.10 | 0.1557 | WARN |
| P 60–120 相位均值 | ≥ −0.05 | −0.0625 | WARN |
| \|峰比−1\| 中位 | ≤ 0.10 | 0.0605 | PASS |
| \|末比−1\| 中位 | ≤ 0.10 | 0.0211 | PASS |
| S R² 中位 | ≥ 0.60 | 0.4536 | WARN |
| 产量达标但 P relRMSE > 0.20 的批数 | ≤ 21 | 21 | PASS（擦线） |

**峰比与末比已经达标**，这很重要：说明模型不是"整体形状错"，而是**中段凹陷**这样一种特定形态。D-42 要修的是形状的一个局部，不是重构整个 P 曲线。

## 6. D-42 的可度量目标（由本轮基线推出）

| 目标 | 起点（R151 基线） | 目标值 | 为什么是它 |
|---|---|---|---|
| P relRMSE 中位 | 0.1557 | ≤ 0.10 | 与 60–120 相位缺口同向，一个旋钮应同时改善两者 |
| P 60–120 相位均值 | −0.0625 | ≥ −0.05 | 中段缺口的直接量 |
| 产量达标但 P 差 的批数 | 21 | ≤ 10 | 这才是"尺子量得到"的改善，产量数字不会动 |
| 峰比 / 末比 | 0.060 / 0.021 | 不得恶化 | 防止"抬中段"变成"整体抬高" |

**验收纪律**：D-42 的任何改动必须同时满足三条——产量 86/86 不破、invalid ≤ 9 不变差、峰比/末比不恶化。只改善中段而抬高峰顶的改动，视为失败。

## 8. 方法论

1. **新指标先与旧实现对齐，再谈结论**。`shape_metrics()` 与 R150 手写统计逐位相同（`max|Δ|=0`），否则"改善"可能只是换了算法。
2. **中位与均值是两个数**。120–180 相位中位 +0.019、均值 +0.045，差 2.4 倍，源头是 2 批 +0.63。报数必须带口径名。
3. **恒真的判据等于没有判据**。`classify_crash` 的早退分支让"0 catastrophic"在 86 批上永远成立。发现这类判据要替换，不要加脚注。
4. **切片要切到"剔掉后缺口还在"**。60–120 的缺口在剔掉 9 批 invalid 后反而更深（−0.062 → −0.071），这才叫结构性缺口；如果剔掉就没了，那只是尾部批的噪声。
5. **不相关要报出来**。S 的 R² 与 P 的 relRMSE 不相关（14 批 S 崩、P 正常），这条本身就是信息：两个通道的问题不能合并处理。
6. **未查的不写结论**。S 的误差在哪个相位、为什么，本轮没做，就只登记为 D-44。
