# R152 债务台账 —— D-42 的旋钮判定（门控不是缺口，但"宽门控 × 低产率"给出形状通道）

> 承接 `r151_debt_ledger.md`。仍在**算子层**（只动参数与覆盖口，不改方程结构）。
> 引擎改动：新增 3 个 opt-in 覆盖口（`mean_P`/`P_std_dev`/`P_crit_PAA`），**默认不传 ⇒ 逐位不变**。

## 一、本轮改判

### D-42　产素时间剖面　🟡 **从「无形状旋钮」改为「有形状通道，代价是重参数化」**

| 项 | 内容 |
|---|---|
| R150 原判 | 产素项 `r_p ∝ mu_p·a_1/2·P_inhib·DO2_P·PAA_P` 里没有形状旋钮；一阶旋钮改不动二阶形状 |
| R152 更正 | **有**。`P_std_dev`（门控宽度，par[3]）是**二阶**旋钮：它按 `s` 的函数形状改变门控，而不同相位的 `s` 不同 ⇒ 改变 `sd` 对不同相位的影响**不同** |
| 但这个旋钮不能单用 | `sd×2` 单独：中段 +0.086、后段 +0.090、产量 **+22.8%** ⇒ 选择性仅 0.95 |
| 必须配一个一阶旋钮 | `mu_p×0.60` 把总量压回 ⇒ `sd×2, mu_p×0.60, mean_P×1.10`：中段 **+0.052**、后段 **+0.001**、产量 **+5.0%**、选择性 **62** |
| 机制 | 窄门控（1.5 mg/L）下产素集中在 s≈2 mg/L；放宽到 3.0 后后段（s≈6.5）也开启，但 `mu_p` 降低把它压回原位，而中段因门控更宽、开启更充分，**净增速高于后段** |
| 状态 | **方向成立，但不可全局化**（86 批见下） |
| **86 批验证** | 最佳臂 `sd×1.8 / mu_p×0.66 / mean_P×1.10`：60–120 **−0.0625 → −0.0176（−72%，67/86 批改善、仅 1 批恶化）**、P relRMSE **中位 0.1557 → 0.1331**、\|峰比−1\| 中位 0.097 → 0.095、valid **77 不变** |
| **硬伤** | **产量逐批只有 51/86 在 ±5%**（min **−70.0%**、max **+98.5%**），均值 +1.73% 掩盖了异质。原因：`sd` 是全局参数但与每批自己的 S 轨迹耦合，各批 S 的绝对水平不同 ⇒ 同一个 `sd×1.8` 放大的倍数从 0.3 到 2.0 不等，`mu_p` 只能按同一比例压一遍 |
| 结论 | **中位指标全面改善、逐批产量崩** ⇒ 与 R149/R150 同型：全局参数在不同批上的有效杠杆不同 |
| 处置 | 转为「已知边界 + 不恶化守门」（路径 B），结构改动另立 **D-48** |

### D-38 遗留　`P_crit_PAA` 从嫌疑人名单删除　✅ **关闭（零语义）**

| 项 | 内容 |
|---|---|
| 原假设 | PAA 门控可能是 60–120 h 的缺口来源（R150 实测同相位 PAA **+33%**） |
| 实测 | `pcritPAA×0.5` 与 `×2` 对 60–120 相位的影响**都是 0.000**（4 位小数），只改变 120–180（±0.03） |
| 解释 | `PAA_inhib_P = 0.5·(1+tanh(y[29] − 200))`，实测 PAA ~1400 mg/L ⇒ `tanh(1200)` 已饱和 ⇒ 门控恒为 1 |
| 处置 | 该门控在实测 PAA 范围内**不存在**。除非 PAA 掉到 200 mg/L 以下（当前无此批），否则改它没有意义 |

## 二、本轮关闭

### D-42a　`mu_h`（水解）作为形状旋钮　✅ **关闭（方向相反）**

| 项 | 内容 |
|---|---|
| 动机 | 水解**不耗糖** ⇒ 是唯一能同时满足「S 对（+0.4%）而 P 低 22%」的通道 |
| 实测 | `mu_h×0.9`：中段 +0.014、**后段 +0.056**、产量 +13.1% ⇒ 选择性 0.24 |
| 原因 | 水解损失 ∝ `mu_h·P`，而 60–120 h 的 P 只有 0.5–3 g/L（该相位总水解 ≈ 0.23 g/L），后段 P 大 ⇒ 降 `mu_h` 主要回收后段 |
| 数值上界 | 即使 `mu_h×0.8`，中段也只回收 0.05 g/L，远不够补 22% |

### D-42b　`mean_P` 单独作为形状旋钮　✅ **关闭（主要作用于后段）**

| 项 | 内容 |
|---|---|
| 实测 | `meanP×1.25`：中段 +0.015、后段 **−0.053**；`meanP×1.5`：中段 +0.002、后段 −0.161、产量 **−25.2%** |
| 结论 | 它修的是后段高估，不是中段缺口。只能作为**辅助**（本轮最终臂里 `meanP×1.10` 把后段从 +0.006 压到 +0.001） |

## 三、新增

### D-46　`sd×2 + mu_p×0.60` 是重参数化，不是微调　🔴 **新，L2**

| 项 | 内容 |
|---|---|
| 事实 | 候选臂把 `P_std_dev` 从 1.5e−3 提到 3.0e−3（×2）、`mu_p` 从 0.012 降到 ~0.0072（×0.60）、`mean_P` 从 0.002 提到 0.0022（×1.10） |
| 含义 | `mu_p` 降 40% 意味着"产素比速率只有原标定的 60%"，全靠门控放宽补偿。数学上等价，物理上是**重新参数化** |
| 风险 1 | 两个参数**强耦合**：换批/换工况时它们会一起漂，单参数的可移植性不再成立 |
| 风险 2 | 12 批的产量基线（+0.26%）与 86 批（−0.07%）不同 ⇒ 12 批的最优 `mu_p` 不能直接搬到 86 批 |
| 风险 3 | 抬中段必然抬峰：12 批峰比 1.159 → 1.171，逼近 1.10 的 soft 线 |
| 待办 | 86 批整批验证；若通过，须在契约里把它标为**"标定前提变更"**（与 D-36 同级），不能当作普通参数微调 |

### D-48　`r_p` 的时间形状需要结构改动（D-42 的唯一根治路径）　🔴 **新，L3（需用户批准）**

| 项 | 内容 |
|---|---|
| 事实 | 算子层三条路已全部走完：R149（pH 三系数全平移、`γ1` 悬崖）、R150（`k_deg` 不可辨识）、R152（`sd` 可修形状但产量逐批崩） |
| 结构缺口 | `r_p = mu_p·a_1/2·P_inhib(s; sd)·DO2_P·PAA_P`，其中 `mu_p` 是**常数**。真实产素能力随菌龄/形态衰减（A1→A3→A4），而模型里这条链**没接线**（`k_vac` 从未出现在 86 批参数里 ⇒ `r_vac ≡ 0` ⇒ A3/A4 恒 0，R137 已记录） |
| 提案 | 让 `mu_p` 随菌龄衰减：`mu_p_eff = mu_p · exp(-k_age·age)` 或 `mu_p · (A1/(A1+A3+A4))`。这会让不同批**自动**适配（老得快的批产素降得快），而不是靠一个全局 `sd` 硬撑 |
| 代价 | 改方程结构 + 重新标定 86 批全部产量参数；属 D-36 级别的"标定前提变更"，**必须用户批准** |
| 前置 | 先把 `k_vac` 接线（R137 判定"接线无收益且有害"，但那是在 `mu_p` 固定的前提下；若 `mu_p` 随形态衰减，接线的意义会变） |

## 五、纪律（新增）

1. **参数索引只能从 `model.py` 的参数解包段读**（`grep -n "= par\["`），不能按 `params.py` 注释的相邻行推断。见 D-47。
2. **先证伪"缺口在哪"，再扫旋钮**。若跳过门控探针直接扫 `sd`，会看到"中段抬起来了"就以为找到解；探针显示中段门控本来就开着 86%，`sd` 抬的其实是后段。
3. **选择性必须定义成比值**：`d(60–120) / |d(120–180)|`。只看中段改善会把 `sd×2`（+0.086）当好臂，而它同时把后段抬了 +0.090、产量抬了 23%。
4. **二阶旋钮 + 一阶旋钮的组合可以造出新自由度**，但必须同时报**总量**与**形状**，否则"改善"可能只是"整体抬高"。
5. **重参数化要单独立债**（D-46），不能混在"参数微调"里。40% 的参数改动会改变可移植性前提。
