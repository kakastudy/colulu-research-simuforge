## 一、本轮改判

### D-48　`r_p` 的时间形状结构改动　🟡 **部分成立：缺口与机制确认，全局解不存在**

| 项 | 内容 |
|---|---|
| 原提案（R152） | 让 `mu_p` 随菌龄/形态衰减（`mu_p·exp(−k_age·age)` 或 `mu_p·(A1/(A1+A3+A4))`），使不同批自动适配 |
| **形式 0 直接不可用** | `A1/(A1+A3+A4)` 在本模型里**恒等于 1**：`k_vac` 从未接线（R137）⇒ `A3/A4` 恒 0.001 量级，而 `A1` 从 0 涨到 20 且仍在涨。该形式没有任何调节力 |
| **原假设被证伪** | R153 探针（`tools/r153_age_probe.py`，88 批）从实测 P 反解所需 `mu_p` 倍率：60–120 中位 **0.957**、120–180 **1.007**、180+ **0.932** ⇒ 60 h 后常数 `mu_p` 已正确。180+ 相对中段 **升 39 批 / 降 8 批 / 平 41 批** ⇒ "后段衰减"方向错误 |
| **真实缺口** | **0–60 h 生长期产素 ≡ 0**。`P_inhib` 中心 2 mg/L、宽 1.5 mg/L；b3 在 40 h 残糖 13 mg/L 时 `P_inhib = 2e-13`，模型产 0.04 g/L，实测 **2.49 g/L**。所需倍率 0–60 中位 **1.631**、**51/81 批 >1.1**；另 **7/88 批**该相位连一个有效点都没有（门控全关） |
| 物理依据 | 青霉素发酵标准双相描述（Pirt）：`r_p = (α·μ + β)·X`。本模型只实现 β 项，且被残糖门控彻底关死 ⇒ α 项缺失 |
| 实现（第五版形式） | `gate = (1−λ)·P_inhib + λ·clip(μ_act/mux_max,0,1)`，`mu_p` 乘 `1/(1−λ)` 精确补偿。idiophase 的 `μ_act→0` ⇒ `gate=(1−λ)·P_inhib`，乘回 `1/(1−λ)` 后**逐值等于 `P_inhib`**（后段不动）；生长期 `gate≈λ/(1−λ)`（只在此新增） |
| **形状确实可修** | 12 批：λ=0.30 把 60–120 从 **−0.064 → −0.033（改善 48%）**，relRMSE 中位 **0.159 → 0.146** |
| **代价是产量（1:1 耦合）** | λ=0.60：12 批产量 Δ **全部为正**，均值 **+5.4pp**、最大 **+28pp** ⇒ 撞 86/86 ±5% 红线；产量达标从 10/11 掉到 6/11 |
| 反相关信号 | **越需要修的批越安全**：b3（60–120=−0.097）Δyield 仅 **+1.88pp**；b60（−0.026，本就准）**+13.16pp**。原因是缺产素的批生长期短，加产素空间小 |
| 配对补偿 | 有效但**逐批标定**：b3 λ=0.6/`mup×0.85` ⇒ relRMSE **0.2249→0.1819（−19%）**、产量 **+0.45%**、峰比 1.232→1.184；b22 最优是 `mup×0.92`（relRMSE 0.1579→**0.1197**、产量 −2.24%）；**b22 在 ×0.78 崖崩**（产量 −67.5%、invalid） |
| 状态 | **部分成立**：缺口真实、机制清楚、结构改动物理正确，但**全局 λ 不可行**；批级二参数标定可用但失去预测性，且可行域边界呈崖状 |
| 处置 | 保留 `mu_p_growth` 为 opt-in 标定接口（默认 0）；转 D-50/D-51 |

### D-50　`P_inhib` 门控宽度与实测产素启动点不匹配　🔴 **新，L2**

| 项 | 内容 |
|---|---|
| 事实 | `P_std_dev = par[3] = 1.5 mg/L`、`mean_P = par[4] = 2 mg/L`。实测 b3 在残糖 13 mg/L 时已大量产素，模型 `P_inhib` 此时 2e-13 |

## 五、纪律（新增）

1. **参数索引只能从 `model.py` 解包段读**（D-47 第二次派上用场）。本轮
   `mu_p=par[0]`、`P_std_dev=par[3]`、`mean_P=par[4]`、`mu_h_scale=par[18]` 全部核对后才动手。
2. **`sim["pH"]` 已经是 pH 值，不能再取 `−log10`**。重取会把 `mu_h` 从 4.6e-3
   放大到 13.8（3000 倍），使"所需倍率"出现 10⁵ 量级。反解类工具**必须先自检基线**（mult≈1）。
3. **潜在速率 ≠ 实际速率**。`mu_e` 不含 Monod 糖项，用它做生长耦合会把增益漏到 idio­phase
   （第四版 180+ 从 +0.045 涨到 +0.163）。凡"生长相关"，先确认含不含底物限制。
4. **形状旋钮必须同时报产量代价**。只报"λ=0.6 修好 67% 形状"会掩盖 +5.4pp 产量。
5. **同一参数的多个实现版本不能混在一张表里**。本轮 4 个 pilot json 对应 4 种形式，
   混看会得出"λ=0.25 让 b55 产量 −87%"的错误结论（那是已废弃的形式②）。
6. **崖状响应要单独标注**。b22 在 `mup×0.85→0.78` 从 −7.3% 到 −67.5%，插值外推危险。
