## 一、本轮关闭

### D-44　S 通道 14 批 R²<0；S 与 P 不同步　✅ **关闭（拆成两种误差）**

| 项 | 内容 |
|---|---|
| 工具 | `tools/r154_s_resid.py`，**88 批**（86 验证集 + b89/b99），11 min 15 s |
| 误差一：初始峰 | `s_peak_ratio` 中位 **1.196**；峰时 模型 **8.7 h** vs 实测 **7.0 h**；`s_r2_hi`（只在 `S>5%·峰` 的点算）中位 **−1.554** ⇒ 连"有糖段"都没拟合上 |
| 误差二：残糖水平 | 30–120 h 的 S 中位：模型 **2.02 mg/L** vs 实测 **1.72 mg/L**；比值中位 **1.129**（P10 0.686 / P90 1.507） |
| **两者关系** | R² 的方差几乎全来自 0–20 h 的初始峰（1–57 g/L），**残糖段的 2 mg/L 波动对 R² 贡献 ≈0**；而 `P_inhib` 只由残糖决定 ⇒ **用 R² 验收 S 会系统性看不见门控的自变量** |
| 判定 | 不是"S 整体错了"，是"S 的两个用途需要两把尺"。`s_r2` 保留为**初始相拟合度**指标；门控相关判定改用残糖中位与门控占空 |
| 顺带排除 | `s_resid_ratio` 中位仅 1.13 ⇒ "模型残糖高 3–5 倍"的说法**不成立**（那是 20–60 h 窗口的局部现象，不是 30–120 h 的中位） |

### D-50　`P_inhib` 门控阈值与实测产素启动点不匹配　✅ **关闭（改判为"结构合成"）**

| 项 | 内容 |
|---|---|
| 原假设 | 门控阈值/宽度参数调错了，改参数即可 |
| 反证 1（R152） | 扫 `P_std_dev ×1.8`：形状大幅改善（60–120 −0.0625→−0.0176）但 86 批产量只 51/86 达标 |
| 反证 2（R153） | 补 `α·μ` 项（`mu_p_growth`）：形状可修，产量与形状 **1:1 耦合**，λ=0.60 产量均值 +5.4pp |
| 反证 3（本轮） | `sd×1.8` + **逐批**反解 `mup`：产量保持 **0/12**、valid **11→8**、b55/b59/b60 崩到 **−42.8/−75.9/−59.4%** |
| 改判 | 阈值不是"调错"，而是 **门槛（半宽 1.5 mg/L）+ 正反馈（`Y_sP·r_p` 占进料 27–50%）+ 开环进料** 的合成结果。三条改参数的路已全部走完 |
| 转 | D-52（机制）、D-53（不可辨识）、D-54（唯一根治） |

### D-51　`mu_p_growth` 批级二参数标定　✅ **关闭（否定）**

| 项 | 内容 |
|---|---|
| 原设想 | `probe` 判某批缺产素 ⇒ 开 λ + `mup×`，逐批可用 |
| 实测 | `yield ∝ mup` **不成立**：`sd18` 臂下 12 批全部偏离 >0.5pp（0/12 保持） |
| 根因 | 见 D-52：`mup` 与产量的关系是**阶跃**，不是比例；b59 从 ×1.00→×0.95 掉 **32pp** |
| 结论 | 逐批标定**在本模型上不可工程化**，除非先解决 D-54 |

### D-40（R150）　"`params["mup"]` 是状态变量初值、`mu_p` 无覆盖口"　✅ **勘误关闭（判断有误）**

| 项 | 内容 |
|---|---|
| 事实 | `simulate_open_loop` 里 `par = make_params(..., mup=params.get("mup", 0.041))` ⇒ **`params["mup"]` 就是 `par[0]`** |
| 证据 | `COMBINED[22]["mup"] = 0.065`，是 `make_params` 默认 0.012 的 **5.4 倍**；用 0.012 离线重算 `dy[3]`，残差是 `dP/dt` 的 5 倍，换成 0.065 后残差 6% |
| 影响 | R150/R152/R153 三轮里凡以"`mu_p` 无覆盖口"为前提的设计（如"只做诊断不加引擎"）**结论不受影响**（它们用的是 `mup` 或 `mu_p_scale`），但**表述是错的**，且遮蔽了"本模型标定范式本来就是逐批"这一事实 |

## 二、本轮新增

### D-52　产素—残糖正反馈导致双稳态　🔴 **新，L2（机制）**

| 项 | 内容 |
|---|---|
| 证据 | `tools/r154_bistable.py`，4 批 × 10 档 `mup`（0.60–1.20） |
| 阶跃 | b59：×1.00 **+4.8%** → ×0.95 **−27.5%** → ×0.90 **−33.4%**；b60：×1.00 −0.2% → ×0.95 −11.2% → ×0.90 −58.6% |
| 弹性 | 0.95→1.05 中心差分（pp 每单位 `mup`）：b3 **+0.3**、b55 **+71.2**、b59 **+411.1**、b60 **+251.9** ⇒ **逐批差 3 个量级** |
| 崖位 | 每批不同：b3 在 0.80–0.85 之间、b55 在 0.90–0.95、b59 在 0.95–1.00 |
| valid 同步 | `mup×0.90` 只有 b3 仍 valid；`×0.95` b59 失效；`×1.00` 起四批全 valid ⇒ **有效域边界与产量崖重合** |
| 机制 | `dy[0]` 有 `−Y_sP·r_p`（`Y_sP=0.9`），产素耗糖占进料 **27–50%**（b3 0.45 / b55 0.36 / b59 0.32 / b60 0.27，60–180 h）。`r_p↓ → 糖汇↓ → S↑ → 门关 → r_p↓` 是正反馈 |
| 后果 | 任何"全局乘数"对所有批是同一个 `Δmup`，但效果从 −0.3pp 到 −120pp ⇒ **全局标定在结构上不可行** |
| 可用性 | 本工具即**稳定性裕度**测量器：任何再标定前先扫崖位 |

### D-53　残糖水平结构性不可辨识　🔴 **新，L2（结论）**

| 项 | 内容 |
|---|---|
| 事实 | 进料糖 **~0.95 g/L/h**；三汇：产素 **0.26–0.50**、生长 ~0.4、维持 ~0.1；残糖 = 残差 ≈ **0.002 g/L** |
| 精度要求 | 要把 0.002 g/L 预测到 ±50%，需在 1.0 g/L/h 的收支上做到 **0.01%** 精度 |
| 后果 | 任何对 `Y_sX`/`c_oil`/`mup`/`m_s` 的常规标定都会把残糖推过门控上沿（3.5 mg/L）⇒ **"修 S 以修门控"这条路不存在** |
| 推论 | 若未来仍要 S 精确，只能测 **通量**（OUR/CER 已可测）而不是 **浓度**，或引入 D-54 的闭环 |

### D-54　缺葡萄糖闭环（唯一根治路径）　🔴 **新，L3（需用户批准）**

| 项 | 内容 |
|---|---|
| 提案 | 让 `Fs` 不再是纯回放，而是"回放 + 残糖反馈修正"（PI 控制，目标 2 mg/L）；或让门控不依赖**瞬时** S（用 OUR/CER 反推的生长限制度，那是可测的） |
| 物理依据 | 真实 IndPenSim 的 `Fs(t)` **本来就是控制器输出**，它把残糖钉在 2 mg/L；本模型开环回放它，一旦偏离就无自愈机制 |
| 代价 | 契约从"开环 I/O 回放器"变成"带控制器的仿真器"；不再逐位复现实验批次的进料剖面 ⇒ 违反 GOAL §5 的边界，须裁决 |
| 备选 | 若不批准，则 P 形状的 60–120 h −0.0625 定为**已知边界**，由 `tools/acceptance.py` 的 SOFT 判据守门 |

## 四、纪律（新增）

1. **"参数没有覆盖口"必须去读构建处**（`simulate_open_loop` 的 `make_params(...)` 调用），
   不能只看 `model.py` 有没有出现 `params[...]`。R150 的 D-40 因此错了 4 轮。
2. **残差型状态（补料期的 S）不能用 R²/relRMSE 验收**：方差全来自初始瞬态，均值才是下游的自变量。
3. **先算可辨识性，再花时间标定**：S 需要 0.01% 通量精度 ⇒ 一开始就不可能。
4. **带门控的模型里 `yield ∝ 参数` 是错的**：反解—补偿式标定必须先验单调性（b59 在 0.95→0.90 掉 32pp）。
5. **相关性强 ≠ 因果**；−0.92 能当因果是因为同时有三分位切片（门开的批 +0.0008）与机制（糖汇 27–50%）。
6. **改判旧债要写明旧结论错在哪**（本轮纠正 R150 的 `mup` 判断）。
