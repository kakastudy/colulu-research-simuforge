# R155 债务台账 —— 闭环装不进去：进料可行域 < ±1%（关闭 D-54 / D-38 / D-45）

> 承接 `r154_debt_ledger.md`。本轮把 R154 留下的唯一根治路径（D-54，葡萄糖闭环）实施到底并**否定**它，
> 同时关闭验收层两条债（D-38 判据恒真、D-45 轨迹口径）。引擎新增 2 个 opt-in 执行器
> （`fs_ctl` / `fb_limit`）+ 2 个只读函数（`classify_health` / `trajectory_metrics(align=)`），
> **默认全部关闭，`max|Δ| = 0` 已由零效应控制臂证明**；`model.py` 逐字节未变。

## 一、本轮关闭

### D-54　缺葡萄糖闭环（唯一根治路径）　✅ **关闭（否定）**

| 项 | 内容 |
|---|---|
| 原假设 | 实测 `Fs(t)` 是控制器输出、把残糖钉在 2 mg/L；模型开环回放它，一旦偏离就没有回拉机制，门控把偏离放大成开关 ⇒ 加反馈即可根治 |
| 装置 | `params["fs_ctl"]`：`u = clip(1 - w*(kp*e + ki*I), u_lo, u_hi)`，`Fs = Fs_rec*u`，`w = 1/(1+(S/s_act)²)`；支持 `t_on/t_off` 时间窗 |
| 零效应 | `u_lo=u_hi=1.0` 与 `t_off=0` 两种退化配置，b3 的 `max|ΔS| = max|ΔP| = 0.000e+00` |
| 结果 1（全域/门控邻域） | b3：`pi_a` **−99.98%**、`pi_gate` **−98.35%**；门控占空 0.170→0.000/0.083 |
| 结果 2（时间窗 4 档 × 5 批） | `pi_w60` −99.40% / `pi_w60m` −99.18% / `pi_w45` −99.98% / `pi_w120m` −98.87%；**门控占空没有一次变好** |
| 失败点 | b3 @70 h pH 6.598 → @80 h **3.002**（守卫钳位）→ 糖停止消耗 → S 从 476 mg/L 涨到 **78 373 mg/L**。**不是控制器逻辑错，是 pH 被推过崖** |
| 决定性反证 | `r155_fs_envelope.py` 静态缩放（无反馈）：12 批在 u=0.99 / 1.01 各有 **5 批**破 ±5%（最差 −30.1% / **−100%**）；**只有 u=1.00 时 12 批全在 ±5% 内** |
| 单批因果 | b22：u=0.99 pHmax 6.798 valid → u=1.01 pHmax **7.279**、钳位、**−100%**（上界=1.00）；b59：u=0.99 pHmax **6.999** valid → u=0.98 **7.210**、钳位（下界=0.99） |
| 量级对比 | 闭环需要 **±30%** 的进料调节，可行域 **< ±1%** ⇒ 差 **30 倍** |
| 判定 | **控制器在本模型上装不进去**。不是设计问题，是可行域问题。任何"再调一个增益"的尝试都不会有结果 |

## 三、本轮新增

### D-55　pH 方程的 `basic` 分支数值病态是可行域窄的根因　🔴 **新，L2（机制 / 数值）**

| 项 | 内容 |
|---|---|
| 事实 | R148 已记载：`basic` 分支含 `−Kw/H⁺` 正反馈，`t* = H⁺²/(2Kw)`（pH 7.0→0.5 h）；`guards()` 把 `y[6] ≤ 0` 钳成 3.0 |
| 本轮证据 | 闭环只把 pH 抬了 **0.03–0.05**（6.708 vs 6.660）就掉到 3.000；`Fs +1%` 令 b22 pHmax 从 6.798 跳到 7.279 并钳位；`Fs +4%` 令 3 批钳位 |
| 推论 | 可行域窄**不是物理的**，是数值的：真实发酵罐的 pH 不会因为越过 7 就在 0.5 h 内崩到 3.0。**墙是这套方程在 `H⁺ → 0` 附近的病态造成的** |
| 为什么它是"解锁"而不是"标定" | 它不改任何动力学系数、不改产量标定；它只让 pH 在 7–9 区间有**有界的解**。若成功，可行域可能从 ±1% 拓到 ±10%，闭环（D-54）与形状旋钮（D-42）才有空间 |
| 候选形式（待 R156 设计，全部 opt-in / 默认关闭） | ① `basic` 分支改用有界形式（如 `B/(1+H⁺/Kw)` 的稳定化）；② `H⁺` 状态改对数变量（`pH` 本身作状态）；③ 在 `pH > ph_hi` 时把 pH 方程降级为代数约束（实测 pH 是受控量，R149 已证）。三者都必须先过 `max|Δ|=0` 与 `r155_fs_envelope` 的"域宽"对照 |
| 风险 | 改变 pH 方程会动到 86 批的钳位批（b37/50/51/91/92）—— 那 4 批的产量达标**依赖**钳位（本轮 D-41 再次证明 +68pt），所以修好 pH 后**必须重新标定 mu_p/k_deg**（回到 D-36 的联合求解） |
| 与 D-36 的关系 | D-36（钳位改写动力学）是**现象**，D-55 是**机制**。修 D-55 会让 D-36 的前提消失，二者必须一起做 |

## 五、下一步（R156 建议）

1. **主攻 D-55**：设计 pH 方程的三种稳定化候选，先在 **b22 / b59 / b37 三批**上验证
   （b22 上界 1.00、b59 下界 0.99、b37 钳位批），判据是"**`r155_fs_envelope` 的 ±1% 域宽能拓到多少**"，
   而不是"pH RMSE 降多少"。
2. **不重标定就不看产量**：D-41 已证明产量达标依赖钳位，pH 修好后产量必然偏移（b37 +68pt）。
   顺序必须是：先拓域 → 再联合标定 `mu_p/k_deg` → 最后才看产量与形状。
3. 若 D-55 三种候选全部失败（pH 仍不可控），则**接受边界**：把 60–120 h 的 −0.0625 写进 README
   的「已知边界」，转 §4.4 故障复现与 §4.5 I2/I3，M4 按"L1 原型 + 显式边界"交付。
