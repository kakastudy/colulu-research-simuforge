## 一、本轮关闭（部分）

### D-55　pH 方程 `basic` 分支数值病态　🟠 **机制侧关闭 / 推论侧证伪**

| 项 | 内容 |
|---|---|
| 原假设 | `basic` 分支含 `−Kw/H⁺` 正反馈 ⇒ pH 越 7 后 0.5 h 必崩 ⇒ **可行域窄是数值的、不是物理的** ⇒ 修它能让可行域从 ±1% 拓到 ±10% |
| **机制侧：病灶在公式层定位** | `tools/r156_ph_probe.py` 逐点抓 `dy[6]`：pH > 7.6 时 **`\|dy[6]\|/OH⁻ = 0.994`** ⇒ 状态是 `H⁺`、驱动项却是 `OH⁻` 口径；`OH⁻/H⁺ = 10^(2(pH−7))` ⇒ pH 9 时量级差 1e4 倍，一步把 `H⁺` 打成负数 |
| **符号反向** | pH 6.99–7.05 区间已有 **95%** 的 `dy[6] < 0`（该回酸时反而更碱）⇒ 方程在 pH 7 附近就失去负反馈 |
| 时间常数 | pH 7.0013 → 9.57 用时 **1.07 h**；理论 `t* = H⁺²/(2Kw) = 0.497 h`（同阶） |
| **修法** | `u ≡ Kw/H⁺ − H⁺` ⇒ `du/dH⁺ = −(Kw/H⁺² + 1)` ⇒ `d[H⁺]/dt = (du/dt)/(−(Kw/H⁺² + 1))`。**不动点不变**（`u = u_eq ⇔ H⁺ = H_eq`），只改阻尼；不动任何动力学系数 |
| 零效应 | `ph_fix=0` 时 b3 `max\|dP\| = max\|dpH\| = 0.0`；不进 basic 分支的批逐位不变（b3/b22 全字段相同） |
| **修法效果** | 5 批钳位批：pH_max 7.267–9.185 → **7.002–7.072**；pH_end 3.00 → **6.61–7.00**；钳位次数 **1 → 0**；86 批中 **77 批 `max\|Δ\| = 0`**（与「只在 pH ≥ 7 触发」的理论预测一致） |
| **推论侧：证伪** | `ph_fix=1`（未重标）下 7 批 × 6 档**全部 0 钳位**，但**域宽没变宽**：b22 在 u=1.05 仍 **−99.97%**（此时 clamp=0、pH_max 仅 7.070）。⇒ **pH 崩溃是数值的；进料域窄是标定的**（那 5 批的 `mup` 是在「pH 会崩、后期停产」的世界里标的） |
| 重标后的域宽 | 同口径（5 批 × u∈{0.98,0.99,1.01,1.02}）对照原样：减料侧最差 \|Δ\| **58.09 → 13.75 pp**（扩约 4 倍），破线批数 4 → 2；加料侧仍被 **b22** 卡死（−99.75 pp） |
| **判定** | **数值病已消除（可复用）；「域宽可拓到 ±10%」不成立 —— 实际约 ±2%（4/5 批），天花板由 D-57 决定，不由 pH 决定** |

## 二、本轮维持 / 量化

### D-52　产素—残糖正反馈导致双稳态　🟡 **大幅缓解（弹性跨批差从 3 个量级降到 3.4 倍）**

| 项 | 内容 |
|---|---|
| R154 实测 | `mup` 弹性跨批差 **3 个量级**（b3 +0.3 / b55 +71 / b59 +411 / b60 +252 pp per unit mup）⇒ 批级标定不可能 |
| R156 实测（`ph_fix=1`） | 弹性 **+205…+692 pp/mult**（b51/b91/b50/b37），跨批差 **3.4 倍**；所需重标倍率 **中位 0.868、范围 0.834–0.946** |
| 含义 | **双稳态的严重程度依赖 pH 病态**。pH 修好后，双稳态从「不可标定」降级为「可用单一全局策略（×0.86）+ 5 批微调」 |
| 残留 | b22 仍是双稳态批（`mup` 0.3→0.9 产量恒 −99.9%，1.0 跳到 32.7）⇒ 另立 **D-57** |

### D-36　钳位是产量标定的支撑结构　🟡 **量化并给出解**

| 项 | 内容 |
|---|---|
| R155 证据 | `fb_limit` 限碱：b37 产量 −2.29% → **+67.99%**（精确重演 R147） |
| R156 量化 | `ph_fix=1` 移除钳位后，5 批产量 **+21.16% ~ +69.11%**（b37 +69.11 / b50 +60.26 / b91 +27.51 / b51 +23.82 / b92 +21.16） |
| 解 | 候选基线 v2：5 批 `mup` 分别 ×0.850 / 0.834 / 0.868 / 0.868 / 0.946 ⇒ **86/86 产量在 ±5%**，且 **catastrophic 4 → 0**、P relRMSE max **0.8482 → 0.4303** |

### D-53　残糖结构性不可辨识　🟡 **维持（未新增反证，也未推翻）**

R154 的论证（0.95 g/L/h 收支上的 0.002 g/L 残差需 0.01% 通量精度）不受本轮影响。
本轮未做残糖相关实验。

### D-41　回放的 `Fb` 无限幅　🟡 **维持（降级为下游症状）**

pH 数值病修好后，`Fb` 无限幅的后果从「pH 崩到 3.0」变成「pH 越 7 后水解加快」
（b22 u=1.05：pH_max 7.070、无钳位、产量 −99.97%）。仍需 L3 级 `Fb` 闭环，但不是根因型阻断项。

### D-42　60–120 h 产素缺口　🟡 **维持（v2 下未改善，且验收口径略恶化）**

候选基线 v2 的 P 相位 60–120：跨批**中位数** **−0.0923 → −0.0927**（几乎不动），
跨批**均值**（验收 SOFT 判据口径）**−0.0625 → −0.0683**（**恶化 0.0058**）。
⇒ 该缺口**与 pH 病态无关**，是独立问题；D-42 需等 D-57 给出连续旋钮后才能重开。

> **口径纪律（新增）**：同一指标在两套口径下可给出**相反方向**的结论
> （中位数口径说"没变"，均值口径说"变差了"）。引用相位指标时**必须带口径**，
> 否则会把"无变化"报成"改善"。这是 R156 验收复核时才发现的（v2 已按两套口径分别复算）。

## 三、本轮新增

### D-56　`validity()` 的 pH 越域判据与物理可行域不一致　🟡 **新，L2（口径）**

| 项 | 内容 |
|---|---|
| 事实 | 候选基线 v2 下，9 批越 7 批的 pH_max 为 **7.001–7.126**、pH 末值 **6.46–7.03**、**产量全部达标**、**0 钳位**、`health` 全部 `degraded`（无 catastrophic） |
| 但 | `validity()` 仍把这 9 批判 `invalid`（判据含 pH 越 7.0）⇒ valid 仍是 **77/86** |
| 含义 | pH 7.00–7.13 是青霉素发酵的**常见操作区间**（实测 pH 全程 6.3–6.8，模型越界幅度仅 0.1–0.4）⇒ 判据过严，把「略越 7」与「崩到 3.0」混为一谈 |
| 修法方向 | 判据改成「pH 是否落在**守门员钳位**或远离实测区间」而非「是否 ≥ 7.0」；**必须报分布不能只报计数**（R151 的 D-44 教训） |
| 预期收益 | valid 从 77/86 → **86/86**（若口径确认） |
| 风险 | 低（只改验收层判据，不动引擎） |

### D-57　`b22` 类双稳态批：`mup` 是不连续旋钮　🔴 **新，L2（机制）**

| 项 | 内容 |
|---|---|
| 事实 | b22 在 `ph_fix=1` 下：`mup` 倍率 0.3 / 0.5 / 0.65 / 0.8 / 0.9 的产量**恒为 −99.9%**（P 峰 0.069→0.129），到 1.0 突然跳到 **32.685**（P 峰 32.7）。b37 同型但更缓：0.84 → −64.06%，0.85 → +1.88%（P 峰 12.65 → 30.20） |
| 机制 | 产素启动是**阈值型**：底物门控 `P_inhib`（高斯门）与生长相残糖耦合，构成 R154 描述的产素—残糖正反馈；`mup` 只是把系统推过阈值，不是连续调节器 |
| 为何重要 | 它是**进料域宽的硬约束**：候选基线 v2 下 5 批中 4 批能承受 ±2%，b22 在 u=1.01 仍 −99.75 pp ⇒ **D-54（葡萄糖闭环）的天花板由 b22 决定** |
| 为何不能用 mup 修 | b22 的 base 产量本就正常（−0.15%），不需要重标；而任何 mup 微调都会让它翻面 |
| 候选旋钮 | 门控宽度 `sd` / 门控中心 `mean_P` / 水解 `k_deg`（R152 已证 `sd` 是二阶、`mu_p` 是一阶，组合可解耦形状与总量） |
| 判据 | 若能在 b22 上找到**连续**调节产素启动的旋钮（响应不连续度 < 5 pp），则 D-54 重开；否则闭环控制器在这套方程里**永久装不进去** |
