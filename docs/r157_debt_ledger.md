### D-69　连续性判据的**二分器**平局缺陷 ⇒ 假阳性 CONTINUOUS　🔴 **新，L2（判据）**

| 项 | 内容 |
|---|---|
| 现象 | v1 版 `tools/r157_bistab_knob.py` 报 `sd`（门控宽度 `P_std_dev`）为 **CONTINUOUS**（细化最大相邻 0.00 pp）。但**工具自己的数据否定了它**：二分把区间收敛到 `[0.00149951, 0.0015]`，而该区间 32 个密采样点**全部**落在高端（−0.151%…−0.148%）⇒ **跳变根本不在区间内** ⇒ 区间没夹住跳变，判定无效 |
| 根因 | v1 的二分更新规则 `if abs(ym-ylo) <= abs(yhi-ylo): lo=mid else: hi=mid`。当跳变接近 100 pp（`ylo=-100%`、`yhi=0%`）且中点落在**高端分支**时，`abs(ym-ylo) ≈ abs(yhi-ylo)`，`<=` 的平局判定把高端中点**错记到低端** ⇒ 区间塌陷到单一分支 ⇒ 密采样全在同侧 ⇒ 假阳性 |
| 修法 | ① 二分更新改为**以响应区间中点为界**（`if ym < (ylo+yhi)/2: lo=mid else: hi=mid`）—— 对任意跳变幅度都正确；② 判据主证据改为**区间响应跨度收缩**（连续 ⇒ 跨度几何收缩；不连续 ⇒ 跨度恒为满跳变），**不依赖采样点落在哪一侧**；③ 新增**区间有效性校验**：粗扫跨度 > 20 pp 但密采样全在同侧 ⇒ 判 `BRACKET_INVALID`，**不得判 CONTINUOUS** |
| **v2 也有缺陷（判据自身失效的第二形态）** | v2 的「以响应区间中点为界」对**单调光滑**函数会收敛到「响应取中值的那一点」而**不是跳变处** ⇒ 区间里根本没有跳变 ⇒ 跨度照样**几何收缩**（假收缩）⇒ `kdeg` / `muhs` 误判 `BRACKET_INVALID`（实测跨度 20.01→0.00 / 73.90→0.00） |

| **v4（现行）** | v3 仍漏判**混沌窗**：`muhs` 的跨度收敛到 0.65 pp 看似连续，但密采样显示 −36.77/−56.24/−36.90/−41.92/−55.54…（**相邻 19.47 pp、差分变号 12 次**）⇒ v4 新增 ① **`--dense-coarse`**（在**粗区间**上直接密扫，不走二分 —— 因为二分对单调光滑响应会收敛到「响应取中值处」而非跳变处）；② **`ERRATIC` 第三判定分支**（密采样相邻差分**变号 ≥3 次** ⇒ 非单调震荡 ⇒ 既不是阶跃也不是可走的连续段）；③ **`--base-override "k=v"`**（把系统推进到崩塌态后扫旋钮，用于判决「崩塌态是否吸引子」） |
| 判据三态 | 现行判定共三态：**CONTINUOUS**（密扫最大相邻跳变 < 5 pp）/ **DISCONTINUOUS**（≥ 5 pp 的阶跃）/ **ERRATIC**（变号 ≥ 3 次的混沌窗）。**没有第四态「未知」是危险的** —— 判据遇到非单调响应必须有专属出口，否则会被静默误判为 CONTINUOUS |

## 六、纪律（本轮新增）

1. **`--reuse` 通路也是判据通路**：验收脚本读旧 json 时，**缺字段必须显式判定为「跳过」**，不能静默填 0（D-58）。
2. **退出码要三态**：0=全 PASS / 1=有 FAIL / **2=判据被跳过**。把"跳过"折进 PASS 会让不完整验收冒充完整验收。
3. **覆盖率 / 通过率类指标必须同时约束分母侧**（区间宽度、判据强度），否则可平凡满足（D-63）。
4. **路线图也是会被实测推翻的**：T2-2 里「0 钳位」的描述实测是「5 批真钳位、pH_max 9.185」⇒ 判据改成「感知 basic 分支是否已修」而非拍阈值（D-56）。
5. **参数是否有效必须读构建处**：`mu_h`(par[19]) 在 `inhib_flag=2` 分支被覆盖 ⇒ 对 86 批绝大多数无效；有效旋钮是 `mu_h_scale`(par[18])。
6. **「没有代理」要有量化证据**：P / PAA 的否定结论（跨 4 种代理组合一致）才能作为边界被引用（D-64）。
7. **参考模型输出不是化验**：V3 的连续 S/DO2/P/OUR/CER 是模型自身输出，拿它们当软测量的"真值"是**循环论证**；合法目标只有稀疏离线化验列。
8. **治理层未重评审 = 假技术债**：M4 的 4 个阻断项实质早已关闭，卡的只是签核单 ⇒ 治理层的重评审成本极低、收益极高（D-62）。
9. **判据必须覆盖"第三种响应"**：连续性判据不能只有 CONTINUOUS / DISCONTINUOUS 两态 —— **混沌窗（非单调震荡）**必须有自己的出口（`ERRATIC`），
   否则会被静默误判为 CONTINUOUS（D-69）。
10. **预判式结论必须留一个专门的证伪位**：判决性实验的价值在于**它可能否证自己的预判**。
    本轮预判「若四旋钮全无效 ⇒ 崩塌态=吸引子 ⇒ 参数解锁路线全封」被实测**否证**（`sd`/`meanP` 可跨阈值逃逸）
    ⇒ 若不专门跑这一步，台账与后续路线会建立在一个**过强**的否定结论上，进而误判"结构改动是唯一出路"（D-57）。
    **证伪位被触发时必须改写结论，不得事后合理化。**
11. **形式判据达成 ≠ 实质可用**：`kdeg` 在基线态满足"响应不连续度 < 5 pp"，在崩塌态同样"连续"，
    但两个状态下它都**只降不升**（产量 −100%、`P_max` 0.160→0.152）⇒ **连续性判据只回答"能不能小步走完"，
    不回答"走完能不能到目标"**（D-57）。

**R158 追加（T3-3）三条**：

12. **相关系数不是量纲的证据**：PLS 资产的输出单位与 mg/L **差 ~1000 倍**，
    而 R120 的三重验证（0.9995 / 0.9997 / 0.8463）全是相关系数 ⇒ **缩放不变 ⇒ 量纲类缺陷全部隐身**。
    任何「保真度 / 一致性」类指标必须**同时**报绝对量或尺度比（D-70）。
    这是 D-38 的第四种形态：**判据不是恒真，而是恒定地漏掉某一类缺陷**。
13. **覆盖率类指标必须做抗平凡满足检验**：锚定/拟合类构造会让**锚点处**指标恒真
    ⇒ 必须用**留一交叉验证**度量锚点间外推能力；并配一个**平凡上界**（直接插值真值）作为天花板参照（D-72）。
14. **任何「改善」都必须配一个「同样输入、更简单方法」的控制组**：否则会把**校准的功劳**记到被评估对象头上。
    本轮两个控制组各推翻了一个初判：① **A2**（只做两点校准的引擎 PAA）推翻了「PAT 在失真批上有实用价值」
    ——A2 中位 **0.49%** 严格优于 PAT 的 31.90%；② **C0**（同样锚点但锚在引擎 PAA 上）推翻了
    「锚定修正层可交付」——失真批 **41/41** 劣化（D-71 / D-72）。
    **「更简单的基线是否已被击败」是任何交付判定的必要前提。**


15. **由分位数构造的区间，其覆盖率必然等于名义值** —— 这不是「达标」，是同义反复。
    凡引用覆盖率，必须同时引用**区间半宽**与**相对更简单基线的改善**；且必须做一次
    **零信息预测器对照**（把预测换成常数，看指标是否还"达标"）。本轮即用这个对照
    把一个跨三轮、支撑过 M4 阻断项 6 销号的数字证伪（D-78）。
16. **跨通道逐位相同是恒真的强信号** —— 本轮正是靠「X/P/PAA/vis 四通道 coverage 逐位相同」
    发现 D-78。任何在多通道/多批次上汇总的指标，若不同通道给出**逐位相同**的值
    ⇒ 必须先假设它是构造产物，再去反查它的计算路径。
17. **冻结的实现计划不等于实现了的链路** —— M2「回退链冻结」只冻结了**设计**；
    回溯时必须**逐环核对源码**，不能凭「文档已冻结」推断「链路已闭合」（D-75）。
18. **治理层更新必须有一份「受影响文件清单」**，且**逐文件核对** ——

    却漏了 README ⇒ 撤回的结论继续对外流传）。
19. **降级判据必须能被证伪，且必须跑真实样本** —— 合成样本只能证明「判据按设计工作」，
    **证明不了「判据在真实数据上不误报」**。R161 的两个判据缺陷（D-79 地板饱和假阳性、
    D-82 Q/T 恒真越限）**全部由真实批探针抓出**，合成样本 12/12 全绿却一个都没抓到。
    **新增判据的验收门槛：≥1 组真实批的「不该触发」样本。**
20. **「无信息」不等于「健康」** —— 判据在**证据缺失**时若默认判「健康」，

    无探针 / 空序列 / 无 cv 键 ⇒ **一律判不健康**（保守方向：宁可误报降级，不可静默用坏集合）。
21. **判据的适用通道必须由实测确定，不能由直觉假定** —— R161 初版创新判据对全部通道施加
    |z| 门限，实测发现 Q/T 因**模型本身**偏差（T 偏高 2–4 K、Q 发散 4 倍）在**所有批次**上
    恒真越限 ⇒ 该判据等价于没有判据（D-78）。**通道白名单必须由「逐通道越限分布实测」得出**，
    且被排除通道的越限事实仍须记录（不静默丢弃，只是不用它下判决）。

22. **口径必须先核对符号再谈同构** —— MATLAB `Fremoved` 存**负值**出流 ⇒
    `harvested_during = sum(Fremoved·P)·h` 是**负数** ⇒ `yield_total = V_end·P_end − harvested_during`
    实为**加绝对值**。若不核符号就抄公式，会把「同构」判成「差一个负号」（R162 oq#38）。

    且**命题前提本身不成立**（Python 侧的扰动是确定性代理，**没有「种子」这个对象**）。
