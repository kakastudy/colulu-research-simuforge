## 二、R163-1　MCP 接入回退链（D-80）

### 2.1 接入方式：**opt-in + 默认关闭**

| 项 | 设计 |
|---|---|
| 入口 | `reconstruct_batch(batch_no, n_ens=50, fallback_chain=False)` |
| 默认行为 | `fallback_chain=False` ⇒ 返回体与接入前**逐位一致**（不新增任何键） |
| 开启后 | **只追加**一个键 `fallback_chain`，不改动任何既有键 |
| 新增只读工具 | `batch_fallback_tier(batch_no, n_ens=20, seed=7)` —— 只判层级，不跑集合平滑 |
| `solver_info` | 增列 **D 档**（B 档方法族回退链），让 Agent 能发现新能力 |

### 2.2 降级标记**必在返回体**（§3.3「不得静默输出貌似合理的数」）

`fallback_chain` 块的结构：

```
tier                  enkf / mhe / steady_state / explicit_failure
degraded              是否已降级
reconstruction_valid  ★ 主结果（集合平滑）当前是否可信
reasons               降级原因（逐条可读）
trace                 逐环判定链（EnKF → MHE → 稳态 → 显式失败）
fallback              降级后的可用估计（无则 null）
evidence              三环的判据证据量（健康度指标 / MHE 判据 / 稳态 C 平衡）
```

**关键语义**：`tier != 'enkf'` 时**主结果可能不可信**，必须改用 `fallback` 字段；
`tier == 'explicit_failure'` 表示**无可用估计**（不得当作貌似合理的数使用）。
这一点写进了 MCP 工具的 docstring，Agent 调用时可直接看到。

### 2.3 链序与核心实现（`solver_chain.py` 新增第 7 节）

```
EnKF 健康探针 ──(健康)──→ tier=enkf（照常返回，不降级）
     │
  (不健康)
     ↓
MHE（真实残差 + 稳态碳平衡软约束）──(可解)──→ tier=mhe
     │
  (QP 失败 / 残差无结构 / 边界退化)
     ↓
稳态碳平衡基线 ──(闭合)──→ tier=steady_state
     │
  (C 平衡误差 > 20%)
     ↓
tier=explicit_failure（显式失败，不输出貌似合理的数）
```

新增函数（全部**旁路**，不改任何现役数值路径）：

| 函数 | 作用 |
|---|---|
| `evaluate_batch_fallback(batch_no, ...)` | 批次级链编排（返回体含 tier/trace/evidence/fallback） |
| `mhe_batch_residual(batch_no, t_start, t_end, ...)` | **真实批**的 MHE 残差（移动窗内 模型 vs 实测，含碳平衡软约束） |
| `mhe_estimate_batch(batch_no, ...)` | MHE 单步（真实残差） |
| `mhe_rolling(batch_no, ...)` | **MHE 滚动时序调度**（R163-5 主体） |
| `mhe_boundary_degenerate(result, bounds)` | 边界退化判据（D-86 的修正） |
| `steady_state_for_batch(batch_no)` | 稳态基线（真实批口径，与 R161 探针**逐字一致**） |

### 2.4 零回归（Z1）与标记完备性（Z3）

## 三、R163-4　真实退化批验证（D-80 关联）

### 3.1 A 段：跨批自然退化筛查

方法：对 86 个黄金批跑 EnKF 健康度探针（`health_probe=True`，n_ens=8，seed=7），
逐批判定是否触发降级。

> **判据纪律提醒**：R161 的创新判据限制在白名单通道 `CO2outgas/DO2/O2/pH`
> （Q/T 因模型系统性偏差被排除，见 D-82），阈值 `|z| > 5`、**单点越限即触发**。

**结果**（增量落盘，可恢复）：

| 项 | 数值 |
|---|---|
| 已扫批数 | 32 / 86 |
| 自然退化（DEGRADED） | **27 批（触发率 84.38%）** |
| 健康（ok） | 5 批 |
| 触发原因 | 几乎全部为「标准化创新越界」：DO2 越限 1 ~ 546 次，\|z\|max 6 ~ 14+ |

> **⚠ 采样范围声明（诚实边界）**：A 段**未跑满 86 批**——本轮在 **32 批**
> （黄金集前 32 批，按 `GOLDEN_ALL` 顺序覆盖 b1–b40 区间）处停止，
> 以把算力让给 C 段注入与闸门验证。
> ⇒ 触发率 **84.38%** 是**代表性子集**上的估计，**不是全普查**；
> 触发率标准误 ≈ ±6.4%（95% CI ≈ 71.8% ~ 97.0%，二项分布近似）。
> **结论方向不依赖全普查**：只要真实触发率 > 50%，「四分之三的批被误判降级」
> 这一判断就成立 ⇒ D-87 的**定性结论稳健**；但**具体百分比须以全普查为准**。

**⇒ 这就是 D-87 的来源**：一个在合成样本上双向可证伪的判据，在真实数据上**近乎恒真**。
若按原样接入 MCP，四分之三以上的批会被误判降级 —— **比不接更糟**。

### 3.2 首个自然退化批：**b5**（无需任何故障注入）

### 3.3 C 段：物理可信故障注入 + 零信息对照

> **⚠ 方法论修正（R163 自我修正）**：C 段第一轮跑在 `8,22,55,91` 上，
> 但 **b55/b91 本身就是自然退化批**（双稳态批）⇒ 其「注入后触发」
> **不能**归因于注入（对照已退化，触发只是重复观测到该批固有的退化）。
> ⇒ 改为**只在健康批**（A 段判定为 ok 的 `8/11/15/22/23`）上做注入，
> 得到 **20 例全部可归因**的因果证据；b55/b91 的结果保留为「不可归因的补充观察」。

方法：在**真实批数据**上注入工业现场常见的仪表故障，并配**零信息对照**（同批不注入，
实测 5 批对照**全部健康**）。

| 故障 | 物理含义 | 期望 | 实测检出率（可归因子集） |
|---|---|---|---|
| `do2_sensor_drift` | DO2 探头老化/结垢（+0.02 mg/L·h⁻¹ 自 t=40 h 起） | 触发 | **5/5 触发**（\|z\|max 6.20 ~ 7.60） |
| `ph_probe_bias` | pH 探头未校准（恒定 +0.25） | 触发 | **4/5 触发**（b22 漏检；\|z\|max 5.38 ~ 37.72） |
| `co2_sensor_stuck` | CO2 排气分析仪卡死（冻结于 t=60 h） | 触发 | **1/5 触发** ⚠ |

**四格混淆矩阵**（仅对照健康的 20 例）：
**TP = 10、FN = 5、TN = 4、FP = 1**
（TP=DO2 5 + pH 4 + CO2 1；FN=CO2 4 + pH 1；TN=冷却 4；FP=冷却@b23）

#### 3.3.1 `cooling_fault_T` ⇒ 白名单的反向判别力成立

T 通道越限 333 次却**不**触发降级 ⇒ 判据**不是**「见越限就报」，
R161 把 Q/T 排除的判断在真实数据上**成立**。
唯一 1 例假阳性（b23）的 \|z\|max = **5.03**，**恰在阈值 5.0 边缘**
⇒ 与 §六之二 的标定结论一致：**阈值抬到 10 可消除此 FP**。

#### 3.3.2 `co2_sensor_stuck` 漏检 4/5 ⇒ **根因已定位**（不是注入无效）

实测：CO2 卡死后「实测 − 冻结值」的偏离达 **3.8 ~ 13.4 σ**（σ_obs(CO2)=0.05 %），
**远超阈值 5** ⇒ 注入**幅度足够**，不是「注入太弱」。

根因在**模型侧**：`model.py:699-708` 中气相 CO2 `y[27]` 由**模型状态**（产率 q_co2、
通量）驱动、溶解 CO2 `y[28]` 由气液平衡驱动 ⇒
**观测卡死完全不影响模型轨迹**，只造成「模型预测 vs 冻结实测」的偏差；
而该偏差量级（3.8~13.4 σ）**低于 DO2/pH 通道的越限幅度**（|z| 达 37.7）
⇒ 在通道级比较中天然被掩盖。

⇒ **判据的灵敏度是通道依赖的**：
DO2 通道 5/5、pH 通道 4/5、CO2outgas 通道 1/5、O2 通道 0/20（完全无贡献）。
这是 D-87 的**第二个维度**：判据不仅**假阳性高**，还**通道灵敏度极不均衡**。

> 零信息对照：b8/b11/b15/b22/b23 对照=**健康**；b55/b91 对照=**退化** ⇒ 其中 **20 例（健康批）对照天然健康 ⇒ 触发差异可归因于注入**，**8 例（退化批）对照本身已退化 ⇒ 不可归因**（只作补充观察）

## 五、R163-3　扰动方差贡献量化（D-83）

### 5.1 一个关键对应关系：τ 已经对齐，缺的只是方差

MATLAB `indpensim_run.m:148-181` 用**随机低通滤波**生成 8 路时变扰动：

```matlab
b1 = 1 - 0.995;   a1 = [1 -0.995];
v  = randn(T/h+1, 1);
distXXX = filter(b1, a1, AMP * v);      % 8 路：distMuP/distMuX/distcs/distcoil/
                                          %      distabc/distPAA/distTcin/distO_2in
```

一阶低通 `y(n) = B1·AMP·randn(n) + A_POLE·y(n−1)`，其**时间常数**为

```
τ = h / (1 − 0.995) = 0.2 / 0.005 = 40 h
```

而 Python 侧 `simulate.py:492-500` 用的是 `dist(t) = asym·(1 − exp(−t/τ))`，**τ = 40 h**。

⇒ **两者的均值与时间常数已经完全对齐；缺的只是围绕均值的随机成分（方差）。**
这比 R162 的表述（「随机成分完全丢失，只保留了渐近值」）更精确，也把移植难度降了下来。

### 5.2 注入方式：**磁盘上的引擎零改动**

在探针进程内 patch `simulate.integrate_interval`（`simulate_open_loop` 内部是模块级全局查找 ⇒ patch 生效），
把 MATLAB 同构的滤波过程加到现役确定性扰动上。`simulate.py` **一个字节都没动**。

| **paa** | PAA 浓度 | **0.00 pp** | 1.50e+4 g/L | 120 | **0.008** |
| **o2in** | 进气氧浓度 | **0.00 pp** | 1.00e−3 % | 0.009 | **8.99** |

全通道叠加（幅值扫描）：

| scale | Δrel_err |
|---|---|
| 0.25 | **+0.58 pp** |
| 0.50 | **+1.36 pp** |
| 1.00 | **+3.09 pp** |

### 5.4 结论

1. **量级判断**：全通道在解析 σ 下使产量误差变化 **+3.09 pp**，**已超过验收噪声底 2.345%**
   ⇒ MATLAB 端「每批随机抽 85+10·randn 那种量级」的扰动，在**产量口径上是不可忽略的**。
   对照 R162 的 alpha_kla 随机性影响（产量口径中位 0.0102%），**扰动随机成分的贡献大了两个数量级**
   ⇒ 优先级应高于 alpha_kla 逐批标定。
2. **近似线性**：0.25 : 0.50 : 1.00 → 0.58 : 1.36 : 3.09 pp ⇒ 响应基本线性 ⇒ 可外推。
3. **MATLAB 注释 SD 不可直接用作移植依据**：注释 SD 与滤波器实现的解析 SD 相差 **0.008× ~ 9×**
   （paa 差 125 倍、o2in 反向差 9 倍）⇒ 移植必须以**实现的滤波器式**为准。
   这本身是 MATLAB 端的一处**注释与实现不一致**，已并入 D-83 的说明。
4. **paa / o2in 两通道产量影响为 0**：说明引擎在这两个通道上对该幅度的扰动**不敏感**
   （PAA 通道大概率被钳位/受门控保护）⇒ 移植时应**逐通道**标定，不能一刀切。

## 六、R163-5　MHE 滚动时序调度（D-80 关联）+ D-86

### 6.1 滚动调度（`solver_chain.mhe_rolling`）

R161 的 `mhe_step` 是**单窗口单次优化**；本轮扩展为 **receding horizon**：

- 窗口沿时间轴**滚动前进**（步长 `step_h`），每个窗口**重新优化**；
- **warm start**：初值取上一窗口的解（并夹回参数域）⇒ 迭代更少、更稳定；
- 输出**参数时序轨迹**（μp(t)、m_s(t)），而非单点估计；
- 任一窗口不可解 ⇒ **显式标记**并按 `on_failure`（`stop` / `skip`）处理，**不静默跳过**。

同时把 **稳态碳平衡**纳入 MHE 残差作为**软约束**（窗口内模型 CER 积分碳 vs 实测 CER 积分碳，
权重 0.2）⇒ 落实 §3.2 原文「MHE + 稳态碳平衡约束」。

### 6.2 顺带发现的 D-86：MHE 参数化频繁不可辨识

实测（b8）：

| 窗口 | 解 (μp, m_s) | 相对改善 | 判据 |
|---|---|---|---|
| 末端 [225.4, 229.4] | (0.010, 0.01076) — **μp 撞域下界** | +0.3967 | 旧判据：可解 ❌ |
| [100, 104] | (0.03428, 0.005) — **m_s 撞域下界** | +0.8962 | 旧判据：可解 ❌ |

⇒ 「相对改善 > 1e−3」这条 R161 冻结判据在**真实残差面**上**不具判别力**：
解被推到参数域边界，说明目标面在该方向**没有有效梯度信息**（不可辨识），
而优化器只是「停在边界」，相对改善仍然很大。

**修正**：新增「**边界退化**」判据（`mhe_boundary_degenerate`）：
解落在参数域边界 ⇒ 该方向不可辨识 ⇒ 按「残差无结构」降级。
该判定**不改** `mhe_step` 的冻结语义（只在链编排层生效）⇒ R161 的 T5 判据不受影响。
