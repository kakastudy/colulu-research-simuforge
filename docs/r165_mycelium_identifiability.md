## 一、结论（先给判定）

在**现有观测算子 H** 下，A0/A1/A3/A4 构成一个**结构不可辨识的状态子空间**：

| 观测矩阵 | rank | nullity | 奇异值（列归一后） | 判读 |
|---|---:|---:|---|---|
| `H_assim`（真正进入 `enkf_observe.act_obs` 的 10 通道 × 5 时刻） | **0** | **4** | `[0, 0, 0, 0]` | 同化层对 A 组**完全无观测约束** |
| `H_report`（再叠加 `X_sum` / `X_sd` 两个上报标量） | **1** | **3** | `[2.0, 0, 0, 0]`，`cond=inf` | 只暴露 `[1,1,1,1]` 一个方向 |

即：**观测矩阵对 A 组子空间的限制秩 ≤1（同化层实为 0），零空间 ≥3 维**。
增加同类批次、更密采样或更长时程，只是把同一组列重复更多行，**rank 不随行数改变**
（口径复用 `tools/r146_ph_ident.py:276-291`；R146 已给出「样本量不改变列空间秩」的范例）。

判据：`H_report @ δ_null` 对 3 个零空间基方向的 `max|·| = 0.0`（阈值 ≤1e-12）；
非保和对照 `H_report @ δ_pos` 在 δ∈{1e-6, 1e-4, 1e-2, 1e-1} 上为
`{1e-6, 1e-4, 1e-2, 1e-1}` 且严格单调 ⇒ **判据非恒真、非恒假**（承 D-78）。

**但这不等于「模型对菌丝分室不敏感」，更不等于任务书里那句「黏度只约束总生物量」。**
见第二节：这两处都需要勘误，否则会得到一个「理由错误但结论方向碰巧正确」的登记。

## 二、两处必须先澄清的口径偏差（本轮的实际收益）

### 2.1 引擎黏度**不是**总生物量，而是 A0 单室

`candidate/indpensim/v0.1/model.py:660-674` 逐字：

```python
a_0_pos = a_0 if a_0 > 0 else 0.0        # a_0 = y[11] = A0
vis_state = y[9] if y[9] > 0 else 0.0
dy[9] = (vis_scale * 3 * (a_0_pos ** (1.0 / 3.0))
         * (1 / (1 + np.exp(-k1 * (t - t1))))
         * (1 / (1 + np.exp(-k2 * (t - t2))))
         - k3 * Fw
         - vis_decay_rate * vis_state)
```

- A 组**只以 `a_0 = y[11]`（A0 单室）的立方根**出现；既不是 `A0+A1+A3+A4`，
  也不是加权和，也不含 `total_X`（`total_X` 定义在 `model.py:315`，用在
  `pho_b` / `m_ph*total_X` / `X_t` 等处，**不在黏度方程里**）。
- 「黏度 ≈ 总生物量」是 **R129r 的实测经验关系**（`docs/deepening_plan.md:409-411`：
  `vis ≈ 1.77·X + 12.4`，相关性 0.81–0.85），原文自己就写了
  「当前模型使用 `a_0^(1/3)` 而数据显示线性关系，**结构不匹配**」。
- 黏度化验值 (`Viscosity_offline`) 与状态量之间只有一个**标量比例系数**
  `VIS_OUT_SCALE`（`golden_params.py:948-956`，86 批各一个 0.56–1.33 的数），
  **不携带分室比例信息**。

⇒ 治理层（`state.yaml:35`、`r157_debt_ledger.md:362`、`goal_backtrace_check_v4.md:172/224`）
把「黏度只约束总生物量」与「`a_0^(1/3)`」并列作为同一件事，**字面不成立**。

### 2.2 「保总和改比例 ⇒ 所有输出 Δ=0」只在观测算子层成立

`model.py` 的速率对分室是**逐室依赖**的：

| 速率 | 依赖 | 位置 |
|---|---|---|
| `r_e1` / `r_d1` / `r_m0` | A0 | `model.py:379, 381, 382` |
| `r_b0` / `v_a1` / `r_p`（产素） | A1 | `model.py:377, 394, 427` |
| `r_d4` | A3 | `model.py:429` |
| `K_diff`（经 `A_t1`） | 分室比例 | `model.py:310, 373` |
| `total_X_CO2 = A0 + A1` → CER | **仅两室之和** | `model.py:700-701` |

本轮实测（保 ΣA、保 A0 的 A1→A3 扰动，δ=0.01·X0，取 4 批 × 5 时刻的 `max|Δ|`）：

| 通道 | `max|Δ|` | 判读 |
|---|---:|---|
| `total_X` / `pho_b` / `dy9_vis` | `7.1e-15` / `0.0` / `0.0` | 状态量：保和 + 保 A0 ⇒ 浮点地板 |
| `dP_dt` | `1.63e-04` | **非零**：`r_p ∝ A1` |
| `dS_dt` | `4.32e-04` | **非零** |
| `dNH3_dt` | `1.31e-02` | **非零**：`ph_prod` / `X_C_nitrogen` 含分室项 |
| `dCO2_dt` | `5.55e-03` | **非零**：`total_X_CO2 = A0+A1` 被改变 |
| `X_1` | `1.1e-16` | 内部转移项在 `ΣdA_i/dt` 中抵消 |

⇒ **动力学层对分室比例是敏感的**。所以「不可分离」的正确落点只能是
**观测算子的结构秩亏**，不能写成「模型对分室不敏感」或「所有输出都不变」。
本轮同时给出 A0→A1 反例臂（`dy9_vis` Δ=`8.39e-04`、`dP_dt` Δ=`1.63e-04`、
`X_1` Δ=`1.33e-03`、`A_t1` Δ=`2.17e-03`，6 个通道响应）作为**反向判别力**证据。

## 六、边界：不可辨识 ≠ 不可验证

| 层 | 命题 | 能否靠「加同类数据」解决 | 靠什么解决 |
|---|---|---|---|
| **观测算子层（本轮证明）** | 现有 H 下 `A → 观测序列` 非单射，rank≤1 / 零空间≥3 维 | **不能**（100 批只是把同一个 rank-1 约束重复 100 次） | 新增**分室观测通道**（改变 H 的列空间） |
| **数据资产层（D-88 现状）** | 37 列 V3 无任何 A 组实测真值，Raman 通道被 D-71 否证 | 不能（同类数据仍无真值列） | 立项获取含**菌丝形态测量**的数据（R164-V5(b)） |
| **动力学层（本轮反例）** | 模型 rhs 对分室比例**敏感** | 不适用 | 已有证据，不是缺陷 |

**判别式**：「只增加同类数据（更多批次 / 更密采样 / 更长时程）能否让 A 组可辨识？」——
不能 ⇒ 这是**不可辨识**（结构性质）。「换一份含形态测量的数据资产能否改变结论？」——
能 ⇒ 这是**不可验证**（可修复的资产缺陷）。两者边界是
**是否改变了观测算子 H 的列空间**，而非是否增加了数据行数。

⇒ 「不可辨识」**不自动消除**「不可验证」（依旧没有真值可对照）；
反过来，只证明「37 列没有 A 组」也**只是不可验证**（换数据即可解），不足以登记不可辨识。
R164-7 的作用正是补上中间那一层**数值秩亏证据**。
