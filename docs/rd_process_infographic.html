R137 · v1.64
X 的真因不是"整体偏高"，是「该停不停」
化验 X 峰值中位 150h，峰后斜率化验 −0.040 g/L/h（83/86 批下降），模型却是 +0.013——46/86 批方向相反，分叉集中在 t∈[144,168]（37 批）。在线 OUR 独立佐证：b29 −36%、b56 −65%，而 b8 的 −27% 与模型 −25% 正好对上，b8 也正是 X 最准的批之一（nRMSE 4.9）。
顺带关掉两个悬案：①形态学链 a3/a4 恒为 0 确诊为装配缺陷（k_vac 在 86/86 批参数里从未出现，R130 的"液泡化修复"只加代码未接线），但接线无收益——k_vac=0.001 时死菌仅占 8.5%，产量已 −19.3%，因为产素对 a1 是一阶敏感、总生物量只是二阶；②mux 是伪相关：跨批 r=+0.458 很漂亮，一干预却几乎不动（b29 peakR 1.585→1.555），补料流加下它早已饱和，菌量其实由质量平衡 X≈Y_sX×净耗底物 决定。
唯一有效的机制是时间门控晚期衰亡（death_start=144, kd=0.005）：X nRMSE 中位 24.6 → 13.5（75/86 改善），且首次不破坏本来准的批（b8 4.9→5.1）。但代价是产量：|yield|≤5 从 86/86 掉到 33/86，5 批崩溃级（b16 −99.8%）。机制成立、常数不能全局拍——28 批双改善（b29 42.0→16.1 且 −3.4%→+2.5%）证明路走得通，R138 改用 OUR 通道逐批定标。
R138 · v1.65
换档位：X 不再由机理「算」出来，而由在线 OUR「估」出来
R134–R137 的困境其实是档位错误——GOAL §3 早把「B 软测量（逆问题）」列为交付物，我们却一直在 A 档正问题里硬拍参数。
这轮先探了六条路、五条走不通：碳平衡（X 只占碳通量 14%，b8 的呼吸就吃掉 74%）、氮平衡（X 占 N 通量 85% 看似更优，但残差 −41.8%，N 压根不守恒）、氧化学计量（内部 OUR 0.52 vs 导出 1.57 g/L/h，模型自己差 3 倍）、全局 P 降解（44 批证据一致，但加进去每批都变差）、逐批 death_start（b59 产量从 +4.8% 崩到 −27.3%）。
走通的那条极简：X_est = X_model · median₅(OUR实测/OUR模型)^0.6。指数 0.6 不是拟合出来的魔法数——模型 OUR 对 X 的弹性 β≈1.67，反演就该取 1/β；α=1（完全信任带噪 OUR）会过冲到 17.2%，α=0 就是原来的 24.0%。
X 轨迹 nRMSE 23.99% → 5.69%，峰高比 1.155→0.962、末端比 1.380→1.041，15% 以内的批从 16/86 涨到 79/86；5 折交叉验证的 α* 全部落在 0.60、测试集 5.68%，不是过拟合；90% 置信区间实测覆盖率 89.9%（名义 90%）——顺带把 I3 条款也闭合了。
A 档一行未动，产量仍是 RMSE 2.345%、86/86 达标。4 批残余失效（b36 的 OUR 实测比模型高 56%），根因是分不清「X 错了」还是「OUR 标度错了」——这是方法的可辨识性边界，不是 bug。
R139 · v1.69
R138 修对了数字，却修错了对象——加一条 CER 通道就露馅了
R138 把 X 的 nRMSE 从 24% 压到 5.7%，但它给的解释「模型多产 20% 活菌」经不起第二条通道检验：全局 r_CER = 1.039（模型 CER 基本是准的）而 r_OUR = 0.844。X 若真偏高 20%，氧侧碳侧必须同向偏高——CER 没有。所以 OUR 的偏低主要是导出通道的标度偏差：Y_O2_X / m_O2_X 本就是逐批随机量（b8 是 800/200/15，默认 650/160/17.5）。
两条通道的品质可以直接量出来：log r_CER ~ log(X化验/X模型) 斜率 1.005（R² 0.699），r_OUR 是 1.420（R² 仅 0.433）——CER 才是 X 的 1:1 代理。再把每批「批内去均值」后回归，OUR 的系数掉到 0.043、CER 是 0.666：一旦不管「这批整体偏多少」，OUR 对「X 怎么随时间变」几乎零信息。而 X 的主误差恰恰是时间结构——峰后该降不降。
分工于是很干净：批级标度交给 OUR，时间形交给 CER。log(X_est/X_model) = 0.599·mean(log r_OUR) + 0.713·(log r_CER − mean)，X 轨迹 nRMSE 中位 23.99% → 3.17%、p90 7.10%、15% 以内 85/86；相对 v1 改善 >3pt 的 36 批、恶化的 0 批。
最后一批 b36 用门控拦下：批级 r_OUR 落在 [0.52, 1.28] 之外就判「通道标度不可辨识」，回退机理值并显式报警 → 86/86 批 <15%，最坏 12.63%（原来 41.18%），90% 区间也从 ±13pt 收窄到 [−6.8%, +9.5%]。
教训（写进方法论）：能识别异常 ≠ 异常是坏的。晚期 OUR 比值上冲这个指标能把 4 个失效批全拦下、只误报 1 批，可一旦拿它冻结校正，52/86 批被误触发、中位从 5.69 恶化到 13.17——因为「晚期比值上冲」在多数批上是真实的模型缺陷，正是观测器要修的东西。判据必须先做反事实全量，不能只看判别力。

R140 · v1.69
把观测器接进回路，产量从 86/86 掉到 6/86 —— 有些"修好"是假的
三件事一起做。第一件清了欠账：N 平衡一直是唯一破线项（−15.8%，10/12），拆开看是三个实现缺陷——Y_NX/Y_NP 被当成倒数用（MATLAB 注释写的是 mg of N per gram，正确值是 0.010 gN/gX、0.080 gN/gP；原式 P/80 + X/10 让 P 项小 6.4 倍、X 项大 10 倍，两个错误反向抵消，总和看着还行）；漏了 N 池变化（+55 k g）与随罐移除（90 k g），两项合计约占输入的 38%；还有 NH3_shots 整列为零却没人报警。补全后 85/86 批进预算，中位 +9.9%。
但真实化学计量口径给出 −58.1%：模型的 Y_NP=40（4% 含氮）对真实青霉素 8.38%、Y_NX=25（2.5%）对真实菌体 8–10%，差 2–3.6 倍，靠两个虚构氮源（PAA 液 150 g/L、油 20 g/L）互相配平。所以结论是：我们的账对了，模型的 N 不守恒。这个区分必须写清楚，否则又是一个"错误的正確"。
第二件是判决。把 R139 那个把 X 从 24% 压到 3% 的观测器接进 ODE，每 12h 校正一次菌丝形态。X 确实拉住了（24.5→7.4%），但 P 从 18% 崩到 102%，产量达标从 86/86 掉到 6/86，49 批产素直接归零。机制很干净：开环 X 系统性偏高 → 观测器一直要求缩小 → PAA 相对过量积累 → 触发 P_crit_PAA 抑制 → 产素塌陷 → 氧碳比再偏离 → 正反馈。加了 ±5% 限幅也拦不住。
教训（方法论第 3 条）：后处理观测器的增益不能直接当闭环增益用。后处理是"在给定轨迹上做最优拟合"，闭环是"改轨迹再拟合"。前者可以无约束，后者必须过守恒与稳定关。R139 的观测器安全，只因为它改的是上报值、不是 ODE 内部状态——一旦动真格，就等于打破「X 高估 ↔ 产量匹配」这对平衡，把 D-10 的"错误的正確"现场重演一遍。
第三件是扫地：删掉 137 MB 的 tools/vendor（一个 cp312 的 scipy wheel，和 3.10 解释器根本不匹配）、12 个空目录、归档 14 个一次性脚本，给 392 个 .py 编了索引。零回归 max|Δ| = 0.00e+00。
R141 · v1.69（当前）
把 D-8 实现出来，才发现它的前提是错的
D-8 挂了三轮：衰亡项 -kd·y[i] 对 a0/a1/a3/a4 等比施加，所以"只移除死菌、保留活菌"表达不出来。这轮把它实现了——death_mode=1 叠加一条形态学链：A1 老化进 A3（菌体内部转移，不动总量）→ A3/A4 溶菌出系统，死菌池首次非零。
然后它就失败了，而且失败得很干净。
第一条硬事实：A1 占 X 的 80–83%，而 X/A1 在整段发酵里 CV 只有 2.5–3.3%（1.23–1.28）。r_p = μp·a1/2 是一阶。所以 X 和产素共用同一个状态变量——任何状态层面的 X 削减，就是等比例的产素削减。
第二条更致命：X = a0+a1+a3+a4，死菌也算 X（化验的总生物量同样是这个口径）。所以"把活菌变成死菌"根本不会降低 X，只会先把 X 抬高（死菌池堆起来），而产素立刻下滑。真正能降 X 的只有溶出系统，稳态死菌池 ≈ (age/lysis)·a1、X 的下降速率 ≈ age·a1——和 lysis 无关。
推论是解析的：lysis→∞ 时死菌池→0，机制退化成"按 age 直接移除 a1"，也就是等比衰亡的一个特例；lysis 有限时严格更差。实测完全对上——age 固定 0.010，lysis 从 0.01 拉到 1.0，死菌池从 14.2% 掉到 0.4%，X 末从 25.05 降到 22.55，结果一路收敛到"直接砍 a1"的解。
十批对照（基线 0/10 破线）把代价摆得很清楚：等比臂能把 X 修到 +32pt；形态学臂最多 +9.8pt，还要背 25% 的死菌池，而产量代价照付——ΔX 中位只有 +0.2~+0.5pt，产量中位却掉 2.5~7.3pt，破线从 0/10 变成 4–7/10。典型 B8：X 只动 0.8pt（噪声级），产量掉 7.25pt。
于是三条互不相同的"改状态"路线全部撞墙：R137 等比晚期衰亡 33/86、R140 闭环同化 6/86、R141 形态学链 0/10→4–7/10。而 R139 那个只改上报值的后处理观测器把 X 从 24% 压到 3.2%，零风险。
结论所以不是"再换个死法"，而是：X 高估是观测模型的问题（化验 X 的组成 ≠ 模型 a0/a1 的组成），不是状态模型的缺陷。这正面解释了 R140 那个硬否决。
方法论第 4 条："能表达"不等于"有价值"，先证明机制的前提再实现它。如果先写下 X = a0+a1+a3+a4 并问一句"清死菌会让这个和变小吗"，这一轮可以省掉。
D-8 关闭，L2 阻断项 3 → 2（余 D-2 DL σ̂、D-9 b92 故障幅值）。零回归 max|Δ| = 0.00e+00。

07
研发方法论Principles
①
目标冻结，红线否决
任何改进不得突破 ±5% / 3.5% / 0-catastrophic 三红线。R132 中"按 1/gain 改黏度标度"的捷径因使 86/86→63/86 被产量红线直接否决。
②
证据链优先于自由度
残差先归因再修：黏度 corr(nRMSE, |相对偏差|)=0.975 → 判定残差是"幅度"非"形状"，故只做测量链换算而非改机理。
③
失败必须可见（I2）
越有效域、积分发散一律显式输出状态与原因，永不静默回归；crash 分 normal/benign/catastrophic 三级并附证据。
④
单一事实源
参数只经 build_params 装配，golden_params 为唯一真值；曾因服务层绕路导致 RMSE 25.61% 的 10× 口径漂移，已根除。
⑤
零回归护栏
每次结构性改动后跑全量黄金集回归，产量路径须逐位不变（R133 黏度解耦即验证零回归）。
